ใบงานที่ 3.4 Custom hook และการโหลดข้อมูลแบบอะซิงโครนัส

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แยกตรรกะรายการงานเป็น custom hook และโหลดข้อมูลแบบอะซิงโครนัสพร้อมสถานะ loading error ว่าง ได้

คำชี้แจง

ใบงานนี้แยกตรรกะของรายการงานไปไว้ใน custom hook และจำลองการโหลดข้อมูลที่ใช้เวลาและบางครั้งล้มเหลว ทำทีละขั้นโดยวางโค้ดทั้งไฟล์ ทำใบงาน 3.2 ให้เสร็จก่อน (ไม่จำเป็นต้องทำ 3.3)

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 3.3
  • ใบความรู้ที่ 3 หัวข้อ useEffect อะซิงโครนัส และ custom hook

ขั้นตอนการปฏิบัติ

  1. เตรียมความพร้อม: ionic serve รันอยู่ และเปิดโปรเจกต์ใน VS Code จะสร้างโฟลเดอร์ src/hooks ใหม่ (คลิกขวาที่ src เลือก New Folder ชื่อ hooks)

    ผลที่ควรเห็น: มีโฟลเดอร์ hooks ใน src

  2. สร้างไฟล์ src/hooks/useTasks.ts (นามสกุล .ts ไม่ใช่ .tsx เพราะไม่มี JSX) แล้ววางโค้ดนี้ กด Ctrl+S ขั้นนี้ hook ยังมีแค่การโหลดข้อมูล

    ไฟล์ src/hooks/useTasks.ts
    import { useEffect, useState } from 'react';

export interface Task { id: number; title: string; done: boolean }

const wait = (ms: number) => new Promise(r => setTimeout(r, ms));

// จำลองการดึงข้อมูลจากเซิร์ฟเวอร์ ล้มเหลวประมาณ 1 ใน 3 ครั้ง
async function fetchTasks(): Promise<Task[]> {
  await wait(800);
  if (Math.random() < 0.33) throw new Error('network');
  return [
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ];
}

export function useTasks() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  async function load() {
    setLoading(true);
    setError('');
    try {
      setTasks(await fetchTasks());
    } catch (e) {
      setError('โหลดข้อมูลไม่สำเร็จ');
    } finally {
      setLoading(false);
    }
  }

  useEffect(() => {
    load();
  }, []);

  return { tasks, loading, error, load };
}
    ผลที่ควรเห็น: ยังไม่มีผลบนหน้าเว็บ เพราะยังไม่มีหน้าไหนเรียกใช้ hook นี้

  3. อ่านโค้ด hook: หาฟังก์ชัน fetchTasks แล้วเขียนในช่องบันทึกว่ามันจำลองอะไร (คำใบ้: wait(800) กับ Math.random() < 0.33) และ useEffect(() => { load(); }, []) ทำอะไร

    ผลที่ควรเห็น: ตอบได้ว่าจำลองเซิร์ฟเวอร์ที่ตอบช้า 0.8 วินาทีและล้มเหลวประมาณ 1 ใน 3 ครั้ง และ useEffect ที่มี [] เรียก load หนึ่งครั้งตอนเปิดหน้า

  4. ใช้ hook ในหน้า: เปิด src/pages/Home.tsx ลบโค้ดทั้งหมดแล้ววางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { IonButton, IonContent, IonPage } from '@ionic/react';
import { useTasks } from '../hooks/useTasks';

const Home: React.FC = () => {
  const { tasks, loading, error, load } = useTasks();

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน</h2>

        {loading && <p>กำลังโหลด...</p>}

        {error && (
          <>
            <p>{error}</p>
            <IonButton onClick={load}>ลองใหม่</IonButton>
          </>
        )}

        {!loading && !error && tasks.length === 0 && <p>ยังไม่มีงาน</p>}

        {!error && (
          <ul>
            {tasks.map(t => (
              <li key={t.id}>{t.title}</li>
            ))}
          </ul>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: ขึ้นข้อความ กำลังโหลด... ประมาณ 1 วินาที แล้วมีรายการ อ่านใบความรู้ และ ทำใบงาน (หรือขึ้น โหลดข้อมูลไม่สำเร็จ พร้อมปุ่ม ลองใหม่ ถ้าโชคร้าย)

  5. กด F5 รีเฟรชหน้าเว็บซ้ำ ๆ จนเห็นทั้งสองสถานการณ์ (สำเร็จ และล้มเหลว) แล้วถ่ายภาพแต่ละสถานการณ์ (ในโหมดพัฒนา ข้อมูลอาจโหลดสองรอบเพราะ React.StrictMode เป็นเรื่องปกติ)

    ผลที่ควรเห็น: ได้ภาพ 2 ภาพ: ภาพรายการที่โหลดสำเร็จ และภาพข้อความ โหลดข้อมูลไม่สำเร็จ พร้อมปุ่ม ลองใหม่

  6. เมื่อเห็นข้อความล้มเหลว ให้กดปุ่ม ลองใหม่ (ถ้าล้มอีกให้กดซ้ำ)

    ผลที่ควรเห็น: ขึ้น กำลังโหลด... แล้วกลับมาแสดงรายการเมื่อสำเร็จ

  7. ตรวจสถานะ 4 แบบ: ดูโค้ดใน Home.tsx ที่มี loading, error, ข้อความ ยังไม่มีงาน และรายการ แล้วเขียนตาราง 4 แถวในช่องบันทึก: สถานะ / เมื่อใดเกิด / หน้าจอแสดงอะไร

    ผลที่ควรเห็น: ตารางที่ระบุว่า กำลังโหลด (loading เป็น true) ผิดพลาด (error ไม่ว่าง) ว่าง (ไม่ loading ไม่ error และ tasks ว่าง) และมีข้อมูล

  8. ขั้นที่ 2: เพิ่ม toggle และ remove ลงใน hook: ลบโค้ดทั้งหมดใน useTasks.ts แล้ววางโค้ดนี้ (เพิ่ม remaining, toggle, remove และส่งออกเพิ่ม) กด Ctrl+S

    ไฟล์ src/hooks/useTasks.ts
    import { useEffect, useState } from 'react';

export interface Task { id: number; title: string; done: boolean }

const wait = (ms: number) => new Promise(r => setTimeout(r, ms));

// จำลองการดึงข้อมูลจากเซิร์ฟเวอร์ ล้มเหลวประมาณ 1 ใน 3 ครั้ง
async function fetchTasks(): Promise<Task[]> {
  await wait(800);
  if (Math.random() < 0.33) throw new Error('network');
  return [
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ];
}

export function useTasks() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  const remaining = tasks.filter(t => !t.done).length;

  async function load() {
    setLoading(true);
    setError('');
    try {
      setTasks(await fetchTasks());
    } catch (e) {
      setError('โหลดข้อมูลไม่สำเร็จ');
    } finally {
      setLoading(false);
    }
  }

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function remove(id: number) {
    setTasks(tasks.filter(t => t.id !== id));
  }

  useEffect(() => {
    load();
  }, []);

  return { tasks, loading, error, remaining, load, toggle, remove };
}
    ผลที่ควรเห็น: ยังเหมือนเดิมบนหน้าเว็บ (หน้าแม่ยังไม่ได้ใช้ฟังก์ชันใหม่)

  9. ลบโค้ดทั้งหมดใน Home.tsx แล้ววางโค้ดนี้ ซึ่งเรียกใช้ฟังก์ชันที่เพิ่มใน hook กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { IonButton, IonContent, IonPage } from '@ionic/react';
import { useTasks } from '../hooks/useTasks';

const Home: React.FC = () => {
  const { tasks, loading, error, remaining, load, toggle, remove } = useTasks();

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน ({remaining} ที่ยังไม่เสร็จ)</h2>

        {loading && <p>กำลังโหลด...</p>}

        {error && (
          <>
            <p>{error}</p>
            <IonButton onClick={load}>ลองใหม่</IonButton>
          </>
        )}

        {!loading && !error && tasks.length === 0 && <p>ยังไม่มีงาน</p>}

        {!error && (
          <ul>
            {tasks.map(t => (
              <li key={t.id}>
                <input type="checkbox" checked={t.done} onChange={() => toggle(t.id)} />
                <span style={{ textDecoration: t.done ? 'line-through' : 'none' }}>{t.title}</span>
                <button onClick={() => remove(t.id)}>ลบ</button>
              </li>
            ))}
          </ul>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: รายการมีกล่องติ๊กและปุ่ม ลบ หัวข้อบอกจำนวนที่ยังไม่เสร็จ ติ๊กและลบได้ตามปกติ และเมื่อโหลดล้มเหลวจะซ่อนรายการและแสดงปุ่ม ลองใหม่

  10. ทดสอบ: ติ๊ก 1 งาน ลบ 1 งาน แล้วกด F5 รีเฟรชหน้า

    ผลที่ควรเห็น: หลังรีเฟรชรายการกลับมาเป็นข้อมูลชุดเริ่มต้นทั้งหมด (เพราะข้อมูลอยู่ในหน่วยความจำ ไม่ได้บันทึก จะทำในหน่วยที่ 6)

  11. สังเกตการแยกหน้าที่: เปิดไฟล์ Home.tsx แล้วนับว่ามีกี่บรรทัดที่เกี่ยวกับตรรกะข้อมูล (useState, fetch) เทียบกับใน useTasks.ts เขียนผลในช่องบันทึก

    ผลที่ควรเห็น: เห็นว่า Home.tsx เหลือแต่ส่วนแสดงผล ส่วนข้อมูลและตรรกะอยู่ใน useTasks.ts

  12. สังเกต Console: กด F12 แท็บ Console ใส่ console.log('โหลดข้อมูล'); เป็นบรรทัดแรกในฟังก์ชัน load ของ useTasks.ts แล้วกด Ctrl+S รีเฟรชหน้า นับว่าขึ้นข้อความกี่ครั้ง บันทึกผล

    ผลที่ควรเห็น: ในโหมดพัฒนาขึ้น 2 ครั้ง เพราะ React.StrictMode เรียก useEffect สองครั้งเพื่อช่วยตรวจปัญหา (ตอนใช้งานจริงหลัง build จะเรียกครั้งเดียว) ลบบรรทัด console.log ออก

  13. ทดลองคำถามสุดท้าย: ถ้าสองคอมโพเนนต์เรียก useTasks() แต่ละตัวจะได้ข้อมูลชุดเดียวกันหรือไม่ ลองทดสอบโดยเพิ่ม const second = useTasks(); ชั่วคราวในหน้า Home แล้วเพิ่มบรรทัด <p>ตัวที่สอง: {second.tasks.length} งาน</p> ใต้หัวข้อ ติ๊กหรือลบงานในรายการหลัก ดูตัวเลขของตัวที่สอง

    ผลที่ควรเห็น: ตัวเลขของตัวที่สองไม่เปลี่ยนตามการลบในรายการหลัก แปลว่าแต่ละครั้งที่เรียก hook ได้ state ของตัวเอง (ไม่ใช้ร่วมกัน) แล้วลบสองบรรทัดที่เพิ่มออก

  14. เขียนคำตอบข้อสุดท้ายในช่องบันทึก 2 - 3 ประโยค: ผลทดสอบเป็นอย่างไร และถ้าต้องการให้หลายหน้าใช้ข้อมูลร่วมกัน ควรทำอย่างไร (คำใบ้ในใบความรู้: ยก state ไปไว้ที่หน้าแม่ หรือใช้ context)

    ผลที่ควรเห็น: คำตอบที่บอกว่าไม่ใช้ร่วมกัน และวิธีแก้

  15. ส่งงานขึ้น GitHub: เปิดเทอร์มินัลใหม่ แล้วพิมพ์ทีละบรรทัด

    git add .

git push
    ผลที่ควรเห็น: ขึ้น Writing objects ... done ที่หน้า GitHub เห็นโฟลเดอร์ src/hooks

คำแนะนำ

  • ถ้าข้อมูลโหลดล้มเหลวบ่อยจนเสียเวลา เป็นเรื่องปกติของโค้ดจำลอง (ตั้งใจให้ล้มเหลว 1 ใน 3) ให้กดลองใหม่
  • ไฟล์ hook ต้องชื่อขึ้นต้นด้วย use และเก็บในโฟลเดอร์ src/hooks
  • ถ้า import { useTasks } from '../hooks/useTasks' มีเส้นแดง ให้ตรวจว่าไฟล์ชื่อ useTasks.ts และบันทึกแล้ว

สิ่งที่ต้องส่ง
