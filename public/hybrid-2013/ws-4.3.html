ใบงานที่ 4.3 แสดงรายการ ค้นหา และลบรายการ

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แสดงรายการข้อมูลด้วย IonList พร้อมช่องค้นหา การลบรายการ และสถานะรายการว่าง โดยไม่แก้ state ตรง ๆ

คำชี้แจง

สร้างหน้ารายการของแอปตนเองจากโค้ดตั้งต้น แล้วปรับข้อมูลและคอมโพเนนต์ให้ตรงกับแบบร่าง ตอนนี้ข้อมูลอยู่ในหน่วยความจำของหน้าและหายเมื่อรีเฟรช (เก็บถาวรในหน่วยที่ 6)

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 4.1 และ 4.2
  • ใบความรู้ที่ 3 หัวข้อ useState และใบความรู้ที่ 4 หัวข้อรายการ

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
import { useState } from 'react';
import {
  IonContent, IonHeader, IonItem, IonItemOption, IonItemOptions, IonItemSliding, IonLabel, IonList,
  IonNote, IonPage, IonSearchbar, IonTitle, IonToolbar,
} from '@ionic/react';

interface Item { id: number; title: string; category: string; amount: number }

const INITIAL: Item[] = [
  { id: 1, title: 'ข้าวกลางวัน', category: 'อาหาร', amount: 60 },
  { id: 2, title: 'ค่ารถ', category: 'เดินทาง', amount: 40 },
  { id: 3, title: 'ซื้อสมุด', category: 'การเรียน', amount: 85 },
  { id: 4, title: 'ชานมไข่มุก', category: 'อาหาร', amount: 55 },
];

const ItemList: React.FC = () => {
  const [items, setItems] = useState<Item[]>(INITIAL);
  const [query, setQuery] = useState('');

  const visible = items.filter(i => i.title.includes(query) || i.category.includes(query));

  function remove(id: number) {
    setItems(items.filter(i => i.id !== id));
  }

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>รายการ ({visible.length})</IonTitle>
        </IonToolbar>
        <IonToolbar>
          <IonSearchbar
            value={query}
            placeholder="ค้นหาชื่อหรือหมวด"
            onIonInput={e => setQuery(String(e.detail.value ?? ''))}
          />
        </IonToolbar>
      </IonHeader>
      <IonContent>
        {visible.length === 0 ? (
          <p className="ion-padding ion-text-center">ไม่พบรายการ</p>
        ) : (
          <IonList>
            {visible.map(i => (
              <IonItemSliding key={i.id}>
                <IonItem>
                  <IonLabel>
                    <h2>{i.title}</h2>
                    <p>{i.category}</p>
                  </IonLabel>
                  <IonNote slot="end">{i.amount} บาท</IonNote>
                </IonItem>
                <IonItemOptions side="end">
                  <IonItemOption color="danger" onClick={() => remove(i.id)}>ลบ</IonItemOption>
                </IonItemOptions>
              </IonItemSliding>
            ))}
          </IonList>
        )}
      </IonContent>
    </IonPage>
  );
};

export default ItemList;

ขั้นตอนการปฏิบัติ

  1. วางโค้ดตั้งต้นในไฟล์หน้าใหม่ (เช่น src/pages/ItemList.tsx) และทดสอบการค้นหาและการลบ (ใช้เมาส์ลากรายการไปทางซ้ายเพื่อให้ปุ่มลบปรากฏ)

  2. ปรับข้อมูลและแถวรายการให้ตรงกับแอปของตนเองตามแบบร่าง (ข้อมูลอย่างน้อย 5 รายการ)

  3. เพิ่มส่วนสรุปด้านบนหรือล่างของรายการ เช่น ผลรวมหรือจำนวนรายการ โดยคำนวณจากข้อมูลโดยตรง ไม่เก็บเป็น state แยก

  4. เพิ่มการเพิ่มรายการ: ปุ่มลอย (IonFab) ที่เพิ่มรายการใหม่ในรายการด้วย setItems([...items, รายการใหม่]) ใช้ id ที่ไม่ซ้ำ (เช่น Date.now())

  5. เพิ่มการยืนยันก่อนลบ ด้วย useIonAlert (แสดงกล่องถามยืนยัน ปุ่ม ยกเลิก และ ลบ) ศึกษาวิธีใช้จากเอกสาร Ionic

  6. ปรับข้อความสถานะว่างให้บอกผู้ใช้ว่าทำอะไรต่อได้ (เช่น "ยังไม่มีรายการ กดปุ่ม + เพื่อเพิ่ม") และทดสอบทั้งสถานะว่างจากการค้นหาและจากการลบจนหมด

  7. ถ่ายภาพหน้าจอ 3 ภาพ (มีรายการ ผลการค้นหา สถานะว่าง) และเขียนอธิบายสั้น ๆ ว่าเหตุใดต้องมี key และเหตุใดผลรวมไม่ควรเก็บเป็น state แยก

คำแนะนำ

  • ห้ามใช้ items.push(...) หรือแก้ค่าในอาร์เรย์ตรง ๆ ให้สร้างอาร์เรย์ใหม่ด้วย spread หรือ filter
  • ถ้าลบแล้วรายการสลับตำแหน่งแปลก ๆ ให้ตรวจว่า key เป็น id ไม่ใช่ลำดับ (index)
  • IonItemSliding ใช้ได้ดีบนมือถือ บนคอมพิวเตอร์ให้ใช้เมาส์ลาก
