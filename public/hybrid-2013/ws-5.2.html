ใบงานที่ 5.2 ถ่ายภาพและเลือกรูปจากคลังภาพ

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

ใช้ Camera ถ่ายภาพและเลือกรูปจากคลังภาพ แสดงผลในแอป และจัดการกรณียกเลิกหรือไม่รองรับได้

คำชี้แจง

สร้างหน้าแกลเลอรีรูปของแอปตนเอง ที่มีปุ่มถ่ายภาพ ปุ่มเลือกรูป แสดงรูปเป็นตาราง และลบรูปได้ ตอนนี้รูปเก็บในหน่วยความจำของหน้า (การเก็บถาวรทำในหน่วยที่ 6)

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 5.1
  • ใบความรู้ที่ 5 หัวข้อกล้องและคลังภาพ

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
import { useState } from 'react';
import { IonButton, IonCol, IonContent, IonGrid, IonHeader, IonPage, IonRow, IonTitle, IonToolbar } from '@ionic/react';
import { Camera, MediaTypeSelection } from '@capacitor/camera';

const Gallery: React.FC = () => {
  const [photos, setPhotos] = useState<string[]>([]);
  const [message, setMessage] = useState('');

  async function take() {
    try {
      const result = await Camera.takePhoto({ quality: 80 });
      if (result.webPath) setPhotos([...photos, result.webPath]);
      setMessage('');
    } catch (e) {
      setMessage('ไม่ได้ถ่ายภาพ (ยกเลิก ไม่ได้รับสิทธิ์ หรือเครื่องไม่รองรับ)');
    }
  }

  async function pick() {
    try {
      const result = await Camera.chooseFromGallery({
        mediaType: MediaTypeSelection.Photo,
        allowMultipleSelection: true,
        limit: 5,
      });
      const paths = result.results.map(r => r.webPath).filter((p): p is string => !!p);
      setPhotos([...photos, ...paths]);
      setMessage('');
    } catch (e) {
      setMessage('ไม่ได้เลือกรูป');
    }
  }

  function remove(src: string) {
    // TODO: ลบรูปนี้ออกจาก photos (สร้างอาร์เรย์ใหม่ด้วย filter)
  }

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>แกลเลอรีของฉัน ({photos.length})</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <IonButton onClick={take}>ถ่ายภาพ</IonButton>
        <IonButton fill="outline" onClick={pick}>เลือกจากคลังภาพ</IonButton>
        {message && <p>{message}</p>}

        {photos.length === 0 ? (
          <p className="ion-text-center">ยังไม่มีรูป กดปุ่มด้านบนเพื่อเพิ่ม</p>
        ) : (
          <IonGrid>
            <IonRow>
              {photos.map(src => (
                <IonCol size="6" key={src}>
                  <img src={src} alt="รูปในแกลเลอรี" style={{ width: '100%' }} />
                  <IonButton size="small" color="danger" onClick={() => remove(src)}>ลบ</IonButton>
                </IonCol>
              ))}
            </IonRow>
          </IonGrid>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Gallery;

ขั้นตอนการปฏิบัติ

  1. ติดตั้งปลั๊กอินด้วยคำสั่ง npm install @capacitor/camera @ionic/pwa-elements ตามเอกสารของ Capacitor เพิ่มการเรียก defineCustomElements(window) ที่ไฟล์ src/main.tsx เพื่อให้มีหน้าจอกล้องบนเบราว์เซอร์ (ศึกษาวิธีเรียกจากเอกสาร)

  2. สร้างไฟล์หน้าใหม่จากโค้ดตั้งต้นและทดสอบปุ่มเลือกจากคลังภาพ (บนเว็บจะเปิดหน้าต่างเลือกไฟล์) ตรวจว่ารูปแสดงเป็นตาราง 2 คอลัมน์

  3. ทดสอบปุ่มถ่ายภาพที่ localhost ถ้าเครื่องมีกล้อง (ถ้าไม่มี บันทึกข้อความที่เห็น และอธิบายว่าแอปจัดการกรณีนี้อย่างไร)

  4. เติมฟังก์ชัน remove ให้ลบรูปได้โดยไม่แก้ state ตรง ๆ แล้วทดสอบ

  5. ทดสอบกรณียกเลิก: เปิดหน้าต่างเลือกรูปแล้วกดยกเลิก ดูว่าแอปไม่ค้างและแสดงข้อความเหมาะสม ถ่ายภาพ

  6. เพิ่มข้อจำกัดจำนวนรูปสูงสุด 6 รูป เมื่อเต็มให้ปิดปุ่มเพิ่มและแสดงข้อความ

  7. สรุปเป็นตาราง 4 แถว: ความสามารถของ Camera ที่ใช้ได้บนเว็บ ที่ใช้ได้เฉพาะบนอุปกรณ์ (ดูจากเอกสาร Camera API ของ Capacitor) ผลที่ทดสอบบนเว็บ และสิ่งที่ยังต้องทดสอบบนอุปกรณ์จริง

คำแนะนำ

  • รูปที่ได้จาก webPath ใช้แสดงในแท็ก img ได้ แต่เมื่อรีเฟรชหรือปิดแอปจะไม่คงอยู่ จนกว่าจะบันทึกไฟล์ (หน่วยที่ 6)
  • ถ้าพบคำสั่ง getPhoto ในบทความเก่า อย่านำมาใช้ เพราะถูกประกาศเลิกใช้ ให้ใช้ takePhoto และ chooseFromGallery
  • การถ่ายภาพบนมือถือผ่านเบราว์เซอร์ต้องเป็น HTTPS ถ้าอยากทดสอบบนมือถือ ให้ deploy เว็บแบบ HTTPS หรือสร้างโปรเจกต์ Android ในหน่วยที่ 9

สิ่งที่ต้องส่ง

ภาพหน้าจอ 3 ภาพ (ไม่มีรูป มีรูป และกรณียกเลิก) + ตารางสรุป 4 แถว + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
