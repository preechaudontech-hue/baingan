ใบงานที่ 5.2 ถ่ายภาพและเลือกรูปจากคลังภาพ

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

ใช้ Camera ถ่ายภาพและเลือกรูปจากคลังภาพ แสดงผลในแอป และจัดการกรณียกเลิกหรือไม่รองรับได้

คำชี้แจง

ionic serve ต้องรันอยู่ และเปิดเบราว์เซอร์ที่ localhost (ตำแหน่งและกล้องบนเบราว์เซอร์ใช้ได้เฉพาะ localhost หรือ HTTPS เท่านั้น) ทุกขั้นที่ "วางโค้ดทั้งไฟล์" ให้ลบของเดิมก่อนด้วย Ctrl+A แล้ว Delete ใบงานนี้สร้างหน้า /gallery ถ่ายภาพ เลือกรูป แสดงเป็นตาราง และลบรูป

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 5.1
  • ใบความรู้ที่ 5 หัวข้อกล้องและคลังภาพ

ขั้นตอนการปฏิบัติ

  1. เปิดเทอร์มินัลใหม่แล้วติดตั้งปลั๊กอินกล้องและตัวช่วยหน้าจอกล้องบนเว็บ

    npm install @capacitor/camera @ionic/pwa-elements
    ผลที่ควรเห็น: จบโดยไม่มีข้อความ ERR

  2. เปิดไฟล์ src/main.tsx เพิ่ม 2 อย่าง: บรรทัด import ใต้บรรทัด import { createRoot } ... และบรรทัดเรียกใช้ก่อนบรรทัด const container = ... (ทำให้เบราว์เซอร์มีหน้าจอกล้องให้ปลั๊กอินใช้) แล้ว Ctrl+S

    ไฟล์ src/main.tsx
    import { defineCustomElements } from '@ionic/pwa-elements/loader';

defineCustomElements(window);
    ผลที่ควรเห็น: เบราว์เซอร์รีโหลดเอง ไม่มีข้อความแดง (หลังข้อนี้ แอปต้องยังเปิดหน้าเดิมได้ปกติ)

  3. สร้างไฟล์ src/pages/Gallery.tsx วางโค้ดนี้ทั้งไฟล์ กด Ctrl+S

    ไฟล์ src/pages/Gallery.tsx
    import { useState } from 'react';
import { IonButton, IonCol, IonContent, IonGrid, IonHeader, IonPage, IonRow, IonTitle, IonToolbar } from '@ionic/react';
import { Camera, MediaTypeSelection } from '@capacitor/camera';

const Gallery: React.FC = () => {
  const [photos, setPhotos] = useState<string[]>([]);
  const [message, setMessage] = useState('');

  async function take() {
    try {
      const result = await Camera.takePhoto({ quality: 80 });
      if (result.webPath) setPhotos([...photos, result.webPath]);
      setMessage('');
    } catch (e) {
      setMessage('ไม่ได้ถ่ายภาพ (ยกเลิก ไม่ได้รับสิทธิ์ หรือเครื่องไม่รองรับ)');
    }
  }

  async function pick() {
    try {
      const result = await Camera.chooseFromGallery({
        mediaType: MediaTypeSelection.Photo,
        allowMultipleSelection: true,
        limit: 5,
      });
      const paths = result.results.map(r => r.webPath).filter((p): p is string => !!p);
      setPhotos([...photos, ...paths]);
      setMessage('');
    } catch (e) {
      setMessage('ไม่ได้เลือกรูป');
    }
  }

  function remove(src: string) {
    // TODO: ลบรูปนี้ออกจาก photos (สร้างอาร์เรย์ใหม่ด้วย filter)
  }

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>แกลเลอรีของฉัน ({photos.length})</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <IonButton onClick={take}>ถ่ายภาพ</IonButton>
        <IonButton fill="outline" onClick={pick}>เลือกจากคลังภาพ</IonButton>
        {message && <p>{message}</p>}

        {photos.length === 0 ? (
          <p className="ion-text-center">ยังไม่มีรูป กดปุ่มด้านบนเพื่อเพิ่ม</p>
        ) : (
          <IonGrid>
            <IonRow>
              {photos.map(src => (
                <IonCol size="6" key={src}>
                  <img src={src} alt="รูปในแกลเลอรี" style={{ width: '100%' }} />
                  <IonButton size="small" color="danger" onClick={() => remove(src)}>ลบ</IonButton>
                </IonCol>
              ))}
            </IonRow>
          </IonGrid>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Gallery;
    ผลที่ควรเห็น: ยังไม่เห็นผลบนหน้าเว็บ

  4. เพิ่มเส้นทางใน src/App.tsx แบบเดียวกับใบงาน 5.1 คือ import Gallery from './pages/Gallery'; และ <Route path="/gallery" element={<Gallery />} /> แล้ว Ctrl+S

    ไฟล์ src/App.tsx
    import Gallery from './pages/Gallery';

<Route path="/gallery" element={<Gallery />} />
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  5. ในเบราว์เซอร์ เปิดที่อยู่ /gallery

    ผลที่ควรเห็น: แถบหัว แกลเลอรีของฉัน (0) ปุ่ม ถ่ายภาพ และ เลือกจากคลังภาพ และข้อความ ยังไม่มีรูป กดปุ่มด้านบนเพื่อเพิ่ม

  6. กดปุ่ม เลือกจากคลังภาพ แล้วเลือกรูปจากเครื่อง 2 รูป

    ผลที่ควรเห็น: เปิดหน้าต่างเลือกไฟล์ของเครื่อง เลือกแล้วหัวข้อเป็น แกลเลอรีของฉัน (2) และรูปปรากฏเป็นตาราง 2 คอลัมน์ พร้อมปุ่มสีแดง ลบ ใต้แต่ละรูป

  7. ทดสอบกรณียกเลิก: กดปุ่ม เลือกจากคลังภาพ อีกครั้ง แล้วกดยกเลิกในหน้าต่างเลือกไฟล์

    ผลที่ควรเห็น: แอปไม่ค้างและไม่พัง จำนวนรูปไม่เปลี่ยน อาจมีข้อความ ไม่ได้เลือกรูป ถ่ายภาพ

  8. กดปุ่ม ถ่ายภาพ (ถ้าเครื่องมีกล้อง ให้กด อนุญาต เมื่อเบราว์เซอร์ถาม)

    ผลที่ควรเห็น: ถ้ามีกล้อง: ขึ้นหน้าจอกล้องให้ถ่าย ถ้าไม่มีกล้องหรือไม่อนุญาต: ขึ้นข้อความ ไม่ได้ถ่ายภาพ (ยกเลิก ไม่ได้รับสิทธิ์ หรือเครื่องไม่รองรับ) บันทึกว่าเห็นแบบไหน

  9. ทดสอบปุ่มลบ: กดปุ่ม ลบ ใต้รูปหนึ่งรูป

    ผลที่ควรเห็น: ยังไม่ลบ เพราะฟังก์ชัน remove ยังเป็น TODO (คอมเมนต์) ไม่ได้ทำอะไร นี่คือสิ่งที่ต้องเติมในข้อถัดไป

  10. เติมฟังก์ชัน remove: แทนบรรทัดคอมเมนต์ TODO ด้วยบรรทัดนี้ (สร้างอาเรย์ใหม่ที่ไม่มีรูปนั้น ตามหลักของใบงาน 3.2)

    ไฟล์ src/pages/Gallery.tsx
    setPhotos(photos.filter(p => p !== src));
    ผลที่ควรเห็น: กดลบแล้วรูปนั้นหาย หัวข้อลดลง 1 และเมื่อลบหมด ขึ้น ยังไม่มีรูป กดปุ่มด้านบนเพื่อเพิ่ม

  11. จำกัดจำนวนรูป ขั้นแรก ปิดปุ่ม ถ่ายภาพ เมื่อมีครบ 6 รูป แก้บรรทัดของปุ่มถ่ายภาพตามนี้

    ไฟล์ src/pages/Gallery.tsx
    <IonButton onClick={take} disabled={photos.length >= 6}>ถ่ายภาพ</IonButton>
    ผลที่ควรเห็น: ยังเหมือนเดิมจนกว่าจะมี 6 รูป

  12. ขั้นที่สอง ปิดปุ่ม เลือกจากคลังภาพ ด้วยเงื่อนไขเดียวกัน

    ไฟล์ src/pages/Gallery.tsx
    <IonButton fill="outline" onClick={pick} disabled={photos.length >= 6}>เลือกจากคลังภาพ</IonButton>
    ผลที่ควรเห็น: ยังเหมือนเดิมจนกว่าจะมี 6 รูป

  13. ขั้นที่สาม แสดงข้อความเมื่อเต็ม: เพิ่มบรรทัดนี้ใต้บรรทัด {message && <p>{message}</p>}

    ไฟล์ src/pages/Gallery.tsx
    {photos.length >= 6 && <p>ครบ 6 รูปแล้ว ลบรูปก่อนเพิ่ม</p>}
    ผลที่ควรเห็น: เลือกรูปจนครบ 6 รูป ปุ่มทั้งสองจางกดไม่ได้ และมีข้อความ ครบ 6 รูปแล้ว ลบรูปก่อนเพิ่ม ลบ 1 รูปแล้วปุ่มกลับมากดได้

  14. ทำตารางสรุป 4 แถวในไฟล์ Word: ความสามารถของ Camera ที่ใช้ได้บนเว็บ / ที่ใช้ได้เฉพาะบนอุปกรณ์ (อ่านจากเอกสาร Camera API ของ Capacitor หัวข้อ Web) / ผลที่ทดสอบบนเว็บของคุณ / สิ่งที่ต้องทดสอบบนอุปกรณ์จริง

    ผลที่ควรเห็น: ตาราง 4 แถวที่ระบุอย่างน้อย 2 ความสามารถที่เว็บไม่รองรับ (เช่น การบันทึกวิดีโอ)

  15. ถ่ายภาพหน้าจอ 3 ภาพ: ไม่มีรูป มีรูป และกรณียกเลิก แล้วส่งงานขึ้น GitHub

    git add .
git commit -m "5.2 camera gallery"
git push
    ผลที่ควรเห็น: ได้ภาพ 3 ภาพ และขึ้น Writing objects ... done

คำแนะนำ

  • ถ้าพบบทความเก่าใช้ Camera.getPhoto อย่านำมาใช้ เพราะถูกประกาศเลิกใช้ ให้ใช้ takePhoto และ chooseFromGallery
  • รูปที่ได้จาก webPath แสดงได้ แต่หายเมื่อรีเฟรช จนกว่าจะบันทึกไฟล์ (หน่วยที่ 6)
  • ถ่ายภาพบนมือถือผ่านเบราว์เซอร์ต้องเป็น HTTPS ถ้าจะทดสอบบนมือถือ ให้เผยแพร่เว็บแบบ HTTPS (หน่วยที่ 9) หรือสร้างแอป Android

สิ่งที่ต้องส่ง

ภาพหน้าจอ 3 ภาพ (ไม่มีรูป มีรูป และกรณียกเลิก) + ตารางสรุป 4 แถว + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
