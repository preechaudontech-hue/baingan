จุดประสงค์

สร้างหน้ารายการงานที่เพิ่ม ลบ ติ๊กเสร็จ และนับงานคงเหลือได้ โดยใช้ useState ช่องกรอกแบบ controlled และ map

คำชี้แจง

ใบงานนี้สร้างหน้ารายการงานทีละขั้น ทุกขั้นวางโค้ดทั้งไฟล์ลงใน src/pages/Home.tsx (ลบของเดิมก่อนทุกครั้งด้วย Ctrl+A แล้ว Delete) แล้วดูผลบนเบราว์เซอร์ จากนั้นอ่านและทดลองแก้ตามคำสั่ง ต้องรัน ionic serve ค้างไว้ตลอด

สิ่งที่ต้องเตรียม

  • โปรเจกต์ myFirstApp จากใบงาน 1.1 และ ionic serve ที่รันอยู่
  • ใบความรู้ที่ 3 หัวข้อ useState และช่องกรอก

ขั้นตอนการปฏิบัติ

  1. เตรียมความพร้อม: เปิด VS Code ที่โปรเจกต์ myFirstApp เปิดเทอร์มินัล พิมพ์ ionic serve เปิดหน้าเว็บใน Chrome (โหมดจำลองมือถือ) แล้วเปิดไฟล์ src/pages/Home.tsx

    ผลที่ควรเห็น: เห็นหน้าแอปบนเบราว์เซอร์ และเห็นไฟล์ Home.tsx ใน VS Code

  2. ขั้นที่ 1: ลบโค้ดเดิมทั้งหมดใน Home.tsx (Ctrl+A แล้ว Delete) แล้ววางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { IonContent, IonPage } from '@ionic/react';

const Home: React.FC = () => {
  const tasks = [
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ];

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน</h2>
        <ul>
          {tasks.map(t => (
            <li key={t.id}>{t.title}</li>
          ))}
        </ul>
      </IonContent>
    </IonPage>
  );

    ผลที่ควรเห็น: หน้าจอมีหัวข้อ รายการงาน และรายการ 2 บรรทัด: อ่านใบความรู้, ทำใบงาน

  3. อ่านโค้ดขั้นที่ 1: ดูบรรทัด const tasks = [ ... ] แล้วเขียนในช่องบันทึกว่า tasks คืออะไร และ tasks.map(t => ( ... )) ทำอะไร (คำใบ้: ใบความรู้ที่ 3 หัวข้อ JSX และ key)

    ผลที่ควรเห็น: ตอบได้ว่า tasks เป็นอาเรย์ของออบเจ็กต์งาน และ map วนสร้าง <li> หนึ่งอันต่อหนึ่งงาน key ใช้ให้ React แยกแต่ละแถวออกจากกัน

  4. ทดลอง: เพิ่มงานใหม่ในอาเรย์ tasks อีกหนึ่งรายการด้วยมือ ให้ต่อจากบรรทัด { id: 2, ... }, เช่น { id: 3, title: 'ส่งงาน', done: false }, แล้วกด Ctrl+S

    ผลที่ควรเห็น: หน้าจอมีรายการที่ 3 ชื่อ ส่งงาน (ลบรายการที่เพิ่มออกหลังดูผลแล้วก็ได้)

  5. ขั้นที่ 2: ลบโค้ดเดิมทั้งหมดแล้ววางโค้ดนี้ ขั้นนี้เปลี่ยนจากตัวแปรธรรมดาเป็น useState และเพิ่มกล่องติ๊ก กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonContent, IonPage } from '@ionic/react';

interface Task { id: number; title: string; done: boolean }

const Home: React.FC = () => {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ]);

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน</h2>
        <ul>
          {tasks.map(t => (
            <li key={t.id}>
              <input type="checkbox" checked={t.done} onChange={() => toggle(t.id)} />
              <span style={{ textDecoration: t.done ? 'line-through' : 'none' }}>{t.title}</span>
            </li>
          ))}
        </ul>
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: แต่ละรายการมีกล่องติ๊ก อ่านใบความรู้ ถูกติ๊กไว้และมีเส้นขีดฆ่าทับชื่อ ส่วน ทำใบงาน ยังไม่ติ๊ก

  6. คลิกกล่องติ๊กของ ทำใบงาน แล้วคลิกอีกครั้ง

    ผลที่ควรเห็น: คลิกแล้วมีเครื่องหมายถูกและเส้นขีดฆ่า คลิกซ้ำแล้วกลับเป็นเหมือนเดิม

  7. อ่านฟังก์ชัน toggle ในโค้ด: บรรทัด setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t))); เขียนในช่องบันทึกด้วยคำพูดของตนเองว่ามันทำอะไร (คำใบ้: map สร้างอาเรย์ใหม่ { ...t, done: !t.done } คือสำเนาของงานนั้นที่กลับค่า done)

    ผลที่ควรเห็น: อธิบายได้ว่าสร้างอาเรย์ใหม่ที่งานที่ id ตรงกันถูกสลับค่า done ส่วนงานอื่นเหมือนเดิม แล้วส่งให้ setTasks เพื่อให้หน้าจอวาดใหม่

  8. ขั้นที่ 3: ลบโค้ดเดิมทั้งหมดแล้ววางโค้ดนี้ ขั้นนี้เพิ่มช่องกรอกและปุ่มเพิ่ม กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonContent, IonPage } from '@ionic/react';

interface Task { id: number; title: string; done: boolean }

let nextId = 3;

const Home: React.FC = () => {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ]);
  const [newTitle, setNewTitle] = useState('');

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function add() {
    const title = newTitle.trim();
    if (title === '') return;
    setTasks([...tasks, { id: nextId++, title, done: false }]);
    setNewTitle('');
  }

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน</h2>

        <input value={newTitle} onChange={e => setNewTitle(e.target.value)} placeholder="งานใหม่" />
        <button onClick={add}>เพิ่ม</button>

        <ul>
          {tasks.map(t => (
            <li key={t.id}>
              <input type="checkbox" checked={t.done} onChange={() => toggle(t.id)} />
              <span style={{ textDecoration: t.done ? 'line-through' : 'none' }}>{t.title}</span>
            </li>
          ))}
        </ul>
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: ด้านบนรายการมีช่องกรอก (ข้อความจาง ๆ ว่า งานใหม่) และปุ่ม เพิ่ม

  9. ทดสอบ: พิมพ์คำว่า ซื้อสมุด ในช่องกรอก แล้วกดปุ่ม เพิ่ม

    ผลที่ควรเห็น: มีรายการ ซื้อสมุด เพิ่มท้ายรายการ (มีกล่องติ๊ก) และช่องกรอกว่างเปล่า

  10. ทดสอบกรณีผิดปกติ: กดปุ่ม เพิ่ม ตอนช่องกรอกว่าง และอีกครั้งตอนพิมพ์แต่เว้นวรรค (กด Spacebar 3 ครั้ง)

    ผลที่ควรเห็น: ไม่มีรายการใหม่เกิดขึ้นทั้งสองกรณี (เพราะโค้ดตรวจ trim ว่างแล้ว return)

  11. อ่านฟังก์ชัน add: เขียนในช่องบันทึกว่าบรรทัด setTasks([...tasks, { id: nextId++, title, done: false }]); ต่างจาก tasks.push(...) อย่างไร และเหตุใดต้องทำแบบแรก (ใบความรู้หัวข้อ useState)

    ผลที่ควรเห็น: อธิบายได้ว่าแบบแรกสร้างอาเรย์ใหม่ที่มีงานใหม่ต่อท้าย ส่วน push แก้อาเรย์เดิม ทำให้ React ไม่รู้ว่าข้อมูลเปลี่ยน หน้าจอไม่อัปเดต

  12. ขั้นที่ 4: ลบโค้ดเดิมทั้งหมดแล้ววางโค้ดนี้ ขั้นนี้เพิ่มปุ่มลบ จำนวนงานที่เหลือ และข้อความเมื่อไม่มีงาน กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonContent, IonPage } from '@ionic/react';

interface Task { id: number; title: string; done: boolean }

let nextId = 3;

const Home: React.FC = () => {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ]);
  const [newTitle, setNewTitle] = useState('');

  // ค่าที่คำนวณได้จาก tasks ไม่ต้องเก็บเป็น state เพิ่ม
  const remaining = tasks.filter(t => !t.done).length;

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function add() {
    const title = newTitle.trim();
    if (title === '') return;
    setTasks([...tasks, { id: nextId++, title, done: false }]);
    setNewTitle('');
  }

  function remove(id: number) {
    setTasks(tasks.filter(t => t.id !== id));
  }

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน ({remaining} ที่ยังไม่เสร็จ)</h2>

        <input value={newTitle} onChange={e => setNewTitle(e.target.value)} placeholder="งานใหม่" />
        <button disabled={newTitle.trim() === ''} onClick={add}>เพิ่ม</button>

        {tasks.length === 0 ? (
          <p>ยังไม่มีงาน</p>
        ) : (
          <ul>
            {tasks.map(t => (
              <li key={t.id}>
                <input type="checkbox" checked={t.done} onChange={() => toggle(t.id)} />
                <span style={{ textDecoration: t.done ? 'line-through' : 'none' }}>{t.title}</span>
                <button onClick={() => remove(t.id)}>ลบ</button>
              </li>
            ))}
          </ul>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: หัวข้อเปลี่ยนเป็น รายการงาน (1 ที่ยังไม่เสร็จ) แต่ละรายการมีปุ่ม ลบ และปุ่ม เพิ่ม จางกดไม่ได้เมื่อช่องกรอกว่าง

  13. ทดสอบจำนวนงานที่เหลือ: ติ๊กกล่องของ ทำใบงาน แล้วเอาเครื่องหมายถูกออก

    ผลที่ควรเห็น: ตัวเลขในหัวข้อเปลี่ยนจาก 1 เป็น 0 แล้วกลับเป็น 1 ตามการติ๊ก

  14. ทดสอบการลบ: กดปุ่ม ลบ ทีละรายการจนหมด

    ผลที่ควรเห็น: เมื่อไม่เหลือรายการ ขึ้นข้อความ ยังไม่มีงาน และหัวข้อเป็น (0 ที่ยังไม่เสร็จ)

  15. ทดสอบการเพิ่มซ้ำ: เพิ่มงานชื่อเดียวกันสองครั้ง เช่น อ่านหนังสือ แล้วลบอันแรก

    ผลที่ควรเห็น: ทั้งสองรายการแสดงได้ ลบอันแรกแล้วอันที่สองยังอยู่ (เพราะแต่ละรายการมี id ไม่ซ้ำกัน)

  16. ใช้ console.log ดูข้อมูล: ในฟังก์ชัน add เพิ่มบรรทัด console.log(tasks); ก่อนบรรทัด setTasks แล้วกด Ctrl+S กด F12 เปิดแท็บ Console แล้วเพิ่มงาน 2 ครั้ง ถ่ายภาพ

    ผลที่ควรเห็น: ใน Console เห็นอาเรย์ของงานที่ยังไม่รวมงานที่เพิ่งเพิ่ม (เพราะ tasks ยังเป็นค่าเก่า ณ ตอนนั้น) ลบบรรทัด console.log ออกหลังถ่ายภาพ

  17. ท้าทาย (ลองเองก่อนดูคำใบ้): เพิ่มตัวกรอง 3 ปุ่ม ทั้งหมด / ยังไม่เสร็จ / เสร็จแล้ว ใช้ state ชนิด union และกรองรายการก่อน map ตามคำใบ้นี้ แล้วเพิ่มปุ่มสามปุ่มที่เรียก setFilter('all'), setFilter('todo'), setFilter('done')

    type Filter = 'all' | 'todo' | 'done';
const [filter, setFilter] = useState<Filter>('all');
const visible = tasks.filter(t => filter === 'all' || (filter === 'todo' ? !t.done : t.done));
// แล้วเปลี่ยน tasks.map(...) ในรายการเป็น visible.map(...)
    ผลที่ควรเห็น: กดปุ่ม ยังไม่เสร็จ แสดงเฉพาะงานที่ยังไม่ติ๊ก กด เสร็จแล้ว แสดงเฉพาะงานที่ติ๊ก กด ทั้งหมด แสดงทุกงาน

  18. ทดสอบกรณีขอบเขต 3 ข้อ แล้วบันทึกพฤติกรรมที่พบในช่องบันทึก: (1) ชื่องานยาวมาก (พิมพ์ 80 ตัวอักษร) (2) ลบงานทุกรายการแล้วเพิ่มใหม่ (3) เพิ่มงานเมื่อติ๊กตัวกรองเป็น เสร็จแล้ว ว่างานใหม่ปรากฏหรือไม่ เพราะอะไร

    ผลที่ควรเห็น: บันทึกพฤติกรรมได้ 3 ข้อ (เช่น ชื่อยาวขึ้นบรรทัดใหม่ งานใหม่ไม่ปรากฏเพราะยังไม่ติ๊กเสร็จ)

  19. ส่งงานขึ้น GitHub: เปิดเทอร์มินัลใหม่ (ปุ่ม +) แล้วพิมพ์ทีละบรรทัด

คำแนะนำ

  • ห้ามใช้ tasks.push(...) ให้ใช้ setTasks([...tasks, ...]) เสมอ
  • ถ้าหน้าขาวหลังวางโค้ด ให้ดูแท็บ Console (F12) จะมีข้อความสีแดงบอกบรรทัดที่ผิด และตรวจว่าวางโค้ดครบทั้งไฟล์
