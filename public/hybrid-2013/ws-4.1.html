ใบงานที่ 4.1 จัดวางหน้าหลักด้วย Ionic ตามแบบร่าง

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

สร้างหน้าหลักของแอปตนเองตามแบบร่าง ด้วยคอมโพเนนต์ Ionic IonGrid และธีมสีที่กำหนดเอง

คำชี้แจง

นำ wireframe หน้าหลักของแอปตนเองจากใบงาน 2.4 มาสร้างเป็นหน้าจอจริงในโปรเจกต์ Ionic React โดยยังใช้ข้อมูลตัวอย่างที่เขียนไว้ในโค้ดได้

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 2.4 (wireframe หน้าหลัก)
  • ใบความรู้ที่ 4 หัวข้อโครงหน้า Grid และธีมสี
  • โปรเจกต์ Ionic React ที่รัน ionic serve อยู่

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
import {
  IonCard, IonCardContent, IonCardHeader, IonCardSubtitle, IonCardTitle, IonCol, IonContent, IonFab,
  IonFabButton, IonGrid, IonHeader, IonIcon, IonPage, IonRow, IonTitle, IonToolbar,
} from '@ionic/react';
import { add } from 'ionicons/icons';

interface Item { id: number; title: string; category: string; amount: number }

// TODO: เปลี่ยนเป็นข้อมูลตัวอย่างของแอปตนเอง
const ITEMS: Item[] = [
  { id: 1, title: 'ข้าวกลางวัน', category: 'อาหาร', amount: 60 },
  { id: 2, title: 'ค่ารถ', category: 'เดินทาง', amount: 40 },
  { id: 3, title: 'ซื้อสมุด', category: 'การเรียน', amount: 85 },
  { id: 4, title: 'ชานมไข่มุก', category: 'อาหาร', amount: 55 },
];

const Home: React.FC = () => {
  const total = ITEMS.reduce((sum, i) => sum + i.amount, 0);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>ชื่อแอปของฉัน</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <IonCard>
          <IonCardHeader>
            <IonCardSubtitle>ยอดรวมเดือนนี้</IonCardSubtitle>
            <IonCardTitle>{total} บาท</IonCardTitle>
          </IonCardHeader>
        </IonCard>

        <IonGrid>
          <IonRow>
            {ITEMS.map(i => (
              <IonCol size="6" key={i.id}>
                <IonCard>
                  <IonCardHeader>
                    <IonCardSubtitle>{i.category}</IonCardSubtitle>
                    <IonCardTitle>{i.title}</IonCardTitle>
                  </IonCardHeader>
                  <IonCardContent>{i.amount} บาท</IonCardContent>
                </IonCard>
              </IonCol>
            ))}
          </IonRow>
        </IonGrid>

        <IonFab slot="fixed" vertical="bottom" horizontal="end">
          <IonFabButton>
            <IonIcon icon={add} />
          </IonFabButton>
        </IonFab>
      </IonContent>
    </IonPage>
  );
};

export default Home;

ขั้นตอนการปฏิบัติ

  1. วางโค้ดตั้งต้นลงในไฟล์ src/pages/Home.tsx แล้วดูผลในโหมดจำลองอุปกรณ์ของ Chrome

  2. เปลี่ยนชื่อแอปและข้อมูลตัวอย่างให้ตรงกับแอปของตนเองตาม wireframe (ข้อมูลอย่างน้อย 4 รายการ)

  3. กำหนดสีหลักของแอปตนเองในไฟล์ src/theme/variables.css (แก้ตัวแปรของ primary ให้ครบทั้ง 6 ตัว ใช้ Color Generator ของ Ionic ช่วย) แล้วดูว่าแถบหัวและปุ่มเปลี่ยนสีตาม

  4. ปรับการจัดวางให้ตรงแบบร่าง เช่น เปลี่ยนจาก 2 คอลัมน์เป็น 1 คอลัมน์ (size="12") หรือเพิ่มส่วนสรุป ใช้ IonGrid อย่างน้อย 1 ที่ และใช้ Flexbox ในไฟล์ Home.css อย่างน้อย 1 ที่

  5. แยกการ์ดหนึ่งใบออกเป็นคอมโพเนนต์ src/components/ItemCard.tsx ที่รับ props (อย่างน้อย 2 props) แล้วใช้ในหน้า Home

  6. ทดสอบในโหมดจำลองอุปกรณ์อย่างน้อย 2 ขนาด และทดสอบโหมดมืด (เปลี่ยนที่การตั้งค่าของระบบหรือ DevTools) ถ่ายภาพทุกกรณี

  7. เปรียบเทียบผลกับ wireframe เขียนความแตกต่าง 2 ข้อและวิธีปรับ

คำแนะนำ

  • ถ้าสีไม่เปลี่ยน ให้ตรวจว่าแก้ในไฟล์ variables.css และบันทึกแล้ว และชื่อตัวแปรสะกดถูก
  • ถ้าหน้าขาวหรือมีข้อความแดง ให้ดูข้อความผิดพลาดในเทอร์มินัลที่รัน ionic serve และใน Console ของ DevTools
  • ไอคอนอยู่ในแพ็กเกจ ionicons ค้นหาชื่อได้ที่ ionic.io/ionicons แล้ว import ชื่อนั้นจาก 'ionicons/icons'

สิ่งที่ต้องส่ง

ลิงก์ GitHub + ภาพหน้าจอ (2 ขนาด + โหมดมืด) + ภาพ wireframe หน้าหลักเทียบกับผลจริง + บันทึกความแตกต่างและการปรับ (ส่งตามช่องทางที่ครูกำหนด)
