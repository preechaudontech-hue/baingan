ใบงานที่ 1.1 ติดตั้งเครื่องมือและรันโปรเจกต์ Ionic React แรก

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

ติดตั้งเครื่องมือพัฒนา สร้างโปรเจกต์ Ionic React และรันดูผลบนเบราว์เซอร์ได้

คำชี้แจง

ใบงานนี้พาทำทีละขั้นตั้งแต่ติดตั้งเครื่องมือจนเห็นแอปแรกบนเบราว์เซอร์ ทุกข้อมีช่อง "ผลที่ควรเห็น" ให้เทียบกับหน้าจอของตนเอง ถ้าผลไม่ตรง ให้หยุดและแจ้งครูก่อนทำข้อถัดไป

สิ่งที่ต้องเตรียม

  • เครื่องคอมพิวเตอร์ที่ติดตั้งโปรแกรมได้และต่ออินเทอร์เน็ต
  • บัญชี GitHub ของตนเอง

ขั้นตอนการปฏิบัติ

  1. ติดตั้ง Node.js: เปิดเบราว์เซอร์ไปที่ nodejs.org กดดาวน์โหลดรุ่น LTS (ต้องเป็นเลข 22 ขึ้นไป) ดับเบิลคลิกไฟล์ที่ได้ แล้วกด Next ไปเรื่อย ๆ โดยใช้ค่าเริ่มต้นทั้งหมดจนกด Finish

    ผลที่ควรเห็น: หน้าต่างติดตั้งแจ้งว่าติดตั้งเสร็จแล้ว (ถ้าเครื่องห้องเรียนติดตั้งโปรแกรมไม่ได้ ให้แจ้งครู)

  2. เปิดโปรแกรม Visual Studio Code (ถ้ายังไม่มี ให้ติดตั้งจาก code.visualstudio.com)

    ผลที่ควรเห็น: เห็นหน้าต่าง VS Code

  3. เปิดเทอร์มินัลใน VS Code: คลิกเมนู Terminal ด้านบน แล้วเลือก New Terminal

    ผลที่ควรเห็น: มีแผงสีเข้มโผล่ด้านล่าง มีข้อความที่ลงท้ายด้วย > และมีเครื่องหมายกะพริบรอรับคำสั่ง

  4. พิมพ์คำสั่งนี้ในเทอร์มินัล แล้วกด Enter

    node --version
    ผลที่ควรเห็น: ขึ้นเลขเวอร์ชัน เช่น v22.14.0 หรือ v24.x.x (ต้องขึ้นต้นด้วย v22 ขึ้นไป) ถ้าขึ้นว่า 'node' is not recognized ให้ปิด VS Code แล้วเปิดใหม่ แล้วลองอีกครั้ง

  5. พิมพ์คำสั่งนี้ แล้วกด Enter

    npm --version
    ผลที่ควรเห็น: ขึ้นเลขเวอร์ชัน เช่น 10.x.x หรือ 11.x.x

  6. ไปยังโฟลเดอร์ที่จะเก็บงาน พิมพ์คำสั่งนี้ แล้วกด Enter (ถ้าชื่อผู้ใช้ของเครื่องมีภาษาไทยหรือช่องว่าง ให้ใช้ mkdir C:\work แล้ว cd C:\work แทน)

    cd ~/Documents
    ผลที่ควรเห็น: ข้อความหน้าเครื่องหมาย > เปลี่ยนเป็นที่อยู่ที่ลงท้ายด้วย Documents (หรือ work)

  7. ติดตั้งเครื่องมือ Ionic: พิมพ์คำสั่งนี้ แล้วกด Enter จากนั้นรอ (ใช้เวลา 1 - 2 นาที ห้ามปิดหน้าต่าง)

    npm install -g @ionic/cli
    ผลที่ควรเห็น: จบด้วยข้อความ added ... packages in ... วินาที ข้อความสีเหลืองขึ้นต้นด้วย npm warn ไม่ใช่ปัญหา

  8. ตรวจว่าติดตั้งสำเร็จ พิมพ์คำสั่งนี้

    ionic --version
    ผลที่ควรเห็น: ขึ้นเลขเวอร์ชัน เช่น 7.x.x ถ้าขึ้นว่า 'ionic' is not recognized ให้ปิดเทอร์มินัลแล้วเปิดใหม่ (Terminal > New Terminal) แล้วลองใหม่

  9. สร้างโปรเจกต์ใหม่ พิมพ์คำสั่งนี้ แล้วกด Enter (ใช้เวลาหลายนาที เพราะต้องดาวน์โหลดแพ็กเกจ ห้ามปิด) ถ้ามีคำถามว่าจะสร้างบัญชี Ionic ไหม ให้พิมพ์ n แล้วกด Enter

    ionic start myFirstApp blank --type=react
    ผลที่ควรเห็น: จบด้วยข้อความ Your Ionic app is ready! และรายการ next steps

  10. เข้าไปในโฟลเดอร์ของโปรเจกต์ พิมพ์คำสั่งนี้

    cd myFirstApp
    ผลที่ควรเห็น: ข้อความหน้าเครื่องหมาย > ลงท้ายด้วย myFirstApp

  11. เปิดเซิร์ฟเวอร์สำหรับดูผล พิมพ์คำสั่งนี้ แล้วกด Enter (เทอร์มินัลนี้จะค้างไว้ตลอดเวลาที่ดูแอป ห้ามกดปิด)

    ionic serve
    ผลที่ควรเห็น: ขึ้น [INFO] Development server running! และบรรทัด Local: http://localhost:ตัวเลข (เช่น 8100 หรือ 5173) เบราว์เซอร์อาจเปิดขึ้นมาเอง

  12. เปิด Google Chrome แล้วพิมพ์ที่อยู่ที่ขึ้นในบรรทัด Local: ลงในช่องที่อยู่ (หรือกด Ctrl ค้างแล้วคลิกลิงก์ในเทอร์มินัล)

    ผลที่ควรเห็น: เห็นหน้าเว็บมีแถบหัวเขียนว่า Blank และข้อความ Ready to create an app? ตรงกลาง

  13. จำลองหน้าจอมือถือ: กด F12 แล้วกดปุ่มไอคอนรูปมือถือกับแท็บเล็ต (Toggle device toolbar) หรือกด Ctrl+Shift+M

    ผลที่ควรเห็น: หน้าแอปแคบลงเป็นรูปทรงมือถือ มีแถบเลือกรุ่นอุปกรณ์ด้านบน

  14. ที่แถบด้านบน เลือกรุ่น iPhone 12 Pro (หรือรุ่นใดก็ได้) แล้วถ่ายภาพหน้าจอเก็บไว้ จากนั้นเปลี่ยนเป็นรุ่นอื่นอีกรุ่นแล้วถ่ายภาพอีกครั้ง

    ผลที่ควรเห็น: ขนาดหน้าแอปเปลี่ยนตามรุ่นที่เลือก ได้ภาพหน้าจอ 2 รุ่น

  15. กลับไปที่ VS Code เปิดโปรเจกต์: เมนู File แล้วเลือก Open Folder เลือกโฟลเดอร์ myFirstApp แล้วกด Select Folder (ถ้ามีคำถามว่าไว้ใจผู้เขียนไฟล์ไหม ให้กด Yes)

    ผลที่ควรเห็น: แผงซ้ายมือแสดงรายการไฟล์ เช่น src, public, package.json

  16. ที่แผงซ้ายมือ คลิกเปิดโฟลเดอร์ src แล้วเปิด pages แล้วดับเบิลคลิกไฟล์ Home.tsx

    ผลที่ควรเห็น: เห็นโค้ดที่มีคำว่า IonPage และมี <IonTitle>Blank</IonTitle>

  17. แก้ข้อความบนแถบหัว: หาบรรทัด <IonTitle>Blank</IonTitle> (มี 2 ที่ ให้แก้ทั้งสองที่) เปลี่ยนคำว่า Blank เป็นชื่อของคุณ เช่น <IonTitle>สมชาย</IonTitle> แล้วกด Ctrl+S เพื่อบันทึก

    ผลที่ควรเห็น: ไม่ต้องกด F5 หน้าเว็บในเบราว์เซอร์รีเฟรชเอง แถบหัวเปลี่ยนเป็นชื่อของคุณ

  18. ถ่ายภาพหน้าจอเบราว์เซอร์ให้เห็นชื่อของคุณบนแถบหัว (นี่คือภาพ "หลังแก้" ส่วนภาพ "ก่อนแก้" คือภาพที่ถ่ายไว้ในข้อ 14 ซึ่งแถบหัวเขียนว่า Blank)

    ผลที่ควรเห็น: มีภาพก่อนและหลังแก้ข้อความ

  19. สำรวจโครงสร้างโปรเจกต์ ข้อ 1: เปิดไฟล์ src/main.tsx แล้วหาบรรทัดที่เขียนว่า <App /> จากนั้นเขียนในช่องบันทึกว่าไฟล์นี้ทำอะไร (ใบความรู้ที่ 1 ตารางโครงสร้างโปรเจกต์ช่วยตอบได้)

    ผลที่ควรเห็น: เห็นบรรทัด root.render(...) ที่เรียก <App />

  20. สำรวจข้อ 2: เปิดไฟล์ src/App.tsx หาบรรทัดที่มี Route path="/home" แล้วเขียนในช่องบันทึกว่า ที่อยู่ (URL) ใดเปิดหน้า Home และหน้า Home อยู่ในไฟล์ไหน

    ผลที่ควรเห็น: เห็น <Route path="/home" element={<Home />} /> แปลว่าที่อยู่ /home แสดงหน้า Home

  21. สำรวจข้อ 3: เปิดไฟล์ package.json หาหัวข้อ "scripts" แล้วจดคำสั่ง (ชื่อ dev และ build) พร้อมเขียนว่าแต่ละอันใช้ทำอะไรตามที่เข้าใจ

    ผลที่ควรเห็น: เห็นรายการ scripts เช่น dev, build, preview, test:unit

  22. สร้างที่เก็บบน GitHub: เปิดเบราว์เซอร์ไปที่ github.com เข้าสู่ระบบ กดปุ่ม New (หรือ + แล้ว New repository) ตั้งชื่อ ionic-first-app เลือก Public แล้วกด Create repository (ไม่ต้องติ๊กเพิ่มไฟล์ README)

    ผลที่ควรเห็น: ได้หน้าที่เก็บว่างที่แสดงคำสั่งให้ push โค้ดเดิม และมีที่อยู่ที่เก็บ (URL) ที่ลงท้ายด้วย .git

  23. กลับ VS Code กดเครื่องหมาย + ที่แผงเทอร์มินัลเพื่อเปิดเทอร์มินัลใหม่ (เทอร์มินัลเดิมที่รัน ionic serve ปล่อยไว้) แล้วพิมพ์คำสั่งนี้ตรวจว่าโฟลเดอร์เป็นที่เก็บ Git แล้วหรือยัง

    git status
    ผลที่ควรเห็น: ถ้าขึ้นรายการไฟล์ แสดงว่าพร้อมแล้ว ถ้าขึ้น fatal: not a git repository ให้พิมพ์ git init แล้ว Enter ก่อนทำข้อถัดไป

  24. บันทึกการเปลี่ยนแปลง พิมพ์ทีละบรรทัด กด Enter ทุกบรรทัด

    git add .
git commit -m "first ionic app"
git branch -M main
    ผลที่ควรเห็น: บรรทัด git commit ขึ้นจำนวนไฟล์ที่บันทึก (ถ้าขึ้นให้ตั้งชื่อและอีเมลผู้ใช้ Git ให้ทำตามข้อความที่แสดง แล้วพิมพ์ git commit อีกครั้ง)

  25. ส่งขึ้น GitHub: พิมพ์คำสั่งนี้โดยเปลี่ยนที่อยู่ให้เป็นที่อยู่ที่เก็บของคุณ (คัดลอกจากหน้า GitHub ในข้อ 22) แล้ว Enter ทีละบรรทัด

    git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/ionic-first-app.git
git push -u origin main
    ผลที่ควรเห็น: ขึ้นข้อความ Writing objects ... done และ branch 'main' set up to track ... (ถ้าเบราว์เซอร์เปิดให้ยืนยันตัวตน GitHub ให้ทำตามขั้นตอน)

  26. รีเฟรชหน้าที่เก็บบน GitHub ในเบราว์เซอร์ แล้วคัดลอกที่อยู่ (URL) ของหน้านั้นไว้ส่งครู

    ผลที่ควรเห็น: เห็นไฟล์ของโปรเจกต์บน GitHub เช่น src, package.json และมีข้อความ first ionic app

คำแนะนำ

  • ถ้าเทอร์มินัลค้างนานมากตอนติดตั้ง ให้รอก่อนอย่างน้อย 5 นาที ห้ามกดปิดหรือกด Ctrl+C
  • เทอร์มินัลที่รัน ionic serve ห้ามปิดระหว่างดูแอป ถ้าต้องพิมพ์คำสั่งอื่น ให้เปิดเทอร์มินัลใหม่ด้วยปุ่ม +
  • ถ้าทำข้อใดแล้วผลไม่ตรงกับ "ผลที่ควรเห็น" ให้ถ่ายภาพหน้าจอข้อความผิดพลาดทั้งหมดแล้วถามครู ไม่ต้องลองสุ่ม

สิ่งที่ต้องส่ง

ภาพผลลัพธ์ node/ionic version + ภาพแอปในโหมดจำลองอุปกรณ์ 2 รุ่น + ภาพก่อน-หลังแก้ข้อความ + คำตอบ 3 ข้อ + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
