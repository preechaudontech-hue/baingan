ใบงานที่ 1.1 ติดตั้งเครื่องมือและรันโปรเจกต์ Ionic React แรก

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

ติดตั้งเครื่องมือพัฒนา สร้างโปรเจกต์ Ionic React และรันดูผลบนเบราว์เซอร์ได้

คำชี้แจง

ติดตั้งเครื่องมือตามลำดับ สร้างโปรเจกต์ชื่อ myFirstApp รันด้วย ionic serve ดูผลในโหมดจำลองอุปกรณ์ และสำรวจโครงสร้างโปรเจกต์ตามคำถามท้ายใบงาน

สิ่งที่ต้องเตรียม

  • เครื่องคอมพิวเตอร์ที่ติดตั้งโปรแกรมได้และต่ออินเทอร์เน็ต
  • บัญชี GitHub ของตนเอง

ขั้นตอนการปฏิบัติ

  1. ติดตั้ง Node.js รุ่น LTS เวอร์ชัน 22 ขึ้นไป (Capacitor ที่ใช้ในวิชานี้ต้องการเวอร์ชันนี้) และ Visual Studio Code จากเว็บทางการ แล้วเปิดเทอร์มินัลพิมพ์ node --version และ npm --version เพื่อตรวจสอบ ถ่ายภาพผลลัพธ์

  2. พิมพ์ npm install -g @ionic/cli แล้วตรวจสอบด้วย ionic --version บันทึกเลขเวอร์ชันที่ได้

  3. สร้างโปรเจกต์ด้วย ionic start myFirstApp blank --type=react ตอบคำถามที่ปรากฏ (เลือกตัวเลือกที่ไม่ต้องสมัครบัญชี) แล้วเข้าไปที่โฟลเดอร์โปรเจกต์ด้วย cd myFirstApp

  4. รัน ionic serve แล้วเปิดที่อยู่ที่แสดงในเทอร์มินัลด้วย Chrome กด F12 เปิดโหมดจำลองอุปกรณ์ เลือกขนาดหน้าจอมือถืออย่างน้อย 2 รุ่น ถ่ายภาพหน้าจอ

  5. เปิดโฟลเดอร์โปรเจกต์ใน VS Code สำรวจไฟล์ main.tsx App.tsx และ pages/Home.tsx แล้วตอบคำถามท้ายใบงานข้อ 1 - 3

  6. แก้ข้อความบนหน้า Home เป็นชื่อของตนเอง บันทึกไฟล์ และสังเกตว่าเบราว์เซอร์รีโหลดเอง ถ่ายภาพก่อนและหลังแก้

  7. สร้างที่เก็บ (repository) บน GitHub ชื่อ ionic-first-app แล้ว push โปรเจกต์ขึ้นไป ส่งลิงก์ที่เก็บ

คำแนะนำ

  • ถ้าคำสั่ง ionic ไม่พบ ให้ปิดแล้วเปิดเทอร์มินัลใหม่ หรือรีสตาร์ท VS Code เพื่อให้ระบบอ่านค่า PATH ใหม่
  • ถ้าติดตั้งแบบ global ไม่ได้เพราะสิทธิ์ผู้ใช้ ให้แจ้งครู
  • คำถามท้ายใบงาน: (1) ไฟล์ใดเป็นจุดเริ่มทำงาน (2) หน้า Home อยู่ไฟล์ใดและ URL ใดเปิดหน้านี้ (ดูใน App.tsx) (3) ไฟล์ package.json มีคำสั่ง (scripts) อะไรบ้าง

สิ่งที่ต้องส่ง

ภาพผลลัพธ์ node/ionic version + ภาพแอปในโหมดจำลองอุปกรณ์ 2 รุ่น + ภาพก่อน-หลังแก้ข้อความ + คำตอบ 3 ข้อ + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
