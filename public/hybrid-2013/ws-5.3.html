ใบงานที่ 5.3 ตรวจจับการเขย่าด้วยเซนเซอร์และการสั่น

เวลา 90 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

อ่านค่าความเร่งด้วย Motion ตรวจจับการเขย่า ให้ผลตอบสนองด้วยการสั่น และยกเลิกการรับค่าเมื่อเลิกใช้ได้

คำชี้แจง

ionic serve ต้องรันอยู่ และเปิดเบราว์เซอร์ที่ localhost (ตำแหน่งและกล้องบนเบราว์เซอร์ใช้ได้เฉพาะ localhost หรือ HTTPS เท่านั้น) ทุกขั้นที่ "วางโค้ดทั้งไฟล์" ให้ลบของเดิมก่อนด้วย Ctrl+A แล้ว Delete ใบงานนี้สร้างหน้า /shake ที่นับจำนวนครั้งที่เขย่าเครื่อง บนคอมพิวเตอร์ไม่มีเซนเซอร์ จึงทดสอบเฉพาะส่วนที่ไม่ต้องใช้เซนเซอร์ และจำลองการเขย่าด้วยคำสั่งใน Console

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 5.1 - 5.2
  • ใบความรู้ที่ 5 หัวข้อเซนเซอร์และการสั่น

ขั้นตอนการปฏิบัติ

  1. ติดตั้งปลั๊กอินเซนเซอร์และการสั่นในเทอร์มินัลใหม่

    npm install @capacitor/motion @capacitor/haptics
    ผลที่ควรเห็น: จบโดยไม่มีข้อความ ERR

  2. สร้างไฟล์ src/pages/Shake.tsx วางโค้ดนี้ทั้งไฟล์ กด Ctrl+S

    ไฟล์ src/pages/Shake.tsx
    import { useEffect, useState } from 'react';
import { IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import type { PluginListenerHandle } from '@capacitor/core';
import { Motion } from '@capacitor/motion';

const SHAKE_DELTA = 8; // ความต่างจาก 9.8 ที่ถือว่าเขย่า (ปรับตามเครื่อง)

const Shake: React.FC = () => {
  const [count, setCount] = useState(0);
  const [magnitude, setMagnitude] = useState(0);
  const [error, setError] = useState('');

  useEffect(() => {
    let handle: PluginListenerHandle | undefined;
    let cancelled = false;
    let last = 0;

    Motion.addListener('accel', e => {
      const a = e.accelerationIncludingGravity;
      const m = Math.sqrt(a.x ** 2 + a.y ** 2 + a.z ** 2);
      if (m === 0) return; // ไม่มีข้อมูลจากเซนเซอร์ (เช่น บนคอมพิวเตอร์)
      setMagnitude(m);
      const now = Date.now();
      if (Math.abs(m - 9.8) > SHAKE_DELTA && now - last > 800) {
        last = now;
        setCount(c => c + 1);
        // TODO: สั่นเบา ๆ เมื่อตรวจจับได้ ด้วย Haptics.impact({ style: ImpactStyle.Medium }) (ต้อง import เพิ่ม และห่อด้วย try/catch)
      }
    })
      .then(h => {
        if (cancelled) h.remove();
        else handle = h;
      })
      .catch(() => setError('เครื่องนี้ไม่รองรับเซนเซอร์การเคลื่อนไหว'));

    return () => {
      cancelled = true;
      handle?.remove();
    };
  }, []);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>เขย่าเครื่อง</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding ion-text-center">
        <h1>{count}</h1>
        <p>ความเร่งรวม {magnitude.toFixed(1)} m/s²</p>
        {error && <p>{error}</p>}
        {/* TODO: เพิ่มปุ่ม "รีเซ็ตตัวนับ" */}
      </IonContent>
    </IonPage>
  );
};

export default Shake;
    ผลที่ควรเห็น: ยังไม่เห็นผลบนหน้าเว็บ

  3. เพิ่มเส้นทางใน src/App.tsx คือ import Shake from './pages/Shake'; และ <Route path="/shake" element={<Shake />} /> แล้ว Ctrl+S

    ไฟล์ src/App.tsx
    import Shake from './pages/Shake';

<Route path="/shake" element={<Shake />} />
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  4. เปิดที่อยู่ /shake ในเบราว์เซอร์บนคอมพิวเตอร์

    ผลที่ควรเห็น: แถบหัว เขย่าเครื่อง ตัวเลขใหญ่ 0 และข้อความ ความเร่งรวม 0.0 m/s² (ไม่มีเซนเซอร์ ตัวนับต้องเป็น 0 ถ้าขึ้น 1 ทันที แปลว่าค่า 0 ถูกนับเป็นการเขย่า)

  5. อ่านโค้ด: หาบรรทัด if (m === 0) return; แล้วเขียนในช่องบันทึกว่าบรรทัดนี้ป้องกันอะไร (ใบความรู้ที่ 5 หัวข้อเซนเซอร์)

    ผลที่ควรเห็น: ตอบได้ว่าเบราว์เซอร์ที่ไม่มีเซนเซอร์ส่งค่า 0 มาครั้งหนึ่ง ถ้าไม่ข้ามจะนับเป็นการเขย่า

  6. จำลองการเขย่าด้วยคำสั่ง: กด F12 แท็บ Console วางคำสั่งนี้ทั้งก้อน (บรรทัดเดียว) แล้วกด Enter

    (()=>{const e=new Event('devicemotion');e.accelerationIncludingGravity={x:20,y:15,z:9.8};e.acceleration={x:20,y:15,z:0};e.rotationRate={alpha:0,beta:0,gamma:0};e.interval=16;window.dispatchEvent(e)})()
    ผลที่ควรเห็น: ตัวเลขใหญ่บนหน้าเป็น 1 และความเร่งรวมแสดงประมาณ 27 m/s² (นี่คือการเขย่า 1 ครั้งที่จำลองขึ้น)

  7. กดคำสั่งเดิมซ้ำ (กดลูกศรขึ้นแล้ว Enter) ทันที 3 ครั้งติดกัน

    ผลที่ควรเห็น: ตัวเลขเพิ่มขึ้นแค่ 1 ครั้ง (ไม่ใช่ 3) เพราะโค้ดไม่นับซ้ำภายใน 800 มิลลิวินาที (debounce) รอ 1 วินาทีแล้วกดอีกครั้ง ตัวเลขเพิ่มอีก 1

  8. ทำให้สั่นเมื่อเขย่า ขั้นแรก เพิ่มบรรทัด import ปลั๊กอินการสั่นใต้บรรทัด import { Motion } ...

    ไฟล์ src/pages/Shake.tsx
    import { Haptics, ImpactStyle } from '@capacitor/haptics';
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  9. ขั้นที่สอง แทนบรรทัดคอมเมนต์ TODO ในตัวรับค่าด้วยบรรทัดนี้ (catch ไว้เพื่อไม่ให้พังเมื่ออุปกรณ์ไม่รองรับการสั่น)

    ไฟล์ src/pages/Shake.tsx
    Haptics.impact({ style: ImpactStyle.Medium }).catch(() => undefined);
    ผลที่ควรเห็น: จำลองการเขย่าอีกครั้ง ตัวนับเพิ่มตามปกติ และไม่มีข้อความแดงใน Console แม้คอมพิวเตอร์สั่นไม่ได้

  10. เพิ่มปุ่มรีเซ็ต ขั้นแรก แก้บรรทัด import จาก @ionic/react ให้มี IonButton

    ไฟล์ src/pages/Shake.tsx
    import { IonButton, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  11. ขั้นที่สอง แทนบรรทัดคอมเมนต์ TODO ปุ่มรีเซ็ตด้วยปุ่มจริง

    ไฟล์ src/pages/Shake.tsx
    <IonButton onClick={() => setCount(0)}>รีเซ็ต</IonButton>
    ผลที่ควรเห็น: มีปุ่ม รีเซ็ต ใต้ตัวเลข จำลองเขย่าจนเลขเป็น 2 แล้วกดรีเซ็ต เลขกลับเป็น 0

  12. แสดงข้อความเมื่อไม่ได้รับค่าจากเซนเซอร์ ขั้นแรก เพิ่มตัวแปรสถานะใต้บรรทัด const [error, setError] = useState('');

    ไฟล์ src/pages/Shake.tsx
    const [received, setReceived] = useState(false);
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  13. ขั้นที่สอง ให้ตั้งเป็น true เมื่อมีค่ามา เพิ่มบรรทัดนี้ก่อนบรรทัด setMagnitude(m);

    ไฟล์ src/pages/Shake.tsx
    setReceived(true);
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  14. ขั้นที่สาม แสดงข้อความ เพิ่มบรรทัดนี้ใต้บรรทัด {error && <p>{error}</p>}

    ไฟล์ src/pages/Shake.tsx
    {!received && !error && <p>ยังไม่ได้รับค่าจากเซนเซอร์ (คอมพิวเตอร์มักไม่มีเซนเซอร์ ให้ลองบนมือถือ)</p>}
    ผลที่ควรเห็น: บนหน้า มีข้อความ ยังไม่ได้รับค่าจากเซนเซอร์ ... ตอนเปิดหน้า และหายไปหลังจำลองการเขย่าด้วยคำสั่งในข้อ 6

  15. ปรับความไว: เปลี่ยนค่า SHAKE_DELTA = 8 เป็น 20 แล้วจำลองการเขย่าด้วยคำสั่งเดิม (ความเร่งรวมประมาณ 27 ต่างจาก 9.8 ประมาณ 17) ลองอีกครั้งกับค่า 4 และ 14 บันทึกว่าตัวนับเพิ่มหรือไม่ในแต่ละค่า

    ผลที่ควรเห็น: ที่ค่า 20 ตัวนับไม่เพิ่ม (เขย่าไม่แรงพอ) ที่ค่า 4 และ 14 ตัวนับเพิ่ม ใส่ค่าไว้ในตาราง ค่า / ผลที่เห็น / ตีความว่า ความไวเป็นอย่างไร แล้วตั้งกลับเป็น 8

  16. ถ้ามีโอกาสทดสอบบนมือถือจริง (เผยแพร่เว็บแบบ HTTPS หรือสร้างแอป Android ในหน่วยที่ 9) ให้เปิดหน้า /shake เขย่าเครื่องแล้วดูตัวเลข ถ้าไม่มีโอกาส ให้เขียนว่ายังไม่ได้ทดสอบและแผนว่าจะทดสอบเมื่อใด

    ผลที่ควรเห็น: มีบันทึกผลบนมือถือ หรือบันทึกว่ายังไม่ได้ทดสอบพร้อมแผน

  17. ตอบคำถามท้ายใบงาน: เหตุใดต้องมีตัวแปร cancelled และ handle?.remove() ในฟังก์ชันที่คืนค่าจาก useEffect และเหตุใดต้องหน่วงเวลา 800 มิลลิวินาที (ใบความรู้ที่ 5)

    ผลที่ควรเห็น: ตอบได้ว่าเพื่อลบตัวรับค่าเมื่อออกจากหน้า (รวมกรณีลบก่อนที่การสมัครจะเสร็จ) และกันการนับซ้ำจากการเขย่าครั้งเดียวที่ส่งค่าเกินเกณฑ์หลายครั้ง

  18. ส่งงานขึ้น GitHub พร้อมภาพหน้าจอ (ก่อนและหลังจำลองการเขย่า)

    git add .
git commit -m "5.3 shake detection"
git push
    ผลที่ควรเห็น: ขึ้น Writing objects ... done

คำแนะนำ

  • ใน React.StrictMode ขณะพัฒนา useEffect ถูกเรียกสองครั้ง ถ้าไม่ลบตัวรับค่าเดิม จะนับการเขย่าซ้ำสองเท่า
  • การสั่นบนเว็บบนคอมพิวเตอร์ไม่ทำงาน ไม่ใช่ข้อผิดพลาดของโค้ด
  • iPhone ต้องให้สิทธิ์เข้าถึงเซนเซอร์การเคลื่อนไหวของเบราว์เซอร์ก่อน อ่านเอกสารของปลั๊กอิน Motion
