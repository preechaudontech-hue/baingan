ใบงานที่ 3.1 TypeScript: ชนิดข้อมูล interface และฟังก์ชัน

เวลา 90 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

เขียนโค้ด TypeScript ที่กำหนดชนิดข้อมูล interface และฟังก์ชัน และแก้ข้อผิดพลาดที่ตัวตรวจชนิดแจ้งได้

คำชี้แจง

ใบงานนี้ฝึก TypeScript บนเว็บ typescriptlang.org/play โดยไม่ต้องติดตั้งอะไร ทำทีละข้อและดูผลหลังทุกข้อ ข้อที่ให้ทำให้ผิดโดยตั้งใจมีไว้ให้เห็นข้อความเตือนของ TypeScript

สิ่งที่ต้องเตรียม

  • ใบความรู้ที่ 3 หัวข้อ TypeScript เบื้องต้น

ขั้นตอนการปฏิบัติ

  1. เปิดเบราว์เซอร์ ไปที่ typescriptlang.org/play

    ผลที่ควรเห็น: หน้าเว็บแบ่งสองฝั่ง ฝั่งซ้ายเป็นที่เขียนโค้ด ฝั่งขวามีแท็บหลายแท็บ เช่น .JS, Errors, Logs

  2. คลิกในช่องโค้ดฝั่งซ้าย กด Ctrl+A แล้วกด Delete เพื่อลบโค้ดตัวอย่างเดิมทั้งหมด จากนั้นวางโค้ดนี้ (กดปุ่ม "คัดลอกโค้ด" แล้วกด Ctrl+V)

    ไฟล์ ช่องโค้ดบน typescriptlang.org/play
    interface Student {
  id: number;
  name: string;
  scores: number[];
}

function average(nums: number[]): number {

const s: Student = { id: 1, name: 'สมชาย', scores: [8, 9, 10] };
console.log(s.name, average(s.scores));
    ผลที่ควรเห็น: ไม่มีเส้นหยักสีแดงใต้โค้ด

  3. กดปุ่ม Run ที่แถบด้านบนของหน้า แล้วคลิกแท็บ Logs ทางฝั่งขวา

    ผลที่ควรเห็น: ในแท็บ Logs เห็นข้อความ สมชาย 0 (ตัวเลขเป็น 0 เพราะฟังก์ชัน average ยังไม่ได้เขียน)

  4. อ่านส่วน interface Student ในบรรทัดแรก ๆ แล้วเขียนในช่องบันทึกว่า Student มีฟิลด์อะไรบ้าง แต่ละฟิลด์เป็นชนิดข้อมูลอะไร

    ผลที่ควรเห็น: เขียนได้ว่า id เป็น number, name เป็น string, scores เป็นอาเรย์ของ number (number[])

  5. ทำความเข้าใจรูปแบบของฟังก์ชัน: คัดลอกโค้ดตัวอย่างนี้ไปวางต่อท้ายโค้ดเดิมในช่องโค้ด (เว้นบรรทัดก่อน) แล้วกด Run

    // ตัวอย่างรูปแบบ (ไม่ใช่คำตอบ): หาผลรวมของอาเรย์ตัวเลข
function sum(nums: number[]): number {
  let total = 0;
  for (const n of nums) {
    total += n;
  }
  return total;
}

console.log(sum([1, 2, 3]));
    ผลที่ควรเห็น: ในแท็บ Logs มีเลข 6 เพิ่มต่อจากข้อความเดิม (ผลรวมของ 1 + 2 + 3)

  6. สังเกตตัวอย่าง sum แล้วเขียนในช่องบันทึก 3 ข้อ: (1) total เก็บอะไร (2) for (const n of nums) ทำอะไร (3) return total ส่งอะไรกลับ

    ผลที่ควรเห็น: ตอบได้ว่า total เก็บผลรวมที่สะสมไว้ for วนทีละตัวเลขในอาเรย์ และ return ส่งค่าผลรวมกลับให้ผู้เรียก

  7. แก้ฟังก์ชัน average ในโค้ดเดิมให้ถูกต้อง โดยใช้รูปแบบเดียวกับ sum แต่ตอนท้ายให้ return total หารด้วย nums.length (ลบบรรทัด return 0; เดิม และคอมเมนต์ TODO ออก) แล้วกด Run

    ผลที่ควรเห็น: แท็บ Logs ขึ้น สมชาย 9 (ค่าเฉลี่ยของ 8, 9, 10)

  8. ทดสอบกรณีอาเรย์ว่าง: เพิ่มบรรทัด console.log(average([])); ต่อท้ายโค้ด แล้วกด Run

    ผลที่ควรเห็น: ถ้าฟังก์ชันยังไม่ได้ป้องกันอาเรย์ว่าง จะเห็นคำว่า NaN (ไม่ใช่ตัวเลข เพราะหารด้วย 0)

  9. แก้ให้ปลอดภัย: ในฟังก์ชัน average เพิ่มบรรทัดแรกในฟังก์ชันเป็น if (nums.length === 0) return 0; แล้วกด Run อีกครั้ง

    ผลที่ควรเห็น: บรรทัด average([]) แสดง 0 แทน NaN และบรรทัดอื่นยังได้ค่าเดิม

  10. ทำให้เกิดข้อผิดพลาดโดยตั้งใจ ครั้งที่ 1: เพิ่มบรรทัด average('abc'); ต่อท้ายโค้ด แล้วชี้เมาส์ที่เส้นหยักสีแดง หรือดูแท็บ Errors

    ผลที่ควรเห็น: ข้อความทำนองว่า Argument of type 'string' is not assignable to parameter of type 'number[]' จดข้อความไว้ในช่องบันทึก แล้วลบบรรทัดนี้ทิ้ง

  11. ครั้งที่ 2: เปลี่ยนในบรรทัด const s: Student = ... จาก scores: [8, 9, 10] เป็น scores: 'abc' (มีเครื่องหมายคำพูด)

    ผลที่ควรเห็น: มีเส้นแดงที่ scores ข้อความทำนองว่า Type 'string' is not assignable to type 'number[]' จดไว้ แล้วแก้กลับเป็น [8, 9, 10]

  12. ครั้งที่ 3: ลบ name: 'สมชาย', ออกจากบรรทัด const s: Student = ...

    ผลที่ควรเห็น: มีเส้นแดงที่ s ข้อความทำนองว่า Property 'name' is missing in type ... but required in type 'Student' จดไว้ แล้วใส่ name: 'สมชาย' กลับคืน

  13. เพิ่มฟิลด์ที่ไม่บังคับ: ใน interface Student เพิ่มบรรทัด email?: string; ก่อนปีกกาปิด (เครื่องหมาย ? แปลว่าไม่ต้องมีก็ได้) แล้ว Run

    ผลที่ควรเห็น: ไม่มีเส้นแดง และ const s ที่ไม่มี email ยังใช้ได้ตามเดิม

  14. สร้างชนิดข้อมูลแบบเลือกได้ และฟังก์ชัน toGrade: เติมโค้ดนี้ต่อท้าย ในส่วนที่เป็น TODO ให้เติมเงื่อนไขของ B, C, D ตามเกณฑ์ในคอมเมนต์ (เลียนแบบบรรทัด if (score >= 80) return 'A';) แล้วกด Run

    type Grade = 'A' | 'B' | 'C' | 'D' | 'F';

// 80 ขึ้นไป A, 70 ขึ้นไป B, 60 ขึ้นไป C, 50 ขึ้นไป D, น้อยกว่านั้น F
function toGrade(score: number): Grade {
  if (score >= 80) return 'A';
  // TODO: เติมเงื่อนไข B, C, D ต่อจากนี้
  return 'F';
}

console.log(toGrade(85), toGrade(65), toGrade(10));
    ผลที่ควรเห็น: แท็บ Logs ขึ้น A C F สำหรับ toGrade(85), toGrade(65), toGrade(10) ตามลำดับ

  15. ลองให้ toGrade คืนค่าที่ไม่อยู่ในรายการ เช่น เปลี่ยน return 'F'; เป็น return 'Z'; ชั่วคราว

    ผลที่ควรเห็น: มีเส้นแดง ข้อความทำนองว่า Type '"Z"' is not assignable to type 'Grade' แล้วแก้กลับเป็น 'F'

  16. เขียนฟังก์ชัน best ที่หานักเรียนที่ค่าเฉลี่ยสูงสุด เติมโค้ดนี้ต่อท้าย แล้วเติมส่วน TODO ในลูป ตามคำอธิบายในคอมเมนต์ แล้วกด Run

    function best(students: Student[]): Student | undefined {
  let top: Student | undefined = undefined;
  for (const s of students) {
    // TODO: ถ้า top ยังไม่มีค่า หรือ average ของ s สูงกว่า average ของ top ให้ top = s
  }
  return top;

console.log(best([]));
    ผลที่ควรเห็น: บรรทัด best([]) แสดง undefined (ไม่มีนักเรียนจึงไม่มีผู้ชนะ)

  17. ทดสอบ best กับนักเรียน 2 คน: เพิ่มบรรทัดนี้ต่อท้าย แล้วกด Run

    console.log(best([s, { id: 2, name: 'สมหญิง', scores: [10, 10, 9] }])?.name);
    ผลที่ควรเห็น: แท็บ Logs ขึ้น สมหญิง (ค่าเฉลี่ย 9.67 สูงกว่า 9)

  18. เพิ่มนักเรียนคนที่สามให้ค่าเฉลี่ยสูงสุดเอง แล้วทดสอบอีกครั้ง ถ่ายภาพหน้าจอให้เห็นโค้ดและแท็บ Logs

    ผลที่ควรเห็น: ผลลัพธ์เป็นชื่อนักเรียนคนที่ค่าเฉลี่ยสูงสุด ได้ภาพสำหรับส่ง

  19. กดปุ่ม Share ของหน้า Playground (ด้านบน) แล้วคัดลอกลิงก์ที่ได้ไว้ส่งครู

    ผลที่ควรเห็น: ได้ลิงก์ยาวที่เปิดแล้วเห็นโค้ดของคุณ

  20. เขียน 3 บรรทัดในช่องบันทึกหรือไฟล์ Word: TypeScript ช่วยจับข้อผิดพลาดอะไรได้ที่ JavaScript ธรรมดาไม่เตือน (ใช้ 3 ข้อผิดพลาดที่ทำในข้อ 10 - 12 เป็นตัวอย่าง)

    ผลที่ควรเห็น: ได้สรุป 3 บรรทัดที่เขียนด้วยคำพูดของตนเอง

คำแนะนำ

  • ถ้าไม่มีปุ่ม Run ให้ตรวจว่าเปิดเว็บ typescriptlang.org/play ถูกหน้า (หน้าตัวอย่างเริ่มต้นต้องมีโค้ดอยู่)
  • เส้นหยักสีแดงไม่ใช่สิ่งผิดปกติ มันคือสิ่งที่ TypeScript กำลังช่วยเตือน ให้อ่านข้อความแล้วแก้ทีละจุด
  • ถ้าลืมวิธีเขียนเงื่อนไข ให้ดูบรรทัด if (score >= 80) return 'A'; เป็นแบบ แล้วเปลี่ยนตัวเลขและตัวอักษร
