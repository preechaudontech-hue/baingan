ใบงานที่ 3.1 TypeScript: ชนิดข้อมูล interface และฟังก์ชัน

เวลา 90 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

เขียนโค้ด TypeScript ที่กำหนดชนิดข้อมูล interface และฟังก์ชัน และแก้ข้อผิดพลาดที่ตัวตรวจชนิดแจ้งได้

คำชี้แจง

ทดลองเขียนใน TypeScript Playground (typescriptlang.org/play) ซึ่งใช้ผ่านเบราว์เซอร์ได้โดยไม่ต้องติดตั้ง ทำตามขั้นตอนทีละข้อและสังเกตข้อความเตือนสีแดง

สิ่งที่ต้องเตรียม

  • ใบความรู้ที่ 3 หัวข้อ TypeScript เบื้องต้น

ขั้นตอนการปฏิบัติ

  1. เปิด TypeScript Playground วางโค้ดตั้งต้น แล้วเติมฟังก์ชัน average ให้ถูกต้อง รันดูผลที่หน้าต่างผลลัพธ์

  2. จงทำให้เกิดข้อผิดพลาดโดยตั้งใจ 3 แบบ ได้แก่ ส่ง string ให้ average ให้ scores เป็น string และลืมใส่ field name ใน Student แล้วจดข้อความที่ตัวตรวจชนิดแจ้งแต่ละแบบ

  3. เพิ่ม field ไม่บังคับชื่อ email?: string และ union type ชื่อ Grade = 'A' | 'B' | 'C' | 'D' | 'F' แล้วเขียนฟังก์ชัน toGrade(score: number): Grade

  4. เขียนฟังก์ชัน best(students: Student[]): Student | undefined ที่คืนนักเรียนที่มีค่าเฉลี่ยสูงสุด (ถ้าไม่มีนักเรียนให้คืน undefined)

  5. ทดสอบด้วยนักเรียนอย่างน้อย 3 คน และกรณีอาเรย์ว่าง ถ่ายภาพหน้าจอผลลัพธ์

  6. เขียนสั้น ๆ 3 บรรทัดว่า TypeScript ช่วยจับข้อผิดพลาดใดได้ที่ JavaScript ธรรมดาไม่เตือน

คำแนะนำ

  • ใช้ Array.reduce หรือ for loop ก็ได้ในการรวมคะแนน
  • ฟังก์ชัน best คืน undefined ได้ จึงต้องระบุเป็น Student | undefined

สิ่งที่ต้องส่ง

ลิงก์ที่ได้จากปุ่ม Share ของ TypeScript Playground + ข้อความผิดพลาดที่จด 3 แบบ + ภาพผลรัน + สรุป 3 บรรทัด (ส่งตามช่องทางที่ครูกำหนด)
