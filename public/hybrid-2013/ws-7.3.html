ใบงานที่ 7.3 เชื่อมแอปของฉันกับ API และเก็บสำเนาในเครื่อง

เวลา 180 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

เชื่อมแอปของตนเองกับ API ภายนอกอย่างน้อย 1 รายการ และเก็บสำเนาข้อมูลในเครื่องเพื่อใช้ตอนออฟไลน์ พร้อมแสดงเวลาที่อัปเดตล่าสุด

คำชี้แจง

ionic serve ต้องรันอยู่ และต้องต่ออินเทอร์เน็ต ทุกขั้นที่ "วางโค้ดทั้งไฟล์" ให้ลบของเดิมก่อนด้วย Ctrl+A แล้ว Delete ใบงานนี้ตัวอย่างใช้ PokeAPI (รายชื่อโปเกมอน) เพื่อฝึกเก็บสำเนาข้อมูลไว้แสดงตอนออฟไลน์ แล้วนำวิธีเดียวกันไปใช้กับ API ที่เกี่ยวข้องกับแอปของคุณ ทำใบงาน 6.1 และ 7.1 ให้เสร็จก่อน

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 6.3 และ 7.1 - 7.2
  • ใบความรู้ที่ 7 หัวข้อเครือข่ายที่ไม่แน่นอน และการอ่านเอกสาร API

ขั้นตอนการปฏิบัติ

  1. ตรวจว่ามีไฟล์ src/api/http.ts จากใบงาน 7.1 และติดตั้งปลั๊กอิน Preferences แล้ว (ใบงาน 6.1) ถ้ายังไม่ได้ ให้ทำตามใบงานเหล่านั้นก่อน

    ผลที่ควรเห็น: มีไฟล์ http.ts และคำสั่ง npm install @capacitor/preferences จบโดยไม่มี ERR

  2. สร้างไฟล์ src/api/cache.ts วางโค้ดนี้ทั้งไฟล์ กด Ctrl+S (ฟังก์ชัน fetchWithCache โหลดจากเครือข่าย ถ้าล้มเหลวใช้สำเนาที่เก็บไว้)

    ไฟล์ src/api/cache.ts
    // src/api/cache.ts
import { Preferences } from '@capacitor/preferences';

interface Cached<T> { savedAt: number; data: T }

export interface Loaded<T> { data: T; fromCache: boolean; savedAt: number }

// โหลดจากเครือข่าย ถ้าล้มเหลวใช้สำเนาที่เก็บไว้ (ถ้าไม่มีสำเนา โยนข้อผิดพลาดเดิม)
export async function fetchWithCache<T>(key: string, load: () => Promise<T>): Promise<Loaded<T>> {
  try {
    const data = await load();
    const savedAt = Date.now();
    await Preferences.set({ key, value: JSON.stringify({ savedAt, data } as Cached<T>) });
    return { data, fromCache: false, savedAt };
  } catch (e) {
    const { value } = await Preferences.get({ key });
    if (value) {
      try {
        const c = JSON.parse(value) as Cached<T>;
        return { data: c.data, fromCache: true, savedAt: c.savedAt };
      } catch {
        // สำเนาเสียหาย ถือว่าไม่มีสำเนา
      }
    }
    throw e;
  }
}

// TODO: เขียนฟังก์ชันแปลงเวลา savedAt เป็นข้อความ เช่น "อัปเดตเมื่อ 5 นาทีที่แล้ว" หรือ "อัปเดตเมื่อ 14:30"
export function timeAgo(savedAt: number): string {
  return String(savedAt);
}
    ผลที่ควรเห็น: ไม่มีข้อความแดง

  3. อ่านโค้ด fetchWithCache: หา 2 ส่วน try ... catch แล้วเขียนในช่องบันทึกว่าลำดับการทำงานเป็นอย่างไรเมื่อ (ก) โหลดสำเร็จ (ข) โหลดล้มเหลวแต่มีสำเนา (ค) โหลดล้มเหลวและไม่มีสำเนา

    ผลที่ควรเห็น: ตอบได้ว่า (ก) เก็บสำเนาแล้วคืนข้อมูลใหม่ (ข) คืนข้อมูลสำเนาพร้อม fromCache เป็น true (ค) โยนข้อผิดพลาดเดิม

  4. เขียนฟังก์ชัน timeAgo ที่ยังเป็นโค้ดชั่วคราว (คืนตัวเลขดิบ) แทนบรรทัด return String(savedAt); ด้วยโค้ดนี้

  5. สร้างหน้าตัวอย่าง src/pages/Pokedex.tsx วางโค้ดนี้ทั้งไฟล์ (เรียก PokeAPI ผ่าน fetchWithCache) กด Ctrl+S

    ไฟล์ src/pages/Pokedex.tsx
    import { useEffect, useState } from 'react';
import { IonButton, IonContent, IonHeader, IonItem, IonLabel, IonList, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import { getJson } from '../api/http';
import { fetchWithCache, timeAgo } from '../api/cache';

interface PokemonList { results: { name: string; url: string }[] }

const Pokedex: React.FC = () => {
  const [names, setNames] = useState<string[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState('');
  const [oldInfo, setOldInfo] = useState('');

  async function load() {
    setLoading(true);
    setError('');
    setOldInfo('');
    try {
      const r = await fetchWithCache('pokemon-list', () => getJson<PokemonList>('https://pokeapi.co/api/v2/pokemon?limit=10'));
      setNames(r.data.results.map(p => p.name));
      if (r.fromCache) setOldInfo(`กำลังแสดงข้อมูลเก่า ${timeAgo(r.savedAt)}`);
    } catch (e) {
      setError(e instanceof Error ? e.message : 'เกิดข้อผิดพลาด');
    } finally {
      setLoading(false);
    }
  }

  useEffect(() => {
    load();
  }, []);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>โปเกมอน ({names.length})</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <IonButton expand="block" onClick={load} disabled={loading}>โหลดใหม่</IonButton>

        {loading && <p>กำลังโหลด...</p>}
        {oldInfo && <p>{oldInfo}</p>}
        {error && <p>{error}</p>}

        <IonList>
          {names.map(n => (
            <IonItem key={n}>
              <IonLabel>{n}</IonLabel>
            </IonItem>
          ))}
        </IonList>
        <p>ข้อมูลจาก PokeAPI (pokeapi.co)</p>
      </IonContent>
    </IonPage>
  );
};

export default Pokedex;
    ผลที่ควรเห็น: ยังไม่เห็นผลบนหน้าเว็บ

  7. เปิดที่อยู่ /pokedex ในเบราว์เซอร์

    ผลที่ควรเห็น: แถบหัว โปเกมอน (10) รายการชื่อ 10 ชื่อ (bulbasaur, ivysaur, venusaur ...) และข้อความ ข้อมูลจาก PokeAPI (pokeapi.co) ปุ่ม โหลดใหม่

  8. ดูสำเนาที่เก็บไว้: กด F12 แท็บ Application เปิด Local Storage หาคีย์ CapacitorStorage.pokemon-list

    ผลที่ควรเห็น: เห็นค่าเป็น JSON มีฟิลด์ savedAt (ตัวเลขเวลา) และ data ที่มีรายชื่อโปเกมอน ถ่ายภาพ

  9. ทดสอบออฟไลน์ ขั้นที่ 1: ที่แท็บ Network ตั้งเป็น Offline

    ผลที่ควรเห็น: ยังไม่มีอะไรเปลี่ยนบนหน้า

  10. ขั้นที่ 2: กดปุ่ม โหลดใหม่

    ผลที่ควรเห็น: ข้อมูลยังแสดงครบ 10 ชื่อ และมีข้อความ กำลังแสดงข้อมูลเก่า อัปเดตเมื่อ ... (เช่น สักครู่ หรือ กี่นาทีที่แล้ว) แทนที่จะขึ้นข้อผิดพลาด

  11. ขั้นที่ 3: กด F5 รีเฟรชหน้าทั้งที่ยัง Offline

    ผลที่ควรเห็น: ข้อมูลยังแสดงจากสำเนาพร้อมข้อความข้อมูลเก่า (สำเนาอยู่รอดหลังรีเฟรช) ถ่ายภาพ

  12. ทดสอบออฟไลน์ครั้งแรกที่ไม่มีสำเนา: ตั้งยัง Offline แล้วลบคีย์ CapacitorStorage.pokemon-list ใน Local Storage (คลิกขวาที่รายการ เลือก Delete) แล้วกด F5

    ผลที่ควรเห็น: ขึ้นข้อความ เชื่อมต่อเครือข่ายไม่ได้ และไม่มีรายชื่อ (ไม่มีสำเนาให้ใช้) จากนั้นตั้ง Network กลับเป็น No throttling แล้วกด โหลดใหม่ ข้อมูลกลับมา

  13. เลือก API สำหรับแอปของคุณ 1 รายการที่เกี่ยวข้องกับเรื่องของแอป ตัวเลือกที่ใช้ได้โดยไม่ต้องสมัคร: Open-Meteo, PokeAPI หรือ Open Library (openlibrary.org/search.json) หรือ API ที่ครูกำหนด แล้วเขียนสรุปเอกสาร API ในไฟล์ Word ตามตารางในใบความรู้ (Base URL, endpoint ที่ใช้, พารามิเตอร์, ตัวอย่างคำตอบ, การยืนยันตัวตน, ขีดจำกัด, เงื่อนไขการใช้งาน)

    ผลที่ควรเห็น: ได้สรุปเอกสาร API ที่ตอบครบทั้ง 7 หัวข้อ

  14. ทดลองเรียก API ที่เลือกก่อนเขียนโค้ด: เปิดที่อยู่ของ endpoint ในแท็บใหม่ของเบราว์เซอร์ ดู JSON ที่ได้ แล้วกำหนด interface ของคำตอบ โดยฟิลด์ที่อาจไม่มีให้เป็น optional (มี ? )

    ผลที่ควรเห็น: ได้ interface ที่ตรงกับ JSON ที่เห็นจริง

  15. สร้างหน้าของแอปคุณตามแบบ Pokedex.tsx: เรียก API ของคุณด้วย getJson ห่อด้วย fetchWithCache ใช้คีย์สำเนาที่แยกตามพารามิเตอร์ (เช่น weather-อุดรธานี) แสดงสถานะ กำลังโหลด ผิดพลาด และข้อมูลเก่า พร้อมปุ่มโหลดใหม่

    ผลที่ควรเห็น: หน้าของแอปคุณแสดงข้อมูลจาก API และทำงานตอนออฟไลน์ด้วยสำเนา

  16. ทดสอบ 3 สถานการณ์กับหน้าของคุณ: ออนไลน์ครั้งแรก ออนไลน์ครั้งที่สอง และออฟไลน์ (แล้วรีเฟรช) ถ่ายภาพทุกสถานการณ์ และทดสอบออฟไลน์ตั้งแต่ยังไม่เคยโหลดด้วย

    ผลที่ควรเห็น: ได้ภาพ 4 ภาพ (3 สถานการณ์ + ออฟไลน์ครั้งแรก)

  17. ตรวจความปลอดภัย: ค้นหาในโค้ดทั้งโปรเจกต์ว่ามีรหัสผ่านหรือกุญแจลับหรือไม่ ตรวจว่าทุก URL ของ API ใช้ https:// แล้วเขียนรายการข้อมูลที่แอปส่งออกไปยัง API (เช่น ชื่อเมือง พิกัด) พร้อมเหตุผลที่จำเป็น

    ผลที่ควรเห็น: ได้รายการข้อมูลที่ส่งออกและเหตุผล และไม่พบกุญแจลับในโค้ด

  18. เขียนสิ่งที่ยังไม่สมบูรณ์ของแอปและแผนแก้ไข 3 ข้อ แล้วส่งงานขึ้น GitHub

คำแนะนำ

  • ใช้ key สำหรับเก็บสำเนาที่แยกตามพารามิเตอร์ของคำขอ เช่น weather-อุดรธานี ไม่เช่นนั้นข้อมูลของเมืองหนึ่งจะไปทับของอีกเมือง
  • ถ้า API ที่เลือกไม่อนุญาต CORS ให้เปลี่ยนไปเลือก API อื่น หรือปรึกษาครู
  • แสดงข้อมูลจากสำเนาด้วยความระมัดระวัง ต้องบอกผู้ใช้ชัดเจนว่าเป็นข้อมูลเก่า

สิ่งที่ต้องส่ง

ลิงก์ GitHub + สรุปเอกสาร API + ภาพหน้าจอ 3 สถานการณ์ (ออนไลน์ ข้อมูลเก่าตอนออฟไลน์ และออฟไลน์ครั้งแรก) + รายการข้อมูลที่ส่งออกและเหตุผล + สิ่งที่ยังไม่สมบูรณ์และแผนแก้ไข (ส่งตามช่องทางที่ครูกำหนด)
