ใบงานที่ 3.3 แยกคอมโพเนนต์ด้วย props และ callback

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แยกส่วนแสดงผลรายการเป็นคอมโพเนนต์ลูก ส่งข้อมูลด้วย props และรับเหตุการณ์ด้วย callback ได้

คำชี้แจง

ใบงานนี้แยกหน้ารายการงานจากใบงาน 3.2 ออกเป็นคอมโพเนนต์ย่อย โดยที่หน้าตาและการทำงานต้องเหมือนเดิมทุกอย่าง ทำใบงาน 3.2 ให้เสร็จ (ขั้นที่ 4) ก่อน

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 3.2
  • ใบความรู้ที่ 3 หัวข้อ props

ขั้นตอนการปฏิบัติ

  1. เตรียมความพร้อม: ionic serve ต้องรันอยู่ และไฟล์ src/pages/Home.tsx เป็นโค้ดขั้นที่ 4 ของใบงาน 3.2 (หัวข้อ รายการงาน (... ที่ยังไม่เสร็จ) มีปุ่ม ลบ)

    ผลที่ควรเห็น: หน้าเว็บทำงานเหมือนผลของใบงาน 3.2 ขั้นสุดท้าย

  2. สร้างโฟลเดอร์ใหม่: ที่แผงซ้ายมือของ VS Code คลิกขวาที่โฟลเดอร์ src เลือก New Folder ตั้งชื่อ components

    ผลที่ควรเห็น: มีโฟลเดอร์ components อยู่ใน src

  3. สร้างไฟล์ใหม่: คลิกขวาที่โฟลเดอร์ components เลือก New File ตั้งชื่อ TaskRow.tsx (ต้องพิมพ์นามสกุล .tsx ให้ถูกต้อง และ T ใหญ่) แล้ววางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/components/TaskRow.tsx
    interface Task { id: number; title: string; done: boolean }

interface TaskRowProps {
  task: Task;
  onToggle: (id: number) => void;
  onRemove: (id: number) => void;
}

const TaskRow: React.FC<TaskRowProps> = ({ task, onToggle, onRemove }) => (
  <li>
    <input type="checkbox" checked={task.done} onChange={() => onToggle(task.id)} />
    <span style={{ textDecoration: task.done ? 'line-through' : 'none' }}>{task.title}</span>
    <button onClick={() => onRemove(task.id)}>ลบ</button>
  </li>
);

export default TaskRow;
    ผลที่ควรเห็น: มีไฟล์ TaskRow.tsx พร้อมโค้ด (ตอนนี้ยังไม่มีผลบนหน้าเว็บ เพราะยังไม่มีใครเรียกใช้)

  4. อ่านโค้ด TaskRow: ดู interface TaskRowProps แล้วเขียนในช่องบันทึกว่า props 3 ตัวคืออะไร แต่ละตัวชนิดอะไร และ onToggle กับ onRemove ต่างจาก task อย่างไร (คำใบ้: ตัวหนึ่งเป็นข้อมูล ตัวอื่นเป็นฟังก์ชัน)

    ผลที่ควรเห็น: ตอบได้ว่า task เป็นข้อมูลงาน ส่วน onToggle และ onRemove เป็นฟังก์ชันที่หน้าแม่ส่งมาให้ลูกเรียกเมื่อผู้ใช้ติ๊กหรือกดลบ

  5. ใช้ TaskRow ในหน้าแม่: เปิด src/pages/Home.tsx ลบโค้ดทั้งหมดแล้ววางโค้ดนี้ (ต่างจากเดิมที่บรรทัด import TaskRow และตรงที่เรียก <TaskRow ... /> แทน <li> ยาว ๆ) กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonContent, IonPage } from '@ionic/react';
import TaskRow from '../components/TaskRow';

interface Task { id: number; title: string; done: boolean }

let nextId = 3;

const Home: React.FC = () => {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ]);
  const [newTitle, setNewTitle] = useState('');

  const remaining = tasks.filter(t => !t.done).length;

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function add() {
    const title = newTitle.trim();
    if (title === '') return;
    setTasks([...tasks, { id: nextId++, title, done: false }]);
    setNewTitle('');
  }

  function remove(id: number) {
    setTasks(tasks.filter(t => t.id !== id));
  }

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน ({remaining} ที่ยังไม่เสร็จ)</h2>

        <input value={newTitle} onChange={e => setNewTitle(e.target.value)} placeholder="งานใหม่" />
        <button disabled={newTitle.trim() === ''} onClick={add}>เพิ่ม</button>

        {tasks.length === 0 ? (
          <p>ยังไม่มีงาน</p>
        ) : (
          <ul>
            {tasks.map(t => (
              <TaskRow key={t.id} task={t} onToggle={toggle} onRemove={remove} />
            ))}
          </ul>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: หน้าตาและการทำงานเหมือนใบงาน 3.2 ขั้นสุดท้ายทุกอย่าง (ติ๊ก เพิ่ม ลบ นับจำนวน) นี่คือความสำเร็จของการแยกคอมโพเนนต์

  6. ทดสอบว่าทำงานจริง: ติ๊ก 1 งาน เพิ่มงานใหม่ 1 งาน ลบ 1 งาน ตรวจว่าตัวเลขในหัวข้อถูกต้อง

    ผลที่ควรเห็น: ตัวเลขที่ยังไม่เสร็จเปลี่ยนถูกต้องทุกครั้ง

  7. ทำความเข้าใจ props down, events up: หาบรรทัด <TaskRow key={t.id} task={t} onToggle={toggle} onRemove={remove} /> แล้วเขียนในช่องบันทึกว่า ข้อมูลไหลจากไหนไปไหน และเหตุการณ์ (ติ๊ก/ลบ) ไหลกลับทางไหน

    ผลที่ควรเห็น: เขียนได้ว่าข้อมูล task ไหลลงจากหน้าแม่ไปลูก ส่วนเมื่อกดลบ ลูกเรียกฟังก์ชัน onRemove ที่หน้าแม่ส่งให้ แล้วหน้าแม่เป็นคนแก้ state

  8. ทดลองพิสูจน์ว่าลูกไม่ควรแก้ข้อมูลเอง: ในไฟล์ TaskRow.tsx ลองเปลี่ยน onChange={() => onToggle(task.id)} ชั่วคราวเป็น onChange={() => { task.done = !task.done; }} แล้วกด Ctrl+S จากนั้นทำตามลำดับ (ก) ติ๊กกล่องของ ทำใบงาน แล้วดูหน้าจอ (ข) พิมพ์ตัวอักษรอะไรก็ได้ในช่องกรอก งานใหม่

    ผลที่ควรเห็น: หลังข้อ (ก) หน้าจอไม่เปลี่ยน (กล่องยังว่าง ตัวเลขในหัวข้อเท่าเดิม) แต่หลังข้อ (ข) กล่องถึงถูกติ๊กและตัวเลขเปลี่ยน แปลว่าข้อมูลถูกแก้ไปแล้วแต่หน้าจอไม่ได้วาดใหม่ เพราะไม่ได้ผ่าน setTasks จากนั้นแก้กลับให้เป็น onChange={() => onToggle(task.id)} ตามเดิม

  9. เพิ่ม prop ที่ไม่บังคับ showId: ลบโค้ดทั้งหมดใน TaskRow.tsx แล้ววางโค้ดนี้ (เพิ่ม showId?: boolean และแสดง (#id) ต่อท้ายชื่อเมื่อเป็น true) กด Ctrl+S

    ไฟล์ src/components/TaskRow.tsx
    interface Task { id: number; title: string; done: boolean }

interface TaskRowProps {
  task: Task;
  onToggle: (id: number) => void;
  onRemove: (id: number) => void;
  showId?: boolean;
}

const TaskRow: React.FC<TaskRowProps> = ({ task, onToggle, onRemove, showId = false }) => (
  <li>
    <input type="checkbox" checked={task.done} onChange={() => onToggle(task.id)} />
    <span style={{ textDecoration: task.done ? 'line-through' : 'none' }}>
      {task.title}
      {showId ? ` (#${task.id})` : ''}
    </span>
    <button onClick={() => onRemove(task.id)}>ลบ</button>
  </li>
);

export default TaskRow;
    ผลที่ควรเห็น: หน้าจอยังเหมือนเดิม (ยังไม่มี #id เพราะหน้าแม่ยังไม่ส่ง showId)

  10. ที่หน้า src/pages/Home.tsx แก้บรรทัด <TaskRow ... /> โดยเพิ่มคำว่า showId ต่อท้ายก่อน /> ให้เป็น <TaskRow key={t.id} task={t} onToggle={toggle} onRemove={remove} showId /> แล้วกด Ctrl+S

    ผลที่ควรเห็น: ชื่อแต่ละงานมี (#1), (#2) ต่อท้าย ลองเอา showId ออกอีกครั้ง ตัวเลขหายไป

  11. สร้างคอมโพเนนต์ที่สอง: สร้างไฟล์ src/components/TaskSummary.tsx แล้ววางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/components/TaskSummary.tsx
    interface TaskSummaryProps {
  total: number;
  done: number;
}

const TaskSummary: React.FC<TaskSummaryProps> = ({ total, done }) => (

    </p>
    <progress value={done} max={total === 0 ? 1 : total} />
  </div>

export default TaskSummary;
    ผลที่ควรเห็น: มีไฟล์ใหม่ (ยังไม่มีผลบนหน้าเว็บ)

  12. ใช้ TaskSummary ในหน้าแม่: ลบโค้ดทั้งหมดใน Home.tsx แล้ววางโค้ดนี้ (เพิ่มบรรทัด import TaskSummary และบรรทัด <TaskSummary total={...} done={...} /> ใต้หัวข้อ) กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonContent, IonPage } from '@ionic/react';
import TaskRow from '../components/TaskRow';
import TaskSummary from '../components/TaskSummary';

interface Task { id: number; title: string; done: boolean }

let nextId = 3;

const Home: React.FC = () => {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: 'อ่านใบความรู้', done: true },
    { id: 2, title: 'ทำใบงาน', done: false },
  ]);
  const [newTitle, setNewTitle] = useState('');

  const remaining = tasks.filter(t => !t.done).length;

  function toggle(id: number) {
    setTasks(tasks.map(t => (t.id === id ? { ...t, done: !t.done } : t)));
  }

  function add() {
    const title = newTitle.trim();
    if (title === '') return;
    setTasks([...tasks, { id: nextId++, title, done: false }]);
    setNewTitle('');
  }

  function remove(id: number) {
    setTasks(tasks.filter(t => t.id !== id));
  }

  return (
    <IonPage>
      <IonContent className="ion-padding">
        <h2>รายการงาน ({remaining} ที่ยังไม่เสร็จ)</h2>

        <TaskSummary total={tasks.length} done={tasks.length - remaining} />

        <input value={newTitle} onChange={e => setNewTitle(e.target.value)} placeholder="งานใหม่" />
        <button disabled={newTitle.trim() === ''} onClick={add}>เพิ่ม</button>

        {tasks.length === 0 ? (
          <p>ยังไม่มีงาน</p>
        ) : (
          <ul>
            {tasks.map(t => (
              <TaskRow key={t.id} task={t} onToggle={toggle} onRemove={remove} showId />
            ))}
          </ul>
        )}
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: ใต้หัวข้อมีข้อความ เสร็จแล้ว 1 จาก 2 และแถบความคืบหน้า ติ๊กงานที่เหลือแล้วแถบเต็มและขึ้น เสร็จแล้ว 2 จาก 2

  13. ทดสอบกรณีไม่มีงาน: ลบงานทุกรายการ

    ผลที่ควรเห็น: ขึ้น เสร็จแล้ว 0 จาก 0 ข้อความ ยังไม่มีงาน และไม่มีข้อผิดพลาดใน Console (ตัวโค้ดใช้ total === 0 ? 1 : total เพื่อกันแถบพัง)

  14. วาดแผนภาพ 1 ภาพ (บนกระดาษแล้วถ่ายภาพ หรือใช้โปรแกรมวาด) แสดงกล่อง 3 กล่อง: Home (แม่) TaskRow (ลูก) TaskSummary (ลูก) ลูกศรลงเขียนชื่อ props ลูกศรขึ้นเขียนชื่อฟังก์ชันที่ลูกเรียก

    ผลที่ควรเห็น: แผนภาพที่ลูกศรลงมี task, total, done, showId และลูกศรขึ้นมี onToggle, onRemove

  15. ส่งงานขึ้น GitHub: เปิดเทอร์มินัลใหม่ แล้วพิมพ์ทีละบรรทัด

  • ชื่อไฟล์และชื่อคอมโพเนนต์ต้องขึ้นต้นด้วยตัวพิมพ์ใหญ่ และ import ต้องสะกดตรงกับชื่อไฟล์ทุกตัวอักษร
