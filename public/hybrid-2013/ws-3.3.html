ใบงานที่ 3.3 แยกคอมโพเนนต์ด้วย props และ callback

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แยกส่วนแสดงผลรายการเป็นคอมโพเนนต์ลูก ส่งข้อมูลด้วย props และรับเหตุการณ์ด้วย callback ได้

คำชี้แจง

นำผลงานใบงาน 3.2 มาแยกแต่ละรายการออกเป็นคอมโพเนนต์ TaskRow.tsx และให้หน้าแม่เป็นผู้เก็บข้อมูลเพียงจุดเดียว

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 3.2
  • ใบความรู้ที่ 3 หัวข้อ props

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
// src/components/TaskRow.tsx
interface Task { id: number; title: string; done: boolean }

interface TaskRowProps {
  task: Task;
  onToggle: (id: number) => void;
  onRemove: (id: number) => void;
}

const TaskRow: React.FC<TaskRowProps> = ({ task, onToggle, onRemove }) => (
  <li>
    <input type="checkbox" checked={task.done} onChange={() => onToggle(task.id)} />
    <span style={{ textDecoration: task.done ? 'line-through' : 'none' }}>{task.title}</span>
    <button onClick={() => onRemove(task.id)}>ลบ</button>
  </li>
);

export default TaskRow;

ขั้นตอนการปฏิบัติ

  1. สร้างไฟล์ src/components/TaskRow.tsx จากโค้ดตั้งต้น (ตัดบรรทัดคอมเมนต์บนสุดออกก็ได้)

  2. ในหน้าแม่ import TaskRow แล้วแทนที่ li เดิมด้วย <TaskRow key={t.id} task={t} onToggle={toggle} onRemove={remove} />

  3. ตรวจว่า TaskRow ไม่ได้แก้ค่า task โดยตรง และข้อมูลทั้งหมดอยู่ที่หน้าแม่เพียงที่เดียว

  4. เพิ่ม prop ใหม่ 1 ตัวที่ไม่บังคับ เช่น showId?: boolean แสดงเลข id ต่อท้ายชื่อเมื่อเป็น true

  5. สร้างคอมโพเนนต์ TaskSummary.tsx รับ props total และ done แล้วแสดงข้อความสรุป และแถบความคืบหน้าด้วยแท็ก progress ของ HTML นำไปใช้ในหน้าแม่

  6. วาดแผนภาพสั้น ๆ (บนกระดาษหรือเครื่องมือวาด) แสดงทิศทางของ props และ callback ระหว่างหน้าแม่กับสองคอมโพเนนต์ลูก

คำแนะนำ

  • ถ้าชื่อคอมโพเนนต์ขึ้นสีแดง ให้ตรวจการ import ตัวสะกด และตัวอักษรแรกต้องเป็นตัวพิมพ์ใหญ่
  • ถ้าให้ prop ที่ไม่บังคับมีค่าเริ่มต้น ใช้การกำหนดค่าในพารามิเตอร์ เช่น ({ task, showId = false })
