ฝึกเขียนแอปแรก Ionic React

วิชา 31901-2013 · ทำทีละขั้น ดูภาพที่ควรเห็น อ่านโค้ดทีละบรรทัด แล้วตอบคำถามตรวจความเข้าใจ

เตรียมก่อนเริ่ม

สร้างโปรเจกต์และเปิดดูผลบนเบราว์เซอร์

  1. ติดตั้ง Node.js (รุ่น LTS) และ Visual Studio Code จากเว็บทางการ
  2. เปิด VS Code แล้วเปิดเทอร์มินัล (เมนู Terminal แล้วเลือก New Terminal) พิมพ์ node --version ต้องขึ้นเลขเวอร์ชัน
  3. ติดตั้งเครื่องมือ Ionic: npm install -g @ionic/cli
  4. สร้างโปรเจกต์: ionic start myFirstApp blank --type=react (ใช้เวลาสักครู่ ถ้ามีคำถามให้สร้างบัญชี Ionic ให้ตอบ No)
  5. เข้าโฟลเดอร์โปรเจกต์: cd myFirstApp แล้วรัน ionic serve
  6. เปิดที่อยู่ที่ขึ้นในเทอร์มินัล (เช่น http://localhost:ตัวเลข) ด้วย Chrome กด F12 แล้วเลือกไอคอนโหมดจำลองอุปกรณ์ ให้เห็นเป็นขนาดมือถือ
  7. ไฟล์ที่เราจะแก้คือ src/pages/Home.tsx (เปิดใน VS Code) บันทึกไฟล์ด้วย Ctrl+S แล้วเบราว์เซอร์จะรีโหลดเอง

ห้ามปิดเทอร์มินัลที่รัน ionic serve ถ้าต้องพิมพ์คำสั่งอื่น ให้เปิดเทอร์มินัลใหม่ ถ้าขึ้นข้อความผิดพลาดสีแดง ให้ถ่ายภาพหน้าจอแล้วแจ้งครู

ตัวช่วยเรื่องสไตล์

จัดรูปแบบใน Ionic React ทำได้ 3 วิธี

วิธีเขียนอย่างไรใช้เมื่อ
1. ไฟล์ CSS + classNameimport './Home.css';
<div className="center">
แล้วเขียน .center { ... } ในไฟล์ Home.css		สไตล์ที่ใช้ซ้ำหรือยาว (วิธีหลักที่ควรใช้)
2. style ในแท็ก<h1 style={{ fontSize: 28 }}>
วงเล็บชั้นนอกคือ JSX ชั้นในคือออบเจ็กต์		ค่าที่มาจากตัวแปร หรือสไตล์สั้น ๆ ที่ใช้ครั้งเดียว
3. คลาสสำเร็จรูปของ Ionic<IonContent className="ion-padding">
ตัวอย่างอื่น: ion-text-center		เว้นระยะหรือจัดข้อความอย่างเร็ว (โปรเจกต์เริ่มต้นเปิดใช้ไว้แล้ว)
เขียนแบบนี้ผิดเขียนแบบนี้ถูกเหตุผล
<div class="center"><div className="center">ใน React ใช้ className (คำว่า class เป็นคำสงวนของ JavaScript)
style="font-size: 28px"style={{ fontSize: 28 }}style ต้องเป็นออบเจ็กต์ ชื่อเป็น camelCase
style={{ background-color: 'pink' }}style={{ backgroundColor: 'pink' }}ใน JavaScript ชื่อมีขีดไม่ได้ ต้องเป็น camelCase (ใน ไฟล์ .css ยังเขียน background-color ได้ตามปกติ)
style={{ color: red }}style={{ color: 'red' }}ชื่อสีเป็นข้อความ ต้องมีเครื่องหมายคำพูด
ลืมบรรทัด import './Home.css'มี import อยู่ด้านบนไฟล์ .tsxไม่เรียกไฟล์เข้ามา สไตล์จะไม่มีผล

รายการคุณสมบัติ CSS และตัวแปรสีของ Ionic ละเอียดกว่านี้ จะทำเป็นคู่มือแยกต่างหาก
