ใบงานที่ 1.3 แก้หน้าแรกของแอปและทดสอบบนมือถือจริง

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แก้ไขหน้า Home ตามโค้ดตั้งต้น ใช้ข้อมูลที่เปลี่ยนค่าได้ และเปิดแอปบนมือถือจริงผ่านเครือข่ายได้

คำชี้แจง

ใบงานนี้ต่อจากใบงาน 1.1 ให้เปลี่ยนหน้า Home ของโปรเจกต์ myFirstApp ทีละขั้น และดูผลบนเบราว์เซอร์ทุกขั้น จากนั้นลองเปิดบนมือถือ ทำใบงาน 1.1 ให้เสร็จก่อน

สิ่งที่ต้องเตรียม

  • โปรเจกต์ myFirstApp จากใบงาน 1.1
  • มือถือที่ต่อ Wi-Fi เดียวกับคอมพิวเตอร์ หรือเครื่องของเพื่อน

ขั้นตอนการปฏิบัติ

  1. เปิด VS Code ที่โปรเจกต์ myFirstApp เปิดเทอร์มินัล (Terminal > New Terminal) แล้วรันเซิร์ฟเวอร์ดูผล

    ionic serve
    ผลที่ควรเห็น: ขึ้น Development server running! และมีที่อยู่ Local: http://localhost:ตัวเลข เปิดที่อยู่นั้นใน Chrome แล้วกด F12 และเปิดโหมดจำลองมือถือ (Ctrl+Shift+M)

  2. เปิดไฟล์ src/pages/Home.tsx คลิกในหน้าต่างโค้ด กด Ctrl+A เพื่อเลือกทั้งไฟล์ แล้วกด Delete

    ผลที่ควรเห็น: ไฟล์ Home.tsx ว่างเปล่า (เบราว์เซอร์อาจแสดงหน้าขาวหรือข้อผิดพลาดชั่วคราว ปกติ)

  3. กดปุ่ม "คัดลอกโค้ด" ใต้โค้ดนี้ (หรือเลือกทั้งหมดแล้วกด Ctrl+C) แล้วกลับไปวางในไฟล์ Home.tsx ด้วย Ctrl+V จากนั้นกด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonButton, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';

const name = 'ชื่อของฉัน';

const Home: React.FC = () => {
  const [count, setCount] = useState(0);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>แอปแรกของฉัน</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <h2>สวัสดี เราคือ {name}</h2>
        <IonButton onClick={() => setCount(count + 1)}>กดแล้ว {count} ครั้ง</IonButton>
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: เบราว์เซอร์แสดงแถบหัวสีน้ำเงินเขียนว่า แอปแรกของฉัน ข้อความ สวัสดี เราคือ ชื่อของฉัน และปุ่มเขียนว่า กดแล้ว 0 ครั้ง

  4. แก้ชื่อ: หาบรรทัด const name = 'ชื่อของฉัน'; แล้วเปลี่ยนข้อความในเครื่องหมายคำพูดเป็นชื่อจริงของคุณ (ห้ามลบเครื่องหมายคำพูด) กด Ctrl+S

    ผลที่ควรเห็น: ข้อความเปลี่ยนเป็น สวัสดี เราคือ (ชื่อของคุณ) โดยไม่ต้องรีเฟรช

  5. ที่เบราว์เซอร์ คลิกปุ่ม กดแล้ว 0 ครั้ง 3 ครั้ง

    ผลที่ควรเห็น: ตัวเลขบนปุ่มเปลี่ยนเป็น 1, 2, 3 ตามจำนวนที่กด

  6. ทำความเข้าใจ (ยังไม่ต้องแก้โค้ด): ดูบรรทัด const [count, setCount] = useState(0); ในโค้ด แล้วเขียนในช่องบันทึกว่า count คืออะไร และ setCount ทำอะไร (ใบความรู้ที่ 3 หัวข้อ useState)

    ผลที่ควรเห็น: เขียนได้ว่า count เก็บตัวเลขที่เปลี่ยนได้ ค่าเริ่มต้น 0 ส่วน setCount เป็นฟังก์ชันที่ใช้เปลี่ยนค่าและทำให้หน้าจอวาดใหม่

  7. เพิ่มปุ่มรีเซ็ต: ลบทั้งไฟล์ Home.tsx อีกครั้ง (Ctrl+A แล้ว Delete) แล้ววางโค้ดชุดนี้แทน (มีปุ่ม รีเซ็ต เพิ่มขึ้นมา 1 บรรทัด) กด Ctrl+S

    ไฟล์ src/pages/Home.tsx
    import { useState } from 'react';
import { IonButton, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';

const name = 'ชื่อของฉัน';

const Home: React.FC = () => {
  const [count, setCount] = useState(0);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>แอปแรกของฉัน</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <h2>สวัสดี เราคือ {name}</h2>
        <IonButton onClick={() => setCount(count + 1)}>กดแล้ว {count} ครั้ง</IonButton>
        <IonButton color="danger" onClick={() => setCount(0)}>รีเซ็ต</IonButton>
      </IonContent>
    </IonPage>
  );
};

export default Home;
    ผลที่ควรเห็น: มีปุ่มสีแดงเขียนว่า รีเซ็ต ข้างปุ่ม กดแล้ว ... ครั้ง

  8. ทดสอบ: กดปุ่ม กดแล้ว ... ครั้ง 4 ครั้ง แล้วกดปุ่ม รีเซ็ต

    ผลที่ควรเห็น: ตัวเลขเพิ่มเป็น 4 แล้วกลับเป็น 0 เมื่อกดรีเซ็ต

  9. เปลี่ยนสีปุ่มรีเซ็ต: ในบรรทัด <IonButton color="danger" ...> เปลี่ยนคำว่า danger เป็น secondary แล้วกด Ctrl+S ลองเปลี่ยนเป็น success และ warning ด้วย

    ผลที่ควรเห็น: สีปุ่มรีเซ็ตเปลี่ยนตามค่า (secondary เป็นม่วง/น้ำเงินเข้ม success เป็นเขียว warning เป็นเหลือง) ตั้งทิ้งไว้เป็นสีที่ชอบ

  10. ถ่ายภาพหน้าจอเบราว์เซอร์ (โหมดจำลองมือถือ) ให้เห็นชื่อของคุณ และตัวเลขที่ไม่ใช่ 0 บนปุ่ม

    ผลที่ควรเห็น: ได้ภาพที่ 1 สำหรับส่ง

  11. เตรียมเปิดบนมือถือ: กลับไปที่เทอร์มินัลที่รัน ionic serve กด Ctrl+C เพื่อหยุด (ถ้าถามให้พิมพ์ Y แล้ว Enter) แล้วรันคำสั่งนี้

    ionic serve --external
    ผลที่ควรเห็น: ขึ้นบรรทัด External: http://ตัวเลข.ตัวเลข.ตัวเลข.ตัวเลข:พอร์ต อาจมีหลายที่อยู่

  12. เลือกที่อยู่ที่ถูกต้อง: ดูบรรทัดด้านล่างที่ขึ้นต้นด้วย [vite] Network: ที่อยู่ที่ต่อท้ายว่า Wi-Fi คือที่อยู่ของเครือข่ายที่มือถือเข้าได้ (ที่อยู่ที่ต่อท้ายว่า WSL หรือ vEthernet ไม่ใช่) จดที่อยู่นั้นไว้

    ผลที่ควรเห็น: ได้ที่อยู่แบบ http://10.xx.xx.xx:พอร์ต หรือ http://192.168.xx.xx:พอร์ต

  13. บนมือถือที่ต่อ Wi-Fi เดียวกับคอมพิวเตอร์ เปิดเบราว์เซอร์ พิมพ์ที่อยู่ที่จดไว้ในช่องที่อยู่ (ต้องพิมพ์ http:// นำหน้า) แล้วกดไป

    ผลที่ควรเห็น: เห็นหน้าแอปของคุณบนมือถือ ปุ่มกดได้ (ถ้าเปิดไม่ได้ ดูคำแนะนำท้ายใบงาน)

  14. ถ่ายภาพหน้าจอบนมือถือที่เห็นแอปของคุณ และถ้าเปิดไม่ได้ ให้บันทึกข้อความที่ขึ้นแทน

    ผลที่ควรเห็น: ได้ภาพที่ 2 สำหรับส่ง (หรือบันทึกปัญหา)

  15. บนมือถือ เปิดเมนูของเบราว์เซอร์ (จุดสามจุดบน Android Chrome หรือปุ่มแชร์บน Safari) เลือก เพิ่มไปยังหน้าจอหลัก (Add to Home screen) ถ้ามีตัวเลือก

    ผลที่ควรเห็น: ถ้าทำได้ จะมีไอคอนใหม่ที่หน้าจอหลัก ถ้าไม่มีตัวเลือกนี้ ให้บันทึกว่าไม่มี

  16. เปิดไอคอนที่หน้าจอหลัก (ถ้ามี) แล้วเขียนในช่องบันทึก 2 ข้อ: หน้าตาต่างจากเปิดในเบราว์เซอร์อย่างไร และต่างจากแอปที่ติดตั้งจากร้านอย่างไร (คำใบ้: ตอนนี้โปรเจกต์ยังไม่ได้ตั้งค่า manifest และ Service Worker เต็มรูปแบบ)

    ผลที่ควรเห็น: บันทึกความแตกต่างได้ 2 ข้อ หรือบันทึกว่าไม่สามารถทดสอบได้ พร้อมเหตุผล

  17. ส่งงานขึ้น GitHub: เปิดเทอร์มินัลใหม่ (กดปุ่ม +) แล้วพิมพ์ทีละบรรทัด กด Enter ทุกบรรทัด

    git add .
git commit -m "1.3 counter app"
git push
    ผลที่ควรเห็น: ขึ้น Writing objects ... done ที่หน้า GitHub ของที่เก็บ ionic-first-app เห็นข้อความ 1.3 counter app

คำแนะนำ

  • ถ้าเปิดที่อยู่บนมือถือไม่ได้: ตรวจว่ามือถือกับคอมพิวเตอร์ต่อ Wi-Fi เดียวกัน ใช้ที่อยู่ที่เป็นของ Wi-Fi ไม่ใช่ localhost และลองปิดไฟร์วอลล์ชั่วคราวตามที่ครูอนุญาต หรือใช้ฮอตสปอตจากมือถือเครื่องหนึ่งให้ทั้งสองเครื่องต่อร่วมกัน
  • ถ้าหน้าเบราว์เซอร์ขาวหลังวางโค้ด ให้ดูที่เทอร์มินัลและ Console ของ DevTools (แท็บ Console) จะมีข้อความสีแดงบอกบรรทัดที่ผิด และตรวจว่าวางโค้ดครบทุกบรรทัด
  • ที่อยู่บนมือถือต้องเป็นหมายเลข IP ของคอมพิวเตอร์ ใช้ localhost ไม่ได้ เพราะ localhost บนมือถือหมายถึงมือถือเอง

สิ่งที่ต้องส่ง

ภาพหน้าจอบนเบราว์เซอร์และบนมือถือ + คำอธิบาย useState + บันทึกผลการเพิ่มไปยังหน้าจอหลัก + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
