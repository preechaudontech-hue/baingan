ใบงานที่ 1.3 แก้หน้าแรกของแอปและทดสอบบนมือถือจริง

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

แก้ไขหน้า Home ตามโค้ดตั้งต้น ใช้ข้อมูลที่เปลี่ยนค่าได้ และเปิดแอปบนมือถือจริงผ่านเครือข่ายได้

คำชี้แจง

นำโค้ดตั้งต้นไปแทนที่ไฟล์ src/pages/Home.tsx ของโปรเจกต์ myFirstApp แล้วทดสอบการกดปุ่ม จากนั้นเปิดแอปบนมือถือของตนเอง

สิ่งที่ต้องเตรียม

  • โปรเจกต์ myFirstApp จากใบงาน 1.1
  • มือถือที่ต่อ Wi-Fi เดียวกับคอมพิวเตอร์ หรือเครื่องของเพื่อน

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
import { useState } from 'react';
import { IonButton, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';

const name = 'ชื่อของฉัน';

const Home: React.FC = () => {
  const [count, setCount] = useState(0);

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>แอปแรกของฉัน</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <h2>สวัสดี เราคือ {name}</h2>
        <IonButton onClick={() => setCount(count + 1)}>กดแล้ว {count} ครั้ง</IonButton>
      </IonContent>
    </IonPage>
  );
};

export default Home;

ขั้นตอนการปฏิบัติ

  1. เปิดไฟล์ src/pages/Home.tsx ของโปรเจกต์ แล้วแทนที่เนื้อหาทั้งหมดด้วยโค้ดตั้งต้น เปลี่ยนค่า name เป็นชื่อจริงของตนเอง

  2. ดูผลบนเบราว์เซอร์ กดปุ่มหลายครั้ง และอธิบายด้วยคำพูดของตนเองว่าเหตุใดตัวเลขจึงเปลี่ยน (useState ทำหน้าที่อะไร และเหตุใดต้องใช้ setCount)

  3. เพิ่มปุ่มที่สองชื่อ รีเซ็ต ที่ตั้งค่า count กลับเป็น 0 และเปลี่ยนสีปุ่มด้วยคุณสมบัติ color ของ IonButton (ลองค่า secondary หรือ danger)

  4. รันด้วย ionic serve --external (ให้เครื่องอื่นในเครือข่ายเข้าถึงได้) แล้วอ่านที่อยู่แบบ Network ที่ปรากฏในเทอร์มินัล

  5. เปิดที่อยู่นั้นบนมือถือที่ต่อ Wi-Fi เดียวกัน ถ่ายภาพหน้าจอมือถือที่เห็นแอป ถ้าเปิดไม่ได้ให้บันทึกข้อความผิดพลาดและตรวจสอบไฟร์วอลล์หรือเครือข่ายของห้องเรียน

  6. บนมือถือ ลองเลือก เพิ่มไปยังหน้าจอหลัก (Add to Home screen) ในเมนูของเบราว์เซอร์ แล้วบันทึกว่าที่ทำได้หรือไม่ และสิ่งที่เห็นต่างจากแอปที่ติดตั้งจากร้านอย่างไร

  7. ทำคอมมิตและ push การเปลี่ยนแปลงขึ้น GitHub

คำแนะนำ

  • ถ้าเครือข่ายโรงเรียนไม่อนุญาตให้อุปกรณ์เห็นกัน ให้ใช้ฮอตสปอตจากมือถือเครื่องหนึ่งให้คอมพิวเตอร์และมือถืออีกเครื่องต่อร่วมกัน
  • ที่อยู่ที่ใช้บนมือถือต้องเป็นหมายเลข IP ของคอมพิวเตอร์ ไม่ใช่ localhost
  • การเพิ่มไปยังหน้าจอหลักอาจทำได้ไม่ครบทุกฟังก์ชันของ PWA เพราะโปรเจกต์ยังไม่ได้ตั้งค่า manifest และ Service Worker

สิ่งที่ต้องส่ง

ภาพหน้าจอบนเบราว์เซอร์และบนมือถือ + คำอธิบาย useState + บันทึกผลการเพิ่มไปยังหน้าจอหลัก + ลิงก์ GitHub (ส่งตามช่องทางที่ครูกำหนด)
