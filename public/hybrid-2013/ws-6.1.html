ใบงานที่ 6.1 เก็บค่าตั้งค่าด้วย Preferences

เวลา 90 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

บันทึกและอ่านค่าตั้งค่าของแอปด้วย Preferences ให้แอปจำค่าได้หลังรีเฟรชหรือปิดเปิดใหม่ พร้อมค่าเริ่มต้นและการรีเซ็ต

คำชี้แจง

ionic serve ต้องรันอยู่ ทุกขั้นที่ "วางโค้ดทั้งไฟล์" ให้ลบของเดิมก่อนด้วย Ctrl+A แล้ว Delete ข้อมูลที่เก็บเป็นของเบราว์เซอร์ที่ใช้ทดสอบ (ผูกกับที่อยู่ localhost:พอร์ต) ใบงานนี้สร้างหน้า /settings ที่บันทึกค่าตั้งค่าลงเครื่อง และโหลดกลับมาเมื่อเปิดหน้าใหม่

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 4.2 และ 5.3
  • ใบความรู้ที่ 6 หัวข้อ Preferences

ขั้นตอนการปฏิบัติ

  1. เปิดเทอร์มินัลใหม่ (ปุ่ม +) แล้วติดตั้งปลั๊กอิน

    npm install @capacitor/preferences
    ผลที่ควรเห็น: จบโดยไม่มีข้อความ ERR และ ionic serve ที่รันอยู่ยังทำงานต่อ

  2. สร้างไฟล์ src/pages/SettingsPage.tsx วางโค้ดนี้ทั้งไฟล์ กด Ctrl+S

    ไฟล์ src/pages/SettingsPage.tsx
    import { useEffect, useState } from 'react';
import {
  IonButton, IonContent, IonHeader, IonInput, IonItem, IonPage, IonSelect, IonSelectOption, IonTitle,
  IonToggle, IonToolbar, useIonToast,
} from '@ionic/react';
import { Preferences } from '@capacitor/preferences';

interface Settings { name: string; defaultCategory: string; showTotal: boolean }

const KEY = 'settings';
const DEFAULTS: Settings = { name: '', defaultCategory: 'อาหาร', showTotal: true };

async function loadSettings(): Promise<Settings> {
  const { value } = await Preferences.get({ key: KEY });
  if (!value) return DEFAULTS;
  try {
    return { ...DEFAULTS, ...JSON.parse(value) };
  } catch (e) {
    return DEFAULTS; // ข้อมูลเสียหาย ใช้ค่าเริ่มต้น
  }
}

async function saveSettings(s: Settings): Promise<void> {
  await Preferences.set({ key: KEY, value: JSON.stringify(s) });
}

const SettingsPage: React.FC = () => {
  const [settings, setSettings] = useState<Settings>(DEFAULTS);
  const [ready, setReady] = useState(false);
  const [present] = useIonToast();

  useEffect(() => {
    loadSettings().then(s => {
      setSettings(s);
      setReady(true);
    });
  }, []);

  async function save() {
    await saveSettings(settings);
    present({ message: 'บันทึกแล้ว', duration: 1200, color: 'success' });
  }

  async function reset() {
    // TODO: ลบค่าที่บันทึกไว้ด้วย Preferences.remove แล้วตั้ง settings กลับเป็น DEFAULTS
  }

  if (!ready) return <p>กำลังโหลด...</p>;

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>ตั้งค่า</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <h2>สวัสดี {settings.name || 'ผู้ใช้'}</h2>

        <IonInput
          label="ชื่อของคุณ"
          labelPlacement="floating"
          fill="outline"
          value={settings.name}
          onIonInput={e => setSettings({ ...settings, name: String(e.detail.value ?? '') })}
        />

        <IonSelect
          label="หมวดเริ่มต้น"
          labelPlacement="floating"
          fill="outline"
          value={settings.defaultCategory}
          onIonChange={e => setSettings({ ...settings, defaultCategory: String(e.detail.value) })}
        >
          {['อาหาร', 'เดินทาง', 'การเรียน', 'อื่น ๆ'].map(c => (
            <IonSelectOption key={c} value={c}>{c}</IonSelectOption>
          ))}
        </IonSelect>

        <IonItem lines="none">
          <IonToggle
            checked={settings.showTotal}
            onIonChange={e => setSettings({ ...settings, showTotal: e.detail.checked })}
          >
            แสดงยอดรวมในหน้าหลัก
          </IonToggle>
        </IonItem>

        <IonButton expand="block" onClick={save}>บันทึก</IonButton>
        <IonButton expand="block" fill="outline" color="medium" onClick={reset}>รีเซ็ต</IonButton>
      </IonContent>
    </IonPage>
  );
};

export default SettingsPage;

  4. เปิดที่อยู่ /settings ในเบราว์เซอร์

    ผลที่ควรเห็น: แถบหัว ตั้งค่า หัวข้อ สวัสดี ผู้ใช้ ช่องชื่อของคุณ ตัวเลือก หมวดเริ่มต้น (แสดง อาหาร) สวิตช์ แสดงยอดรวมในหน้าหลัก (เปิดอยู่) และปุ่ม บันทึก กับ รีเซ็ต

  5. พิมพ์ชื่อของคุณในช่อง ชื่อของคุณ (ยังไม่ต้องกดบันทึก)

    ผลที่ควรเห็น: หัวข้อเปลี่ยนเป็น สวัสดี (ชื่อของคุณ) ทันทีขณะพิมพ์ (ค่านี้อยู่ในหน่วยความจำ ยังไม่ถูกบันทึกลงเครื่อง)

  6. กด F5 รีเฟรชหน้า

    ผลที่ควรเห็น: หัวข้อกลับเป็น สวัสดี ผู้ใช้ เพราะยังไม่ได้บันทึก นี่คือเหตุผลที่ต้องใช้ Preferences

  7. พิมพ์ชื่ออีกครั้ง แล้วกดปุ่ม บันทึก

    ผลที่ควรเห็น: มีข้อความสีเขียวด้านล่างจอ บันทึกแล้ว (หายไปเองใน 1.2 วินาที)

  8. กด F5 รีเฟรชหน้า

    ผลที่ควรเห็น: หัวข้อเป็น สวัสดี (ชื่อที่บันทึก) ช่องชื่อมีชื่อเดิม เพราะแอปจำค่าได้

  9. ดูว่าค่าถูกเก็บที่ไหน: กด F12 เลือกแท็บ Application (ถ้าไม่เห็นให้กด >> ) เปิด Local Storage แล้วคลิกที่อยู่ localhost ของคุณ มองหาคีย์ที่ชื่อ CapacitorStorage.settings

    ผลที่ควรเห็น: เห็นคีย์ CapacitorStorage.settings และค่าเป็นข้อความรูปแบบ {"name":"ชื่อของคุณ","defaultCategory":"อาหาร","showTotal":true} (บนเว็บ Preferences เก็บใน Local Storage ส่วนบนมือถือจะเก็บในที่เก็บของระบบ) ถ่ายภาพ

  10. เปลี่ยนหมวดเริ่มต้นเป็น เดินทาง ปิดสวิตช์ แล้วกด บันทึก จากนั้นดูค่าใน Local Storage อีกครั้ง (คลิกรีเฟรชในตาราง)

    ผลที่ควรเห็น: ค่าเปลี่ยนเป็น "defaultCategory":"เดินทาง" และ "showTotal":false

  11. อ่านโค้ด: หาฟังก์ชัน loadSettings แล้วเขียนในช่องบันทึกว่า 3 สิ่งนี้ทำอะไร: (1) if (!value) return DEFAULTS (2) { ...DEFAULTS, ...JSON.parse(value) } (3) catch (e) { return DEFAULTS }

    ผลที่ควรเห็น: ตอบได้ว่า (1) ยังไม่เคยบันทึก ใช้ค่าเริ่มต้น (2) นำค่าที่บันทึกมาทับค่าเริ่มต้น ฟิลด์ใหม่ที่ยังไม่มีในของเก่าจึงได้ค่าเริ่มต้น (3) ข้อมูลเสียหายก็ไม่พัง

  12. เติมปุ่มรีเซ็ต: ยังไม่ทำงาน (กดแล้วไม่มีอะไรเกิดขึ้น) แทนบรรทัดคอมเมนต์ TODO ในฟังก์ชัน reset ด้วย 2 บรรทัดนี้

    ไฟล์ src/pages/SettingsPage.tsx

    ผลที่ควรเห็น: กดรีเซ็ตแล้วช่องและสวิตช์กลับเป็นค่าเริ่มต้นทันที คีย์ CapacitorStorage.settings หายจาก Local Storage และเมื่อ F5 ก็ยังเป็นค่าเริ่มต้น

  13. ทดสอบข้อมูลเสียหาย: กดบันทึกหนึ่งครั้งให้มีค่าใน Local Storage แล้วดับเบิลคลิกที่ค่าของคีย์ CapacitorStorage.settings แก้เป็นข้อความ {ไม่ใช่ json แล้วกด Enter จากนั้นกด F5

    ผลที่ควรเห็น: หน้าเปิดได้ปกติ ไม่พัง และใช้ค่าเริ่มต้น (หัวข้อ สวัสดี ผู้ใช้) อธิบายในช่องบันทึกว่าโค้ดส่วนใดทำให้เป็นเช่นนี้

  14. เพิ่มการตั้งค่าใหม่ของแอปคุณ ขั้นที่ 1: แก้ 2 บรรทัดนี้พร้อมกัน (บรรทัด interface Settings และบรรทัด const DEFAULTS ซึ่งอยู่ห่างกัน 2 บรรทัด) โดยเพิ่ม currency ทั้งสองที่ แล้วกด Ctrl+S

    ไฟล์ src/pages/SettingsPage.tsx

  15. ขั้นที่ 2: เพิ่มช่องกรอกสกุลเงิน วางชุดนี้ไว้ก่อนบรรทัด <IonItem lines="none"> (ตัวที่ครอบสวิตช์)

  16. ทดสอบความเข้ากันได้กับข้อมูลเก่า: ที่ค่าใน Local Storage ลบส่วน ,"currency":"บาท" ออกให้เหลือเหมือนข้อมูลเวอร์ชันเก่า แล้วกด F5

    ผลที่ควรเห็น: ช่อง สกุลเงิน ยังขึ้น บาท (ค่าเริ่มต้น) แม้ข้อมูลที่บันทึกไว้ไม่มีฟิลด์นี้ เพราะโค้ดนำข้อมูลเก่าไปทับค่าเริ่มต้น

  17. นำค่าไปใช้ในหน้าอื่น: สร้างไฟล์ src/components/Greeting.tsx วางโค้ดนี้ (คอมโพเนนต์ที่อ่านชื่อจาก Preferences)

    ไฟล์ src/components/Greeting.tsx
    import { useEffect, useState } from 'react';
import { Preferences } from '@capacitor/preferences';

// อ่านชื่อผู้ใช้ที่บันทึกไว้ในหน้าตั้งค่า (ใบงาน 6.1) มาแสดงทักทาย
const Greeting: React.FC = () => {
  const [name, setName] = useState('');

  useEffect(() => {
    Preferences.get({ key: 'settings' }).then(({ value }) => {
      if (!value) return;
      try {
        setName(JSON.parse(value).name ?? '');
      } catch (e) {
        setName('');
      }
    });
  }, []);

  return <p>สวัสดี {name || 'ผู้ใช้'}</p>;
};

export default Greeting;

คำแนะนำ

  • Preferences.get คืนค่า { value: string | null } ถ้าไม่พบคีย์จะได้ null
  • การเปลี่ยนค่าใน state ไม่ได้บันทึกอัตโนมัติ ต้องกดปุ่มบันทึกซึ่งเรียก Preferences.set
  • บนเว็บ Preferences ใช้ Local Storage ค่าจึงผูกกับที่อยู่เว็บ (พอร์ต) ที่ใช้ทดสอบ ถ้าเปลี่ยนพอร์ตจะไม่เห็นค่าเดิม
