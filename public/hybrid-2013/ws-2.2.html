จุดประสงค์

วาด Use Case Diagram ของแอปตนเองด้วยสัญลักษณ์ที่ถูกต้อง

คำชี้แจง

นำความต้องการจากใบงาน 2.1 มาสร้างเป็น Use Case Diagram พร้อมเขียนคำอธิบายขั้นตอนของ use case สำคัญ วาดด้วยมือหรือด้วยโปรแกรมวาดแผนภาพบนเว็บก็ได้

ดาวน์โหลดแบบฟอร์ม

แบบฝึก Use Case Diagram (ไฟล์ Word 5 หน้า) คลิกเพื่อดาวน์โหลด

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 2.1
  • ใบความรู้ที่ 2 หัวข้อ Use Case Diagram

ขั้นตอนการปฏิบัติ

  1. ระบุ actor ทั้งหมดของแอป อย่างน้อย 1 ตัว (ถ้ามีระบบภายนอกที่โต้ตอบด้วย เช่น API ให้ระบุด้วย)

  2. ระบุ use case อย่างน้อย 6 อัน โดยตั้งชื่อเป็นกริยานำและครอบคลุมความต้องการระดับ Must ในใบงาน 2.1

  3. วาดขอบเขตระบบ วาง actor ไว้นอกขอบเขต วาง use case ไว้ในขอบเขต และเชื่อมด้วยเส้น association

  4. เพิ่มความสัมพันธ์ include หรือ extend อย่างน้อย 1 รายการ พร้อมเขียนอธิบายเหตุผลสั้น ๆ

  5. เลือก use case สำคัญ 2 อัน เขียนขั้นตอนหลักทีละข้อ (ผู้ใช้ทำอะไร ระบบตอบสนองอย่างไร) และสิ่งที่เกิดขึ้นเมื่อมีข้อผิดพลาด 1 กรณี

  6. ตรวจว่า use case ทุกอันสอดคล้องกับ user story ในใบงาน 2.1 แล้วเขียนตารางโยงว่า use case ใดมาจาก user story ข้อใด

สิ่งที่ต้องส่ง

ภาพ Use Case Diagram (ภาพถ่ายหรือภาพส่งออกจากโปรแกรม) + ขั้นตอนของ use case สำคัญ 2 อัน + ตารางโยง use case กับ user story
