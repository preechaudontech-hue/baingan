ใบงานที่ 4.4 สร้างแอปหลายหน้าจอด้วย Router และ Tabs

เวลา 150 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

สร้างแอปหลายหน้าจอตามแผนผังการเปลี่ยนหน้าที่ออกแบบไว้ ส่งข้อมูลระหว่างหน้าด้วยพารามิเตอร์ใน path และใช้ Tabs เมื่อเหมาะสม

คำชี้แจง

นำหน้าจอที่ทำไว้ในใบงาน 4.1 - 4.3 มารวมเป็นแอปเดียวตามแผนผังการเปลี่ยนหน้า (screen map) จากใบงาน 2.4 โดยให้ข้อมูลรายการอยู่ที่ไฟล์กลาง และมีหน้ารายละเอียดที่เปิดจากรายการ

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 2.4 (screen map) และ 4.1 - 4.3
  • ใบความรู้ที่ 4 หัวข้อ Router และ Tabs

โค้ดตั้งต้น

คัดลอกไปวางในไฟล์ที่ระบุในโค้ด
// src/pages/ItemDetail.tsx
import { IonBackButton, IonButtons, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import { useParams } from 'react-router-dom';
import { ITEMS } from '../data/items';

const ItemDetail: React.FC = () => {
  const { id } = useParams<{ id: string }>();
  const item = ITEMS.find(i => i.id === Number(id));

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonButtons slot="start">
            <IonBackButton defaultHref="/home" text="กลับ" />
          </IonButtons>
          <IonTitle>รายละเอียด</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        {item ? (
          <>
            <h2>{item.title}</h2>
            <p>หมวด: {item.category}</p>
            <p>จำนวนเงิน: {item.amount} บาท</p>
            {/* TODO: แสดงข้อมูลอื่นของแอปตนเอง */}
          </>
        ) : (
          <p>ไม่พบรายการ</p>
        )}
      </IonContent>
    </IonPage>
  );
};

export default ItemDetail;

ขั้นตอนการปฏิบัติ

  1. สร้างไฟล์ src/data/items.ts เก็บ interface Item และอาร์เรย์ ITEMS (ข้อมูลตัวอย่างของแอปตนเอง อย่างน้อย 4 รายการ) แล้วสร้างไฟล์ src/pages/ItemDetail.tsx จากโค้ดตั้งต้น

  2. ใน App.tsx เพิ่ม Route สำหรับหน้ารายละเอียดที่ path /item/:id และ import ItemDetail

  3. ในหน้ารายการ ทำให้แต่ละแถวเปิดหน้ารายละเอียดได้ด้วย routerLink={/item/${i.id}} แล้วทดสอบกดเข้าและกดปุ่มกลับ

  4. สร้างหน้าที่สองตามแผนผังของตนเอง (เช่น หน้าสรุป หรือหน้าตั้งค่า) และเพิ่มแถบแท็บด้านล่างด้วย IonTabs ตามตัวอย่างในใบความรู้ ให้มีอย่างน้อย 2 แท็บ

  5. ตรวจว่าหน้าฟอร์มจากใบงาน 4.2 เข้าถึงได้ตามแผนผัง (เช่น ปุ่ม + เปิด /add) และกลับมาหน้ารายการได้ ปรับให้ชื่อ path ตรงกับแผนผัง

  6. ให้ทุกหน้าใช้ธีมสีเดียวกัน (ไม่มีสีที่เขียนติดในหน้าใดหน้าหนึ่ง) และทดสอบทั้งโหมดสว่างและมืด

  7. ทำตารางทดสอบ use case: เลือก use case จากใบงาน 2.2 อย่างน้อย 4 ข้อ แล้วทดสอบทีละขั้นว่าทำได้จริงหรือไม่ ผ่าน/ไม่ผ่าน และสิ่งที่พบ

  8. ถ่ายภาพหน้าจอทุกหน้า และเขียนสิ่งที่ยังไม่เหมือนแบบร่างพร้อมแผนแก้ไข

คำแนะนำ

  • ถ้ากดแถวแล้วหน้าไม่เปลี่ยน ตรวจว่า path ใน routerLink ตรงกับ Route และเปิด Console ดูข้อความผิดพลาด
  • ถ้าเปิดหน้ารายละเอียดโดยตรงแล้วขึ้น "ไม่พบรายการ" ให้ตรวจว่า id ใน URL ตรงกับ id ในข้อมูล และมีการแปลงด้วย Number()
  • แท็บและหน้ารายละเอียดต้องอยู่ใน IonRouterOutlet ตัวเดียวกันที่ครอบด้วย IonTabs เพื่อให้แถบแท็บอยู่ตลอด

สิ่งที่ต้องส่ง

ลิงก์ GitHub + ภาพหน้าจอของทุกหน้า + ตารางทดสอบ use case + สิ่งที่ยังไม่เหมือนแบบร่างและแผนแก้ไข (ส่งตามช่องทางที่ครูกำหนด)
