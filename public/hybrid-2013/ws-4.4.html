ใบงานที่ 4.4 สร้างแอปหลายหน้าจอด้วย Router และ Tabs

เวลา 150 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

สร้างแอปหลายหน้าจอตามแผนผังการเปลี่ยนหน้าที่ออกแบบไว้ ส่งข้อมูลระหว่างหน้าด้วยพารามิเตอร์ใน path และใช้ Tabs เมื่อเหมาะสม

คำชี้แจง

ใบงานนี้ต้องรัน ionic serve ค้างไว้ และเปิดโปรเจกต์ใน VS Code ทุกขั้นที่ "วางโค้ดทั้งไฟล์" ให้คลิกในไฟล์ กด Ctrl+A แล้ว Delete ก่อนวาง ใบงานนี้รวมหน้าต่าง ๆ เป็นแอปเดียว มี 3 แท็บ (หน้าหลัก รายการ สรุป) และหน้ารายละเอียด ทำใบงาน 4.1 และ 4.3 ให้เสร็จก่อน

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 2.4 (screen map) และ 4.1 - 4.3
  • ใบความรู้ที่ 4 หัวข้อ Router และ Tabs

ขั้นตอนการปฏิบัติ

  1. เตรียมความพร้อม: ionic serve รันอยู่ ไฟล์ Home.tsx เป็นหน้าหลักจากใบงาน 4.1 และมีไฟล์ ItemList.tsx จากใบงาน 4.3 ให้ลบเส้นทางทดสอบ /add ออกจาก App.tsx ได้ถ้ามี

    ผลที่ควรเห็น: เปิด /home เห็นหน้าหลักของใบงาน 4.1 เปิด /list เห็นรายการจากใบงาน 4.3

  2. สร้างไฟล์ข้อมูลกลาง src/data/items.ts (สร้างโฟลเดอร์ data ใน src ก่อน) วางโค้ดนี้ (เปลี่ยนเป็นข้อมูลตัวอย่างของแอปคุณได้ แต่ต้องมีอย่างน้อย 4 รายการ)

  3. แทนที่ไฟล์ ItemList.tsx ด้วยโค้ดนี้ ซึ่งอ่านข้อมูลจากไฟล์กลาง และให้แต่ละแถวเป็นลิงก์ไปหน้ารายละเอียด (routerLink) กด Ctrl+S

    ไฟล์ src/pages/ItemList.tsx
    import { IonContent, IonHeader, IonIcon, IonItem, IonLabel, IonList, IonNote, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import { chevronForward } from 'ionicons/icons';
import { ITEMS } from '../data/items';

const ItemList: React.FC = () => {
  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonTitle>รายการ</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent>
        <IonList>
          {ITEMS.map(i => (
            <IonItem key={i.id} routerLink={`/item/${i.id}`} detail>
              <IonLabel>
                <h2>{i.title}</h2>
                <p>{i.category}</p>
              </IonLabel>
              <IonNote slot="end">{i.amount} บาท</IonNote>
              <IonIcon icon={chevronForward} slot="end" />
            </IonItem>
          ))}
        </IonList>
      </IonContent>
    </IonPage>
  );
};

export default ItemList;
    ผลที่ควรเห็น: หน้า /list แต่ละแถวมีลูกศร > ท้ายแถว (ยังกดไปหน้าใหม่ไม่ได้ เพราะยังไม่มีเส้นทาง)

  4. สร้างหน้ารายละเอียด: ไฟล์ src/pages/ItemDetail.tsx วางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/pages/ItemDetail.tsx
    import { IonBackButton, IonButtons, IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import { useParams } from 'react-router-dom';
import { ITEMS } from '../data/items';

const ItemDetail: React.FC = () => {
  const { id } = useParams<{ id: string }>();
  const item = ITEMS.find(i => i.id === Number(id));

  return (
    <IonPage>
      <IonHeader>
        <IonToolbar color="primary">
          <IonButtons slot="start">
            <IonBackButton defaultHref="/list" text="กลับ" />
          </IonButtons>
          <IonTitle>รายละเอียด</IonTitle>
        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        {item ? (
          <>
            <h2>{item.title}</h2>
            <p>หมวด: {item.category}</p>
            <p>จำนวนเงิน: {item.amount} บาท</p>
          </>
        ) : (
          <p>ไม่พบรายการ</p>
        )}
      </IonContent>
    </IonPage>
  );
};

export default ItemDetail;
    ผลที่ควรเห็น: ยังไม่มีผลบนหน้าเว็บ

  5. สร้างหน้าสรุป: ไฟล์ src/pages/Summary.tsx วางโค้ดนี้ กด Ctrl+S

    ไฟล์ src/pages/Summary.tsx
    import { IonContent, IonHeader, IonPage, IonTitle, IonToolbar } from '@ionic/react';
import { ITEMS } from '../data/items';

const Summary: React.FC = () => {

  return (

        <IonToolbar color="primary">

        </IonToolbar>
      </IonHeader>
      <IonContent className="ion-padding">
        <h2>ยอดรวม {total} บาท</h2>
      </IonContent>
    </IonPage>
  );
};

export default Summary;
    ผลที่ควรเห็น: ยังไม่มีผลบนหน้าเว็บ

  6. เพิ่มเส้นทางหน้ารายละเอียด: ลบทั้งไฟล์ src/App.tsx แล้ววางโค้ดนี้ (เพิ่ม import 2 บรรทัด และ Route ของ /list กับ /item/:id)

  7. ทดสอบ: เปิด /list ในเบราว์เซอร์ แล้วคลิกแถว ค่ารถ

    ผลที่ควรเห็น: ไปหน้า รายละเอียด ที่อยู่เป็น /item/2 เห็น ค่ารถ หมวด เดินทาง จำนวนเงิน 40 บาท

  8. กดปุ่มกลับที่มุมซ้ายบนของหน้ารายละเอียด

    ผลที่ควรเห็น: กลับมาหน้ารายการ /list

  9. ทดสอบกรณีผิดปกติ: พิมพ์ที่อยู่ /item/99 ตรงในเบราว์เซอร์

    ผลที่ควรเห็น: หน้ารายละเอียดขึ้นข้อความ ไม่พบรายการ (แทนที่จะพัง)

  10. อ่านโค้ด ItemDetail: หา const { id } = useParams<{ id: string }>(); แล้วเขียนในช่องบันทึกว่า id มาจากไหน ทำไมต้องใช้ Number(id) ตอนค้นหา

    ผลที่ควรเห็น: ตอบได้ว่า id มาจากส่วน :id ของที่อยู่ในเส้นทาง และเป็นข้อความเสมอ จึงต้องแปลงเป็นตัวเลขก่อนเทียบ

  11. ใส่แท็บด้านล่าง: ลบทั้งไฟล์ src/App.tsx แล้ววางโค้ดนี้ ซึ่งมีแท็บ 3 อัน

    ไฟล์ src/App.tsx
    import { IonApp, IonIcon, IonLabel, IonRouterOutlet, IonTabBar, IonTabButton, IonTabs, setupIonicReact } from '@ionic/react';
import { home, list, pieChart } from 'ionicons/icons';
import { IonReactRouter } from '@ionic/react-router';
import { Navigate, Route } from 'react-router-dom';

import Home from './pages/Home';
import ItemDetail from './pages/ItemDetail';
import ItemList from './pages/ItemList';
import Summary from './pages/Summary';

/* Core CSS required for Ionic components to work properly */

/* Basic CSS for apps built with Ionic */
import '@ionic/react/css/normalize.css';

/* Optional CSS utils that can be commented out */
import '@ionic/react/css/padding.css';

  12. ทดสอบแท็บ: แตะแท็บ รายการ แตะแท็บ สรุป แล้วแตะ หน้าหลัก

    ผลที่ควรเห็น: ที่อยู่เปลี่ยนเป็น /list /summary /home ตามลำดับ หน้า สรุป แสดง ยอดรวม 240 บาท

  13. ทดสอบแท็บร่วมกับหน้ารายละเอียด: ที่แท็บ รายการ คลิกแถวหนึ่งแล้วกดปุ่มกลับ

    ผลที่ควรเห็น: เปิดรายละเอียดแล้วกลับมาที่ /list ได้ และแถบแท็บยังอยู่ตลอด

  14. เชื่อมปุ่ม + บนหน้าหลักไปหน้าเพิ่มรายการ (ถ้าทำใบงาน 4.2 แล้ว): ใน App.tsx เพิ่ม import AddItem และ <Route path="/add" element={<AddItem />} /> ต่อจาก Route อื่น และใน Home.tsx เปลี่ยน <IonFabButton> เป็น <IonFabButton routerLink="/add"> แล้วทดสอบ

    ผลที่ควรเห็น: กดปุ่ม + ที่หน้าหลักแล้วไปหน้าฟอร์ม เพิ่มรายการ และกดปุ่มกลับของเบราว์เซอร์ได้

  15. ทำให้ทุกหน้าใช้ธีมเดียวกัน: ค้นหาในโค้ดทุกไฟล์ว่ามีสีที่เขียนตรง ๆ เช่น '#' หรือ 'red' หรือไม่ ถ้ามี ให้เปลี่ยนเป็น color="primary" หรือตัวแปรสี Ionic แล้วทดสอบโหมดมืดอีกครั้ง (วิธีเดียวกับใบงาน 4.1)

    ผลที่ควรเห็น: ไม่มีสีที่เขียนตรงในโค้ดหน้า หรือจดไว้ว่ามีที่ไหนที่ยังไม่ได้แก้ และทุกหน้าอ่านออกในโหมดมืด

  16. ทำตารางทดสอบ use case: เลือก use case จากใบงาน 2.2 อย่างน้อย 4 ข้อ ทำตารางคอลัมน์ ใช้งานอะไร / ขั้นตอนที่ทำ / ผลที่คาดหวัง / ผลจริง / ผ่านหรือไม่ผ่าน แล้วทดสอบทีละข้อบนแอปจริง

    ผลที่ควรเห็น: ตารางครบ 4 ข้อพร้อมผลจริง

  17. ถ่ายภาพหน้าจอทุกหน้าของแอป (หน้าหลัก รายการ รายละเอียด สรุป และฟอร์มถ้ามี) และเขียนสิ่งที่ยังไม่เหมือน wireframe พร้อมแผนแก้ไขอย่างน้อย 2 ข้อ

    ผลที่ควรเห็น: ได้ภาพทุกหน้าและแผนแก้ไข

  18. ส่งงานขึ้น GitHub: เทอร์มินัลใหม่ พิมพ์ทีละบรรทัด

คำแนะนำ

  • ถ้ากดแถวแล้วหน้าไม่เปลี่ยน ตรวจว่า path ใน routerLink ตรงกับ Route และดู Console
  • ถ้าเปิดหน้ารายละเอียดแล้วขึ้น ไม่พบรายการ ตรวจว่า id ใน URL ตรงกับ id ในข้อมูล และมีการแปลงด้วย Number()
  • แท็บและหน้ารายละเอียดต้องอยู่ใน IonRouterOutlet ตัวเดียวกันที่ครอบด้วย IonTabs เพื่อให้แถบแท็บอยู่ตลอด
