ใบงานที่ 7.3 เชื่อมแอปของฉันกับ API ของครูและเก็บสำเนาในเครื่อง

เวลา 180 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

เชื่อมแอปของตนเองกับ API ที่ผู้สอนจัดให้ และเก็บสำเนาข้อมูลในเครื่องเพื่อใช้ตอนออฟไลน์ได้

คำชี้แจง

รับเอกสาร API ของผู้สอน (URL ฐาน endpoint วิธียืนยันตัวตน ตัวอย่างข้อมูล) แล้วเชื่อมกับแอปของตนเอง ดึงและส่งข้อมูลผ่าน API และเก็บสำเนาข้อมูลล่าสุดใน SQLite หรือ AsyncStorage เพื่อแสดงเมื่อไม่มีอินเทอร์เน็ต

สิ่งที่ต้องเตรียม

  • เอกสาร API ของผู้สอน (แจกแยก)
  • ผลงานใบงาน 6.3 และ 7.2
  • ใบความรู้ที่ 7 หัวข้อ การรับมือเครือข่ายที่ไม่แน่นอน

ขั้นตอนการปฏิบัติ

  1. กรอกตารางสรุป API ของผู้สอน: URL ฐาน, รายการ endpoint และเมธอด, ฟิลด์ที่ส่ง/รับของแต่ละ endpoint, วิธียืนยันตัวตน (ถ้ามี), รหัสสถานะที่ API อาจตอบ (ข้อมูลต้องมาจากเอกสารของผู้สอนเท่านั้น ห้ามเดา)

  2. เทียบฟิลด์ใน API กับคลาสและตารางในแอปของตนเอง (ใบงาน 2.3 และ 6.3) แล้วเขียนตารางจับคู่ฟิลด์ พร้อมระบุฟิลด์ที่ต้องแปลงชนิดหรือชื่อ

  3. สร้างไฟล์ api.js รวมฟังก์ชันเรียก API ทั้งหมดของแอป ใช้ URL ฐานจากค่าคงที่เดียว ตรวจ res.ok และแปลงข้อผิดพลาดเป็นข้อความที่เข้าใจได้ (ห้ามเขียนรหัสผ่านหรือโทเคนจริงลงในโค้ดที่บันทึกบน Snack ถ้าต้องใช้ ให้ถามผู้สอนวิธีให้ผู้ใช้กรอกเองตอนใช้งาน)

  4. เชื่อมหน้าจอรายการให้ดึงข้อมูลจาก API เมื่อเปิดหน้า แล้วบันทึกสำเนาล่าสุดลง SQLite (หรือ AsyncStorage) และเพิ่มการส่งข้อมูลใหม่ไปยัง API อย่างน้อย 1 การกระทำ (สร้างหรือแก้ไข)

  5. ทำให้แอปแสดงสำเนาในเครื่องเมื่อเรียก API ไม่สำเร็จ พร้อมข้อความ "ข้อมูลล่าสุดเมื่อ ..." และปุ่มลองใหม่

  6. ทดสอบ 5 กรณี: ปกติ / ออฟไลน์ / URL ผิด / ข้อมูลที่ส่งไม่ถูกต้อง / ผู้ใช้กดซ้ำเร็ว ๆ แล้วทำตารางผลทดสอบ (กรณี ผลที่คาดหวัง ผลจริง ผ่าน/ไม่ผ่าน)

  7. ถ่ายภาพหน้าจอ (ออนไลน์ และออฟไลน์ที่ใช้สำเนา) แล้ว Save และคัดลอกลิงก์

สิ่งที่ต้องส่ง

ลิงก์ Snack + ตารางสรุป API + ตารางจับคู่ฟิลด์ + ตารางผลทดสอบ 5 กรณี + ภาพหน้าจอโหมดออนไลน์และออฟไลน์ (ส่งตามช่องทางที่ครูกำหนด)
