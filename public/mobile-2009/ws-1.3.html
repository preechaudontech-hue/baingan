ใบงานที่ 1.3 เปรียบเทียบแนวทางการพัฒนาแอป

เวลา 90 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

เปรียบเทียบแนวทางพัฒนาแอปแบบเนทีฟ ข้ามแพลตฟอร์ม และเว็บแอป แล้วเลือกแนวทางที่เหมาะกับโจทย์ได้พร้อมเหตุผล

คำชี้แจง

อ่านใบความรู้ที่ 1 และหน้าแรกของเว็บไซต์ reactnative.dev แล้วทำตามขั้นตอน เพื่อสรุปว่าเหตุใดวิชานี้เลือกใช้ React Native กับ Expo และเหมาะกับแอปประเภทใด

สิ่งที่ต้องเตรียม

  • ใบความรู้ที่ 1
  • เว็บ reactnative.dev (หน้าแรก)

ขั้นตอนการปฏิบัติ

  1. อ่านหน้าแรกของ reactnative.dev แล้วคัดข้อความสำคัญที่อธิบายว่า React Native แสดงผลอย่างไร (เขียนด้วยคำของตนเอง ไม่ต้องคัดลอกทั้งประโยค)

  2. เติมตารางเปรียบเทียบ 4 แนวทาง (เนทีฟเต็มรูปแบบ, ข้ามแพลตฟอร์มแบบ React Native, เว็บแอป/PWA, ไฮบริด) ตามหัวข้อ: ภาษาที่ใช้ ผลลัพธ์บนหน้าจอ ข้อดี ข้อจำกัด

  3. จากแอปที่เลือกไว้ในใบงาน 1.2 เลือก 1 แอป แล้วเขียนว่าถ้าจะพัฒนาแอปแบบนั้น ควรเลือกแนวทางใด เพราะเหตุใด (อย่างน้อย 3 เหตุผล)

  4. เขียนว่าวิชานี้เลือกใช้ React Native กับ Expo เพราะอะไร โดยอ้างอิงเงื่อนไขของห้องเรียน (เครื่องคอมพิวเตอร์ มือถือที่มี และเครื่องมือที่ใช้)

  5. เขียนข้อจำกัดของ Expo Go ที่ควรรู้อย่างน้อย 2 ข้อ (อ้างอิงใบความรู้ที่ 1)

สิ่งที่ต้องส่ง

ตารางเปรียบเทียบ 4 แนวทาง + ย่อหน้าเหตุผลเลือกแนวทางของแอปที่เลือก + ย่อหน้าเหตุผลที่วิชานี้ใช้ React Native กับ Expo (ส่งตามช่องทางที่ครูกำหนด)
