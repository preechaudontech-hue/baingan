ขั้นตอนการปฏิบัติ

  1. วางโค้ดตั้งต้น เขียนฟังก์ชัน createTodo setCompleted และ deleteTodo ตามใบความรู้ ตรวจ res.ok ทุกฟังก์ชัน และเขียน useEffect ดึงรายการ 10 รายการ

  2. เขียนฟังก์ชัน add ให้เรียก POST แล้วนำผลที่ได้ไปเพิ่มในรายการ ตรวจให้ id ไม่ซ้ำกับรายการเดิม (API จำลองอาจตอบ id ซ้ำ) ด้วยเงื่อนไขหรือการสร้าง id ในแอป

  3. เขียนฟังก์ชัน toggle ให้เรียก PATCH แล้วอัปเดตเฉพาะรายการนั้นด้วย map ขณะรอผลให้แสดงตัวหมุนที่รายการนั้น

  4. เขียนฟังก์ชัน remove ให้ถามยืนยันก่อน แล้วเรียก DELETE และลบออกจากรายการเมื่อสำเร็จเท่านั้น

  5. ทดสอบบนมือถือ: เพิ่ม 2 งาน ทำเครื่องหมายเสร็จ 2 งาน ลบ 1 งาน แล้วจดสถานะรหัสที่ API ตอบในแต่ละการกระทำ (ดูจากการแสดงผลชั่วคราวในแอปหรือ Alert)

  6. ทดสอบเมื่อเครือข่ายขาด (เครื่องบิน) ขณะกดทำเครื่องหมายเสร็จ ตรวจว่าแอปแจ้งผู้ใช้และสถานะบนหน้าจอไม่ผิดไปจากความจริง

  7. เขียนอธิบายว่า JSONPlaceholder ไม่บันทึกข้อมูลจริง สังเกตได้อย่างไรจากการดึงรายการใหม่ และเปรียบเทียบกับ API จริง ถ่ายภาพหน้าจอ แล้ว Save และคัดลอกลิงก์

สิ่งที่ต้องส่ง

ลิงก์ Snack + ภาพหน้าจอ + ตารางสรุปการเรียก API แต่ละเมธอด (เมธอด URL รหัสสถานะ ผลที่เห็น) + คำอธิบายเรื่อง API จำลอง (ส่งตามช่องทางที่ครูกำหนด)
