จุดประสงค์

เรียก API ด้วย fetch (GET) แสดงข้อมูลเป็นรายการ และจัดการสถานะกำลังโหลด ข้อผิดพลาด และรายการว่างได้

คำชี้แจง

สร้างแอปแสดงรายชื่อผู้ใช้จาก JSONPlaceholder (endpoint /users) พร้อมช่องค้นหา ปุ่มดึงข้อมูลใหม่ และการจัดการข้อผิดพลาดที่ครบถ้วน

  const [loading, setLoading] = useState(true);
  const [error, setError] = useState('');
  const [search, setSearch] = useState('');
  const [reloadKey, setReloadKey] = useState(0);

  useEffect(() => {
    // TODO: GET `${BASE}/users` ตรวจ res.ok ใช้ try/catch/finally และ cancelled flag
    // อัปเดต users, loading, error ให้ถูกต้องทุกสถานะ
  }, [reloadKey]);

  // TODO: สร้าง filtered จาก users โดยกรองด้วย search (ไม่สนตัวพิมพ์เล็กใหญ่) ตามชื่อ (name)
  const filtered = users;

  if (loading) return <View style={styles.center}><ActivityIndicator size="large" /></View>;
  if (error) {
    return (
      <View style={styles.center}>
        <Text>เกิดข้อผิดพลาด: {error}</Text>
        <Button title="ลองใหม่" onPress={() => setReloadKey(k => k + 1)} />
      </View>
    );
  }

  return (
    <View style={styles.container}>
      <TextInput style={styles.input} value={search} onChangeText={setSearch} placeholder="ค้นหาชื่อ" />
      <FlatList
        data={filtered}
        keyExtractor={u => String(u.id)}

ขั้นตอนการปฏิบัติ

  1. เปิด https://jsonplaceholder.typicode.com/users ในเบราว์เซอร์ อ่านโครงสร้าง JSON ของผู้ใช้หนึ่งคน แล้วเขียนรายชื่อฟิลด์ที่เห็น (อย่างน้อย 6 ฟิลด์) และชนิดของข้อมูลแต่ละฟิลด์ ลงในช่องบันทึกผล

  2. วางโค้ดตั้งต้น แล้วเขียน useEffect ที่ดึงข้อมูลตาม TODO ให้สถานะ loading error และ users ถูกต้องในทุกกรณี

  3. เขียน filtered ให้กรองรายชื่อตามช่องค้นหา และเพิ่มการแสดงเมือง (item.address.city) ในแต่ละรายการ

  4. ทดสอบ 3 กรณีและจดผลที่เห็น: (1) ปกติ (2) ใส่ URL ผิดเป็น /userz เพื่อให้ได้ 404 (3) เปิดโหมดเครื่องบินแล้วกดลองใหม่ ตรวจว่าแอปแสดงข้อความและปุ่มลองใหม่ได้โดยไม่ค้าง

  5. เพิ่ม pull-to-refresh ให้ FlatList (onRefresh และ refreshing) โดยดึงข้อมูลใหม่โดยไม่ล้างหน้าจอเป็นสถานะกำลังโหลดเต็มหน้า

  6. ตั้งข้อความผิดพลาดให้ต่างกันตามสาเหตุอย่างน้อย 2 แบบ (ติดต่อเครือข่ายไม่ได้ / เซิร์ฟเวอร์ตอบรหัสผิดปกติ ซึ่งแสดงรหัสสถานะ)

  7. ถ่ายภาพหน้าจอ 3 ภาพ (รายการ ผลค้นหา ข้อผิดพลาด) แล้ว Save และคัดลอกลิงก์

สิ่งที่ต้องส่ง

ลิงก์ Snack + ภาพหน้าจอ 3 ภาพ + รายชื่อฟิลด์ JSON + ตารางผลทดสอบ 3 กรณี (ส่งตามช่องทางที่ครูกำหนด)
