คู่มือสไตล์ React Native

ค้นหาคุณสมบัติที่ใช้ใน StyleSheet ว่าใช้ทำอะไร ใส่ค่าอะไรได้ พร้อมตัวอย่างโค้ดและภาพผลลัพธ์ ใช้คู่กับใบงานแอปแรก (วิชา 31901-2009)

รายการครบถ้วนอยู่ในเอกสารทางการ View Style Props, Text Style Props และ Layout with Flexbox ภาพตัวอย่างในหน้านี้จำลองบนเว็บ ผลจริงบนมือถืออาจต่างเล็กน้อย
