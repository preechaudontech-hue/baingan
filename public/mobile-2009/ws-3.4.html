ใบงานที่ 3.4 useEffect และวงจรชีวิต: นาฬิกาจับเวลาและสถานะแอป

เวลา 120 นาที · งานเดี่ยว · คะแนนเต็ม 10

จุดประสงค์

ใช้ useEffect ที่มีฟังก์ชันล้าง และใช้ AppState ตรวจสถานะของแอปได้

คำชี้แจง

สร้างนาฬิกาจับเวลาที่เริ่ม หยุด และรีเซ็ตได้ พร้อมแสดงสถานะของแอปและบันทึกจำนวนครั้งที่แอปเคยไปอยู่เบื้องหลัง

สิ่งที่ต้องเตรียม

  • ผลงานใบงาน 3.3
  • ใบความรู้ที่ 3 หัวข้อ useEffect และวงจรชีวิต

โค้ดตั้งต้น

คัดลอกไปวางใน Snack ที่ไฟล์ App.js
import { useState, useEffect } from 'react';
import { AppState, View, Text, Button, StyleSheet } from 'react-native';

export default function App() {
  const [seconds, setSeconds] = useState(0);
  const [running, setRunning] = useState(false);
  const [appStatus, setAppStatus] = useState(AppState.currentState);
  const [backCount, setBackCount] = useState(0);

  // TODO 1: useEffect ที่ตั้ง setInterval เมื่อ running เป็น true และมีฟังก์ชันล้าง
  // TODO 2: useEffect ที่ฟัง AppState แล้วอัปเดต appStatus และนับ backCount เมื่อเป็น 'background'

  return (
    <View style={styles.container}>
      <Text style={styles.time}>{seconds} วินาที</Text>
      <Text>สถานะแอป: {appStatus}</Text>
      <Text>ไปอยู่เบื้องหลัง: {backCount} ครั้ง</Text>
      <View style={styles.row}>
        <Button title={running ? 'หยุด' : 'เริ่ม'} onPress={() => setRunning(!running)} />
        <Button title="รีเซ็ต" onPress={() => { setRunning(false); setSeconds(0); }} />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 },
  time: { fontSize: 40, fontWeight: 'bold' },
  row: { flexDirection: 'row', gap: 12 },
});

ขั้นตอนการปฏิบัติ

  1. วางโค้ดตั้งต้นและรันดู ปุ่มและข้อความต้องแสดงบนมือถือ (จับเวลายังไม่ทำงาน)

  2. เขียน useEffect (TODO 1) ให้เมื่อ running เป็น true ตั้ง setInterval เพิ่ม seconds ทุก 1 วินาที และ return ฟังก์ชันที่เรียก clearInterval ใส่ [running] เป็น dependency

  3. ทดสอบกดเริ่ม หยุด รีเซ็ต แล้วเขียนอธิบายว่าถ้าไม่ใส่ฟังก์ชันล้างจะเกิดปัญหาอะไร

  4. เขียน useEffect (TODO 2) ให้ฟัง AppState ด้วย addEventListener('change', ...) อัปเดต appStatus และเพิ่ม backCount เมื่อสถานะเป็น 'background' พร้อมฟังก์ชันล้างที่เรียก remove()

  5. ทดสอบบนมือถือจริง: กดเริ่มจับเวลา สลับไปแอปอื่นประมาณ 5 วินาที แล้วกลับมา จดว่าค่า appStatus และ backCount เป็นอย่างไร และจับเวลายังเดินอยู่หรือไม่

  6. ทดลองใส่ dependency ผิด (เอา [running] ออก) ดูผลที่เปลี่ยน แล้วอธิบายเหตุผล จากนั้นแก้กลับ

  7. Save และคัดลอกลิงก์ ถ่ายภาพหน้าจอมือถือที่แสดงค่า backCount มากกว่าศูนย์

สิ่งที่ต้องส่ง

ลิงก์ Snack + ภาพหน้าจอมือถือ + บันทึกผลการทดสอบการสลับแอป + คำอธิบายฟังก์ชันล้างและ dependency (ส่งตามช่องทางที่ครูกำหนด)
