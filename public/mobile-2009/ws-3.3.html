จุดประสงค์

ใช้ useState เก็บข้อมูลที่เปลี่ยนแปลง และจัดการเหตุการณ์การกดและการกรอกข้อความ

คำชี้แจง

สร้างแอปเครื่องคิดเลขค่าบริการ (ทิป) แบบง่าย ผู้ใช้กรอกยอดเงิน เลือกเปอร์เซ็นต์ แล้วแสดงยอดค่าบริการและยอดรวม

สิ่งที่ต้องเตรียม

  • ใบความรู้ที่ 3 หัวข้อ State และเหตุการณ์

ขั้นตอนการปฏิบัติ

  1. วางโค้ดตั้งต้นใน App.js แล้วรันดูว่าแสดงช่องกรอกยอดเงินบนมือถือ

  2. เพิ่มปุ่ม 3 ปุ่ม (5, 10, 15 เปอร์เซ็นต์) ด้วยคอมโพเนนต์ Button ที่เรียก setPercent เมื่อกด และแสดงให้เห็นว่าปุ่มใดถูกเลือก (เช่น แสดงข้อความ "เลือก: 10%")

  3. คำนวณค่าบริการ = ยอดเงิน x เปอร์เซ็นต์ / 100 และยอดรวม = ยอดเงิน + ค่าบริการ โดยคำนวณในฟังก์ชันคอมโพเนนต์ (แปลงข้อความเป็นตัวเลขด้วย parseFloat และถ้ากรอกไม่ถูกให้ถือเป็น 0) แล้วแสดงผลทศนิยม 2 ตำแหน่ง (toFixed(2))

  4. เพิ่ม state ชื่อ history เก็บประวัติการคำนวณเป็นอาร์เรย์ และเพิ่มปุ่ม "บันทึกผล" ที่เพิ่มรายการใหม่ด้วย spread (ห้ามใช้ push) แล้วแสดงประวัติเป็นรายการด้วย map ใส่ key

  5. เพิ่มปุ่ม "ล้างประวัติ" ที่ตั้งค่า history เป็นอาร์เรย์ว่าง

  6. ทดสอบกรณีผิดปกติ 3 กรณี (ไม่กรอกยอด, กรอกตัวอักษร, ยอดเป็นศูนย์) แล้วบันทึกผลที่ได้และสิ่งที่ปรับปรุง

  7. ถ่ายภาพหน้าจอมือถือขณะมีประวัติอย่างน้อย 2 รายการ แล้ว Save และคัดลอกลิงก์

สิ่งที่ต้องส่ง

ลิงก์ Snack + ภาพหน้าจอมือถือที่มีประวัติ 2 รายการขึ้นไป + ตารางผลทดสอบกรณีผิดปกติ 3 กรณี (ส่งตามช่องทางที่ครูกำหนด)
