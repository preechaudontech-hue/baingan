ฝึกเขียนแอปแรก React Native

วิชา 31901-2009 · ทำทีละขั้น ดูภาพที่ควรเห็น อ่านโค้ดทีละบรรทัด แล้วตอบคำถามตรวจความเข้าใจ

เตรียมก่อนเริ่ม

เปิดที่เขียนโค้ดบนมือถือและคอมพิวเตอร์

  1. ติดตั้งแอป Expo Go บนมือถือ (ร้านแอปของเครื่อง)
  2. บนคอมพิวเตอร์ เปิด snack.expo.dev
  3. มุมล่างของ Snack เลือก SDK เป็น 54 (iPhone ใช้ Expo Go ได้เฉพาะ SDK 54)
  4. ไฟล์ที่เขียนคือ App.js ที่อยู่ในแผงซ้ายมือ ลบโค้ดเดิมทั้งหมดก่อนวางโค้ดใหม่ทุกครั้ง (กด Ctrl+A แล้ว Ctrl+V)
  5. สแกน QR ใน Snack ด้วยกล้องหรือในแอป Expo Go เพื่อดูผลบนเครื่องจริง

ถ้าสแกนแล้วไม่ขึ้น ให้ตรวจว่าเลือก SDK 54 และมือถือต่ออินเทอร์เน็ต แล้วแจ้งครู

ตัวช่วยเรื่องสไตล์

StyleSheet ใส่อะไรได้บ้าง

1. โครงสร้างการเขียน

const styles = StyleSheet.create({  box: { padding: 16, backgroundColor: 'pink' },   // ชื่อสไตล์: { คุณสมบัติ: ค่า }  title: { fontSize: 24, fontWeight: 'bold' },}); <View style={styles.box} />                  // ใช้ด้วยชื่อ<View style={[styles.box, styles.big]} />     // หลายสไตล์ ใส่ในอาร์เรย์ อันหลังทับอันหน้า<View style={{ padding: 16 }} />               // เขียนตรงในแท็ก ต้องมีวงเล็บ 2 ชั้น
  • ชื่อสไตล์ (box, title) ตั้งเองได้ ตั้งให้สื่อความหมาย
  • ชื่อคุณสมบัติ ต้องเป็นของ React Native และเขียนแบบ camelCase เช่น backgroundColor
  • ตัวเลข ไม่ใส่หน่วย (16 ไม่ใช่ '16px') ข้อความ ต้องมีเครื่องหมายคำพูด ('pink')
  • แต่ละคุณสมบัติคั่นด้วยเครื่องหมายจุลภาค (,)
  • วงเล็บ 2 ชั้นใน style={{ ... }}: ชั้นนอกคือ JSX ชั้นในคือออบเจ็กต์สไตล์

2. คุณสมบัติที่ใช้บ่อย แบ่งตามหน้าที่

4. ข้อผิดพลาดที่พบบ่อย

      

        
เขียนแบบนี้ผิดเขียนแบบนี้ถูกเหตุผล

        
background-color: 'pink'backgroundColor: 'pink'ชื่อคุณสมบัติเป็น camelCase

        
fontSize: '20px'fontSize: 20ตัวเลขไม่มีหน่วย

        
backgroundColor: pinkbackgroundColor: 'pink'สีเป็นข้อความ ต้องมีเครื่องหมายคำพูด

        
border: '1px solid black'borderWidth: 1, borderColor: 'black'ไม่มีคุณสมบัติแบบย่อของ CSS ต้องแยกเขียน

        
<View style={{ fontSize: 20 }}><Text style={{ fontSize: 20 }}>คุณสมบัติข้อความใช้กับ Text เท่านั้น

        
box: { padding: 16 }  title: {...}box: { padding: 16 },  title: {...}ลืมจุลภาคคั่นระหว่างสไตล์
