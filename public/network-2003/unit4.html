31908-2003 การออกแบบและติดตั้งระบบเครือข่ายหน่วยที่ 4
สารบัญหน่วยนี้1. Patch Panel และการจัดสายในตู้ Rack2. ตั้งค่าสวิตช์พื้นฐานผ่านคอนโซล3. แบ่งโซนเครือข่ายด้วย VLAN4. สำรองและกู้คืนค่าตั้งค่า5. วิเคราะห์ปัญหาสัญญาณเป็นระยะแบบฝึกหัดท้ายหน่วยใบงานของหน่วยนี้พิมพ์หน้านี้
หน่วยการเรียนรู้ที่ 4

ตั้งค่าชุดอุปกรณ์เครือข่าย

หลังเดินสายและเข้าหัวเสร็จ ต้องตั้งค่าอุปกรณ์ให้เครือข่ายทำงานและปลอดภัย หน่วยนี้สอนการติดตั้ง Patch Panel การทดสอบสาย การตั้งค่าสวิตช์พื้นฐาน การแบ่งโซนเครือข่าย (VLAN) และการสำรองค่าตั้งค่า โดยใช้คำสั่งแบบ Cisco IOS เป็นตัวอย่าง

เมื่อเรียนจบหน่วยนี้ นักเรียนจะ
  • ติดตั้ง Patch Panel และเชื่อมต่อสายตามแผนผังได้
  • ตั้งค่าพื้นฐานของสวิตช์ผ่านคอนโซลได้
  • สร้างและกำหนดพอร์ตให้ VLAN เพื่อแบ่งโซนเครือข่ายได้
  • สำรองและกู้คืนค่าตั้งค่า (Configuration) ของอุปกรณ์ได้

1. Patch Panel และการจัดสายในตู้ Rack

  • Patch Panel เป็นแผงที่สายแนวราบจากห้องต่างๆ มาจบ แล้วใช้สาย Patch Cord สั้นต่อไปยังสวิตช์ ทำให้เปลี่ยนการเชื่อมต่อได้โดยไม่ต้องแตะสายยาว
  • สายแนวราบเข้าหัวกับแผงด้วยเครื่องเข้าสายแบบ Punch Down ตามสีที่พิมพ์บนแผง (ตรวจว่าเลือกแถบสี A หรือ B ตรงกับมาตรฐานที่ใช้)
  • ติดฉลากหมายเลขพอร์ตบนแผงให้ตรงกับฉลากปลายสายที่ผนัง
  • จัดสายด้านหลังด้วยตัวจัดสาย รัดให้เป็นระเบียบ ไม่ดึงตึง
  • ทดสอบสายทุกเส้นหลังเข้าหัว ก่อนต่ออุปกรณ์

2. ตั้งค่าสวิตช์พื้นฐานผ่านคอนโซล

ต่อสาย Console เข้ากับพอร์ต Console ของสวิตช์ แล้วเปิดโปรแกรมเทอร์มินัล (เช่น PuTTY หรือเทอร์มินัลใน Packet Tracer) ตัวอย่างต่อไปนี้ใช้คำสั่งของ Cisco IOS ยี่ห้ออื่นอาจใช้คำสั่งต่างกัน แต่หลักการเหมือนกัน

Switch> enable
Switch# configure terminal
Switch(config)# hostname SW-Floor1
SW-Floor1(config)# enable secret <รหัสผ่านที่แข็งแรง>
SW-Floor1(config)# line console 0
SW-Floor1(config-line)# password <รหัสผ่านคอนโซล>
SW-Floor1(config-line)# login
SW-Floor1(config-line)# exit
SW-Floor1(config)# banner motd # Authorized use only #
ข้อควรระวัง ห้ามใช้รหัสผ่านเริ่มต้นของผู้ผลิตหรือรหัสผ่านที่เดาง่าย ต้องเปลี่ยนก่อนนำอุปกรณ์เข้าใช้งานจริงเสมอ

3. แบ่งโซนเครือข่ายด้วย VLAN

VLAN (Virtual LAN) คือการแบ่งสวิตช์ตัวเดียวออกเป็นหลายเครือข่ายย่อยแบบเสมือน อุปกรณ์คนละ VLAN จะไม่เห็นกันโดยตรง ต้องผ่านเราเตอร์หรือสวิตช์เลเยอร์ 3 ซึ่งช่วยลดขอบเขตความเสียหายและควบคุมการเข้าถึงได้

ตัวอย่าง VLANหมายเลขผู้ใช้
Office10คอมพิวเตอร์สำนักงาน
Guest20อุปกรณ์ของผู้มาติดต่อ แยกออกจากระบบภายใน
CCTV30กล้องวงจรปิด
SW-Floor1(config)# vlan 10
SW-Floor1(config-vlan)# name Office
SW-Floor1(config-vlan)# exit
SW-Floor1(config)# interface range fastEthernet 0/1 - 12
SW-Floor1(config-if-range)# switchport mode access
SW-Floor1(config-if-range)# switchport access vlan 10
SW-Floor1(config-if-range)# exit

! พอร์ตที่ต่อไปยังสวิตช์อื่น (Trunk) ใช้ส่งหลาย VLAN บนสายเดียว
SW-Floor1(config)# interface gigabitEthernet 0/1
SW-Floor1(config-if)# switchport mode trunk

ตรวจผลด้วยคำสั่ง show vlan brief และ show interfaces trunk

เคล็ดลับ แนวปฏิบัติด้านความปลอดภัย: ปิดพอร์ตที่ไม่ได้ใช้งาน (shutdown) และกำหนดให้เป็น VLAN ที่ไม่มีผู้ใช้ เพื่อไม่ให้ใครเสียบสายเข้ามาได้ง่าย

4. สำรองและกู้คืนค่าตั้งค่า

ค่าตั้งค่าที่กำลังใช้งานอยู่ในหน่วยความจำชั่วคราว (running-config) ต้องบันทึกลงหน่วยความจำถาวร (startup-config) ไม่เช่นนั้นเมื่ออุปกรณ์รีสตาร์ตค่าจะหาย และควรสำรองไว้ที่อื่นด้วย

SW-Floor1# copy running-config startup-config

! สำรองไปยังเซิร์ฟเวอร์ TFTP
SW-Floor1# copy running-config tftp:
Address or name of remote host []? 192.168.10.100
Destination filename [SW-Floor1-confg]? SW-Floor1-2569-10-29.cfg

! กู้คืนจากเซิร์ฟเวอร์
SW-Floor1# copy tftp: running-config
  1. บันทึกค่าตั้งค่าด้วย copy running-config startup-config หลังแก้ไขทุกครั้ง
  2. สำรองไฟล์ค่าตั้งค่าไปเก็บภายนอกอุปกรณ์ ตั้งชื่อไฟล์ให้มีชื่อเครื่องและวันที่
  3. เมื่ออุปกรณ์เสียหรือถูกรีเซ็ต ให้นำไฟล์สำรองมากู้คืน แล้วตรวจสถานะพอร์ตและ VLAN
ข้อมูลเพิ่มเติม TFTP ไม่มีการเข้ารหัสและไม่ตรวจสอบตัวตน ใช้ในเครือข่ายภายในที่เชื่อถือได้เท่านั้น งานจริงนิยมใช้วิธีที่ปลอดภัยกว่า เช่น SCP หรือ SFTP

5. วิเคราะห์ปัญหาสัญญาณเป็นระยะ

ถ้าลิงก์หลุดๆ หายๆ ให้ตรวจเป็นลำดับ จากง่ายไปยาก:

  1. ดูไฟสถานะพอร์ตและสวิตช์ว่ากระพริบหรือดับสลับ
  2. เปลี่ยน Patch Cord ทั้งสองฝั่งด้วยสายที่ทดสอบผ่านแล้ว
  3. ทดสอบสายแนวราบด้วย Cable Tester หรือ Analyzer ดูตำแหน่งที่ผิดปกติ
  4. ตรวจสาเหตุภายนอก เช่น สายอยู่ใกล้สายไฟ หรือหัวหลวม
  5. ดูบันทึกของสวิตช์ (show interfaces) ว่ามีข้อผิดพลาดจำนวนมากหรือไม่
  6. ย้ายอุปกรณ์ปลายทางไปพอร์ตอื่นเพื่อแยกว่าปัญหาอยู่ที่สายหรือพอร์ต

แบบฝึกหัดท้ายหน่วย

ลองตอบก่อน แล้วค่อยกดดูแนวคำตอบ

ข้อ 1 จงอธิบายความสำคัญของการแบ่งโซนเครือข่าย (VLAN) และผลกระทบต่อความปลอดภัยของข้อมูลในองค์กร

ดูแนวคำตอบ

VLAN แยกกลุ่มผู้ใช้ออกจากกัน อุปกรณ์ต่างโซนสื่อสารกันได้เฉพาะผ่านจุดที่ควบคุม ช่วยลดการแพร่ของปัญหาและการโจมตี ลดการกระจายข้อมูลกวาด (Broadcast) และควบคุมสิทธิ์ตามโซนได้ เช่น แยกเครือข่ายผู้เยี่ยมชมออกจากระบบภายใน

ข้อ 2 กรณีพบปัญหาสัญญาณเครือข่ายขาดหายเป็นระยะ ผู้เรียนจะมีขั้นตอนการตรวจสอบและวิเคราะห์ปัญหาอย่างไรให้ได้ผลลัพธ์ที่แม่นยำ

ดูแนวคำตอบ

ตรวจไฟสถานะ เปลี่ยน Patch Cord ทดสอบสายแนวราบด้วยเครื่องทดสอบหรือ Analyzer ตรวจสภาพแวดล้อมที่รบกวนสัญญาณ ดู error counter ของพอร์ต และย้ายปลายทางไปพอร์ตอื่นเพื่อแยกสาเหตุ แล้วบันทึกผลทุกขั้น

ข้อ 3 จงเขียนลำดับขั้นตอนการสำรองข้อมูลการตั้งค่า (Configuration Backup) จากอุปกรณ์สวิตช์ลงสู่เซิร์ฟเวอร์

ดูแนวคำตอบ

1) copy running-config startup-config เพื่อบันทึกถาวร 2) เตรียมเซิร์ฟเวอร์ TFTP และตรวจว่าเข้าถึงได้ด้วย ping 3) copy running-config tftp: 4) ใส่ที่อยู่ IP ของเซิร์ฟเวอร์และตั้งชื่อไฟล์ให้มีชื่อเครื่องและวันที่ 5) ตรวจว่ามีไฟล์บนเซิร์ฟเวอร์และเก็บสำเนาไว้อย่างน้อย 2 ที่

เอกสารอ้างอิง

  • Cisco IOS Configuration Guides (เอกสารคำสั่งตั้งค่าสวิตช์ VLAN และการสำรองค่า)
  • IEEE 802.1Q Virtual LANs Standard
  • คู่มือการใช้งานเครื่องทดสอบสายสัญญาณและโปรแกรม Cisco Packet Tracer
