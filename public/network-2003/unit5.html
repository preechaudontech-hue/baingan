31908-2003 การออกแบบและติดตั้งระบบเครือข่ายหน่วยที่ 5
สารบัญหน่วยนี้1. เครื่องมือตรวจสอบพื้นฐาน2. วิธีหาสาเหตุอย่างเป็นขั้นตอน3. การบำรุงรักษาเชิงป้องกัน (Preventive Maintenance)4. แบ่งโซนเครือข่ายและสำรองค่าตั้งค่า5. แผนผังก้างปลา (Fishbone Diagram)แบบฝึกหัดท้ายหน่วยใบงานของหน่วยนี้พิมพ์หน้านี้
หน่วยการเรียนรู้ที่ 5

ตรวจสอบและบำรุงรักษาเครือข่าย

เครือข่ายที่ติดตั้งเสร็จแล้วต้องมีคนดูแล หน่วยนี้สอนเครื่องมือตรวจสอบเครือข่ายพื้นฐาน การวิเคราะห์ปัญหาอย่างเป็นขั้นตอน การบำรุงรักษาเชิงป้องกัน การแบ่งโซนเพื่อความปลอดภัย การสำรอง/กู้คืนค่าตั้งค่า และการวิเคราะห์สาเหตุด้วยแผนผังก้างปลา

เมื่อเรียนจบหน่วยนี้ นักเรียนจะ
  • ใช้คำสั่งและเครื่องมือพื้นฐานตรวจสอบเครือข่ายได้
  • วิเคราะห์ปัญหาเครือข่ายอย่างเป็นขั้นตอน
  • วางแผนบำรุงรักษาเชิงป้องกันรายสัปดาห์ รายเดือน และรายปี
  • ใช้แผนผังก้างปลาหาสาเหตุของปัญหาและเขียนรายงานสถานะ

1. เครื่องมือตรวจสอบพื้นฐาน

เครื่องมือใช้ทำอะไรตัวอย่างคำสั่ง
pingตรวจว่าปลายทางตอบกลับหรือไม่ และดูเวลาตอบสนอง (Latency)ping 192.168.10.1
tracert / tracerouteดูเส้นทางที่แพ็กเก็ตผ่านไปยังปลายทางtracert 8.8.8.8 (Windows), traceroute 8.8.8.8 (Linux/Mac)
ipconfig / ifconfigดูการตั้งค่า IP ของเครื่องipconfig /all
nslookupทดสอบการแปลงชื่อโดเมนเป็น IPnslookup example.com
Wiresharkดักจับและวิเคราะห์แพ็กเก็ตเลือกอินเทอร์เฟซแล้วกด Capture ใช้ Display Filter เช่น icmp หรือ ip.addr == 192.168.10.5
iperf3วัดความเร็วรับส่งข้อมูลจริง (Throughput)เครื่อง A: iperf3 -s เครื่อง B: iperf3 -c <IP ของ A>
ข้อควรระวัง ใช้ Wireshark เฉพาะในเครือข่ายที่ได้รับอนุญาต เช่น ห้องปฏิบัติการของวิทยาลัยหรือเครือข่ายที่เป็นของตนเอง ข้อมูลที่จับได้อาจมีข้อมูลส่วนบุคคลของผู้อื่น

2. วิธีหาสาเหตุอย่างเป็นขั้นตอน

  1. ระบุปัญหา: ถามผู้ใช้ว่าอะไรไม่ทำงาน เกิดเมื่อไร เกิดกับใครบ้าง เพิ่งเปลี่ยนอะไรไป
  2. ตั้งสมมติฐาน: เริ่มจากสาเหตุที่พบบ่อยและตรวจง่ายก่อน
  3. ทดสอบสมมติฐาน: เช่น ping เกตเวย์ ตรวจไฟสถานะพอร์ต เปลี่ยนสาย
  4. วางแผนแก้และทำตามแผน: แจ้งผู้เกี่ยวข้องก่อนแก้ ถ้ามีผลต่อผู้ใช้อื่น
  5. ตรวจว่าแก้ได้จริง: ให้ผู้ใช้ทดสอบ และตรวจว่าไม่ทำให้ส่วนอื่นเสีย
  6. บันทึกผล: เขียนปัญหา สาเหตุ วิธีแก้ ไว้เป็นความรู้ให้ทีม

ตัวช่วยคิด: ไล่จากชั้นล่างขึ้นบน คือตรวจชั้นกายภาพก่อน (สาย พอร์ต ไฟสถานะ) แล้วดูการตั้งค่า IP และ VLAN จากนั้นจึงดูแอปพลิเคชัน ปัญหาจำนวนมากแก้ได้ตั้งแต่สายและพอร์ต

3. การบำรุงรักษาเชิงป้องกัน (Preventive Maintenance)

ความถี่งานทางกายภาพงานด้านการตั้งค่า
รายสัปดาห์ดูไฟสถานะอุปกรณ์ เสียงพัดลม ความเรียบร้อยของสายตรวจบันทึก (Log) และการแจ้งเตือนผิดปกติ
รายเดือนเช็ดฝุ่นรูระบายอากาศ ตรวจอุณหภูมิห้อง Rack ตรวจหัวและสายที่หลวมสำรองค่าตั้งค่า ตรวจสิทธิ์ผู้ใช้ ตรวจพอร์ตที่ไม่ได้ใช้
รายปีทดสอบสายที่สำคัญ ตรวจระบบไฟสำรอง (UPS) เปลี่ยนชิ้นส่วนที่เสื่อมอัปเดตเฟิร์มแวร์ที่จำเป็น ทบทวนแผนผังและบัญชีอุปกรณ์

4. แบ่งโซนเครือข่ายและสำรองค่าตั้งค่า

  • Network Segmentation: แบ่งเครือข่ายตามหน้าที่ เช่น สำนักงาน เซิร์ฟเวอร์ ผู้เยี่ยมชม ตัวอย่างที่จำเป็น เช่น แยก Wi-Fi ผู้เยี่ยมชมออกจากระบบบัญชีขององค์กร ถ้าเครื่องหนึ่งติดมัลแวร์ จะไม่แพร่ไปยังโซนอื่นง่ายๆ
  • สำรองค่าตั้งค่า: เก็บไฟล์สำรองหลายชุด ตั้งชื่อตามเครื่องและวันที่
  • กู้คืนเมื่อตั้งค่าผิด: ถ้าสวิตช์ตั้งผิดจนระบบล่ม ให้เชื่อมต่อผ่านคอนโซล ล้างค่าที่ผิดหรือโหลดไฟล์สำรองล่าสุดกลับ แล้วตรวจ VLAN พอร์ตและการเชื่อมต่อ

5. แผนผังก้างปลา (Fishbone Diagram)

แผนผังก้างปลาช่วยจัดกลุ่มสาเหตุที่เป็นไปได้ของปัญหาเดียว หัวปลาคือปัญหา ก้างแต่ละก้างคือหมวดสาเหตุ ตัวอย่างหมวดสำหรับงานเครือข่าย

หมวดตัวอย่างสาเหตุ
คนตั้งค่าผิด ไม่ได้อ่านเอกสาร ขาดการฝึกอบรม
อุปกรณ์พอร์ตเสีย สวิตช์ร้อนจัด หน่วยความจำเต็ม
สายสัญญาณหัวหลวม สายหักงอ ยาวเกินกำหนด
ซอฟต์แวร์/การตั้งค่าVLAN ผิด IP ซ้ำ เฟิร์มแวร์เก่า
สภาพแวดล้อมความร้อน ฝุ่น ไฟฟ้ารบกวน
กระบวนการไม่มีการสำรองค่า ไม่มีการตรวจเป็นประจำ

แบบฝึกหัดท้ายหน่วย

ลองตอบก่อน แล้วค่อยกดดูแนวคำตอบ

ข้อ 1 อธิบายความสำคัญของการทำ Network Segmentation ในระดับองค์กร พร้อมยกตัวอย่างสถานการณ์ที่จำเป็นต้องมีการแบ่งโซน

ดูแนวคำตอบ

ช่วยจำกัดขอบเขตความเสียหายและควบคุมการเข้าถึง ตัวอย่าง: แยกเครือข่ายผู้เยี่ยมชมออกจากระบบภายใน แยกกล้องวงจรปิดออกจากเครือข่ายสำนักงาน แยกเซิร์ฟเวอร์ที่เก็บข้อมูลสำคัญออกจากเครื่องผู้ใช้

ข้อ 2 วิเคราะห์สถานการณ์หากสวิตช์ตั้งค่าผิดพลาดจนทำให้ระบบล่ม นักเรียนจะมีขั้นตอนในการกู้คืนระบบจากการสำรองข้อมูลอย่างไรให้เร็วที่สุด

ดูแนวคำตอบ

เชื่อมต่อผ่านคอนโซล ตรวจว่าค่าล่าสุดผิดตรงไหน หรือกู้ไฟล์สำรองล่าสุดจากเซิร์ฟเวอร์ (เช่น copy tftp: running-config) ตรวจสถานะพอร์ตและ VLAN ทดสอบการเชื่อมต่อ แล้วบันทึกลง startup-config และเขียนรายงาน

ข้อ 3 จงสรุปขั้นตอนการทำ Preventive Maintenance สำหรับอุปกรณ์ Router และ Switch ในระยะเวลา 1 ปี

ดูแนวคำตอบ

รายสัปดาห์ดูไฟสถานะและ Log รายเดือนเช็ดฝุ่น ตรวจอุณหภูมิ สำรองค่าตั้งค่า และตรวจพอร์ตที่ไม่ใช้ รายปีตรวจ UPS ทดสอบสายสำคัญ อัปเดตเฟิร์มแวร์ที่จำเป็น และทบทวนแผนผังและบัญชีอุปกรณ์

เอกสารอ้างอิง

  • เอกสารคู่มือการใช้งาน Wireshark และ iperf3 (เว็บไซต์ทางการของผู้พัฒนา)
  • แนวทางการแก้ปัญหาเครือข่ายตามลำดับขั้น (เช่น หลักสูตรของ CompTIA Network+ และ Cisco Networking Academy)
  • มาตรฐานอาชีพ สถาบันคุณวุฒิวิชาชีพ ช่างสนับสนุนด้านเทคนิค
